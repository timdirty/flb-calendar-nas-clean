# ✅ 日曆點擊智慧切換完成

## 📋 問題描述

使用者回報：「點擊週日曆或月日曆上的課程方塊，會找不到對應的卡片」

從控制台日誌可以看到：
```
🎯 點擊事件方塊（事件委派）: 20251018T043653-ecgawtic@cal.synology.com
🎯 高亮課程卡片（全域函數被調用）: 20251018T043653-ecgawtic@cal.synology.com
⚠️ 找不到對應的課程卡片: 20251018T043653-ecgawtic@cal.synology.com
📊 可用的課程ID: (16) ['20251018T043723-ouqqshoc@cal.synology.com', ...]
```

## 🔍 根本原因

**視圖範圍不一致問題：**

1. **週日曆渲染**：使用 `getFilteredEvents()`，會顯示所有符合講師篩選的課程
   - 例如：TIM 講師有 78 個課程
   - 週日曆會顯示所有 78 個課程的方塊

2. **課程列表渲染**：使用 `renderEvents()`，只渲染當前視圖範圍的課程
   - 「本週」視圖：只顯示 16 個本週課程
   - 「今日」視圖：只顯示 1 個今日課程
   - 「全部」視圖：顯示所有 78 個課程

3. **點擊問題**：
   - 使用者點擊週日曆上的某個課程（78個中的一個）
   - 但該課程可能不在當前視圖（本週的16個）中
   - 導致 `highlightEventCardFromCalendar()` 找不到對應的卡片

## 💡 解決方案

參考 `learning-record-upload.html` 的高亮實現，實現**智慧視圖切換**：

### 核心邏輯

```javascript
window.highlightEventCardFromCalendar = function(eventId) {
    // 1. 嘗試在當前視圖中找到課程卡片
    let targetCard = document.querySelector(`[data-event-id="${eventId}"]`);
    
    // 2. 如果找不到，檢查是否存在於 allEvents 中
    if (!targetCard) {
        const eventExists = allEvents.some(e => {
            const eId = e.id || e.uid || e.evt_id || '';
            return eId === eventId;
        });
        
        // 3. 如果存在但不在當前視圖，自動切換到「全部」視圖
        if (eventExists) {
            switchView('全部', 'all');
            
            // 4. 等待視圖切換完成後，重新查找並高亮
            setTimeout(() => {
                const retryCard = document.querySelector(`[data-event-id="${eventId}"]`);
                if (retryCard) {
                    performHighlight(retryCard, eventId);
                }
            }, 1000);
            
            return;
        }
    }
    
    // 5. 如果在當前視圖中找到，直接高亮
    performHighlight(targetCard, eventId);
};
```

```javascript
// 🔥 抽取高亮邏輯為獨立函數，避免重複代碼
function performHighlight(targetCard, eventId) {
    // 高亮來源 chip
    document.querySelectorAll('.event-chip').forEach(chip => {
        if (chip.getAttribute('data-event-id') === eventId) {
            chip.classList.add('highlight-source');
        }
    });
    
    // 高亮目標卡片，其他變暗
    targetCard.classList.add('highlight-target');
    document.querySelectorAll('.event-card').forEach(card => {
        if (card !== targetCard) {
            card.classList.add('dimmed');
        }
    });
    
    // 滾動到目標卡片
    // ...
}
```

#### 4️⃣ 避免意外觸發

```javascript
// 標記這是自動切換（避免觸發智慧篩選）

window.pendingHighlightEventId = eventId;
```

## 📊 技術細節

### 視圖切換流程

```
1. 使用者點擊日曆課程方塊
   ↓
2. 調用 highlightEventCardFromCalendar(eventId)
   ↓
3. 嘗試在當前視圖中查找課程卡片
   ↓
4. 找不到？
   ├─ YES → 檢查是否存在於 allEvents
   │         ├─ 存在 → 切換到「全部」視圖
   │         │         ↓
   │         │         等待 1 秒
   │         │         ↓
   │         │         重新查找並高亮
   │         │
   │         └─ 不存在 → 顯示錯誤訊息
   │
   └─ NO → 直接高亮並滾動
```

### 效能考量

1. **非阻塞操作**：使用 `setTimeout` 避免阻塞 UI
2. **條件切換**：只在必要時才切換視圖
3. **單次重試**：避免無限循環
4. **清晰日誌**：方便調試和監控
