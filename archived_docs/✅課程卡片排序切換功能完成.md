### 3️⃣ 排序邏輯更新

#### 主要課程列表排序
**位置**: `perfect-calendar-optimized-complete2.html` (第 14851-14878 行)

```javascript
filteredEvents.sort((a, b) => {
    const now = new Date();
    const eventA = new Date(a.start);
    const eventB = new Date(b.start);
    const endA = new Date(a.end);
    const endB = new Date(b.end);
    
    // 判斷課程是否正在進行中
    const isEventAOngoing = eventA <= now && endA > now;
    const isEventBOngoing = eventB <= now && endB > now;
    
    // 正在進行中的課程，距離為 0（最優先）
    const distanceA = isEventAOngoing ? 0 : Math.abs(now - eventA);
    const distanceB = isEventBOngoing ? 0 : Math.abs(now - eventB);
    
    // 根據排序方向決定排序
    let result = 0;
    if (distanceA !== distanceB) {
        result = distanceA - distanceB;
    } else {
        result = eventA - eventB;
    }
    
    // 如果是「由遠到近」，反轉結果
    return sortDirection === 'far-to-near' ? -result : result;
});
```

### 4️⃣ 事件處理邏輯

**位置**: `perfect-calendar-optimized-complete2.html` (第 13319-13369 行)

**功能**:
- ✅ 點擊按鈕切換排序方向
- 💾 自動儲存到 localStorage
- 🔄 自動重新渲染課程列表
- 📢 顯示切換成功的通知
- 🎯 頁面載入時自動恢復上次的排序設定

```javascript
sortToggleBtns.forEach(btn => {
    btn.addEventListener('click', function() {
        const newSortDirection = this.getAttribute('data-sort');
        
        // 更新全域變數
        sortDirection = newSortDirection;
        
        // 儲存到 localStorage
        localStorage.setItem('courseSortDirection', newSortDirection);
        
        // 更新按鈕狀態
        sortToggleBtns.forEach(b => b.classList.remove('active'));
        this.classList.add('active');
        
        // 重新渲染課程列表
        renderEvents();
        
        // 如果在今日視圖，也要重新渲染今日課程區塊
        if (currentView === '今日') {
            renderTodayEvents();
        }
        
        // 顯示提示
        showNotification(
            newSortDirection === 'near-to-far' ? '已切換為「由近到遠」' : '已切換為「由遠到近」',
            'success',
            2000
        );
    });
});
```

## 🎯 排序邏輯說明

### 由近到遠 (near-to-far) - 預設
1. 正在進行中的課程最優先
2. 其他課程按距離當前時間的遠近排序
3. 剛結束和即將開始的課程會混合顯示
4. 越靠近當前時間的課程排在越上面

### 由遠到近 (far-to-near)
1. 最遠的課程排在最上面
2. 最近的課程排在最下面
3. 適合想要查看長期課程安排的使用者
