# 🧪 前端優化快速測試指南

## 📱 測試環境準備

### 桌面端測試
1. **瀏覽器：** Chrome / Edge / Safari（最新版）
2. **開發者工具：** F12 打開 Console
3. **測試網址：** http://localhost:3040 或 NAS_IP:3040

### 手機端測試
1. **連接同一網路**
2. **打開瀏覽器**（建議 Chrome 或 Safari）
3. **訪問：** http://NAS_IP:3040

---

## 🎨 測試項目 1：液態玻璃綁定通知

### 自動測試（正常使用流程）
1. **登入系統**
   - 使用 LINE 登入
   - 觀察是否出現液態玻璃風格的綁定通知

2. **綁定講師**
   - 點擊「綁定講師」按鈕
   - 選擇一位講師
   - 確認綁定
   - **預期結果：** 出現綠色液態玻璃成功通知

3. **解除綁定**
   - 點擊「解除綁定」
   - 確認解除
   - **預期結果：** 出現相應的通知效果

### 手動測試（Console 測試）
打開瀏覽器 Console（F12），執行以下命令：

```javascript
// 測試成功通知
showBindingNotification('✨ 成功綁定講師：Tim', 'success');

// 等待 4 秒後...

// 測試處理中通知（會旋轉）
showBindingNotification('正在比對講師身份...', 'processing', { persist: true });

// 等待 3 秒後手動移除
document.querySelector('.binding-notification').remove();

// 測試警告通知
showBindingNotification('⚠️ 未找到匹配的講師', 'warning');

// 等待 4 秒後...

// 測試錯誤通知
showBindingNotification('❌ 綁定失敗，請稍後重試', 'error');

// 測試資訊通知
showBindingNotification('💡 請選擇要綁定的講師', 'info');
```

### 驗證要點
- ✅ 通知位置正確（手機：頂部20px，桌面：頂部100px）
- ✅ 液態玻璃效果清晰（模糊背景、漸層、陰影）
- ✅ 動畫流暢（彈出和消失）
- ✅ 自動消失（3.5 秒後）
- ✅ 圖標正確顯示並旋轉（processing 類型）
- ✅ 顏色符合預期

## 📱 測試項目 2：手機端性能優化

### 設備檢測測試
打開手機瀏覽器的 Console（需要遠程調試），查看輸出：

```
預期輸出：
🔧 設備檢測: {
  isMobile: true,
  isLowEnd: false (或 true，取決於設備),
  memory: 4 (或其他值),
  cores: 4 (或其他值),
  screenWidth: 375 (或其他值)
}
```

**如果是低端設備（memory < 4GB 或 cores < 4）：**
```
✅ 已啟用低端設備優化
✅ 滾動性能優化已啟用
✅ Touch 事件優化已啟用
```

### 滾動性能測試
1. **進入課程列表頁面**
2. **快速上下滾動**
3. **驗證要點：**
   - ✅ 滾動流暢，無卡頓
   - ✅ 滾動時非關鍵動畫暫停（低端設備）
   - ✅ 滾動慣性自然

### Touch 反饋測試
1. **點擊各種按鈕**
2. **驗證要點：**
   - ✅ 點擊反饋迅速（< 30ms）
   - ✅ 無雙擊縮放
   - ✅ Tap 高亮顏色自然

### 低端設備特殊測試（僅在低端設備）
1. **檢查動畫時長**
   - 所有動畫應該更快（0.25s）
   - 過渡效果更簡短

2. **檢查模糊效果**
   - 模糊程度降低（blur(8px) 而非 blur(20px)）
   - 性能更好

3. **檢查陰影**
   - 陰影簡化（單層而非多層）

1. **打開 Chrome DevTools**
2. **切換到 Performance 面板**
3. **點擊錄製按鈕**

- **FCP (First Contentful Paint):** < 1s
- **LCP (Largest Contentful Paint):** < 2.5s
- **FID (First Input Delay):** < 100ms
- **CLS (Cumulative Layout Shift):** < 0.1

**手機端預期指標：**
- **FCP:** < 1.8s
- **LCP:** < 4s
- **FID:** < 100ms
- **CLS:** < 0.1

## ❌ 常見問題排查

### 問題 1：通知沒有顯示
**排查步驟：**
1. 打開 Console，檢查是否有錯誤
2. 手動測試：`showBindingNotification('測試', 'success')`
3. 檢查 CSS 是否載入：`document.getElementById('binding-notification-styles')`

### 問題 2：手機端沒有優化
**排查步驟：**
1. 檢查 Console 輸出
2. 確認 `MobileOptimizer.isMobile` 為 `true`
3. 檢查 `MobileOptimizer.init()` 是否執行

### 問題 3：載入很慢
**排查步驟：**
1. 檢查後端日誌：`docker-compose logs -f`
2. 確認 CalDAV 連線：查找 "CalDAV 客戶端初始化成功"
3. 檢查快取狀態：訪問 `/api/events/cache-status`

### 問題 4：講師綁定失敗
**排查步驟：**
1. 檢查 `allInstructors` 是否已填充
2. 確認 `populateInstructorDropdown()` 完成
3. 查看 Console 的比對流程日誌
