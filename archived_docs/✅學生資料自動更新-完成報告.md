# ✅ 學生資料自動更新功能 - 完成報告

**完成時間**: 2025-10-17  
**功能描述**: 實作學生資料從 Google Sheets 自動同步更新機制

---

## 🎯 功能概述

系統現在支援從 Google Sheets 自動更新學生資料，包含：

### ✅ 方案1：每日定時更新
- 每天固定時間自動從 Google Sheets 同步學生資料
- 預設：每天凌晨 2:00 執行
- 可自訂更新時間

### ✅ 方案3：間隔定時更新
- 按照設定的時間間隔自動更新
- 可設定為每 X 分鐘更新一次
- 預設：關閉（設為 0 表示停用）

---

## 📦 安裝的套件

### node-schedule
```bash
npm install node-schedule --save
```

**用途**:
- 提供 cron-like 的排程功能
- 支援精確到分鐘的定時任務
- 可動態啟動和停止排程

### 2. `system-settings.json`
新增配置區塊：
```json
{
  "studentDataSync": {
    "enabled": true,
    "autoUpdateEnabled": true,
    "updateTime": "02:00",
    "intervalMinutes": 0,
    "retryMaxAttempts": 3,
    "retryDelaySeconds": 60,
    "logUpdates": true
  }
}
```

**配置說明**:
- `enabled`: 是否啟用學生資料同步功能
- `autoUpdateEnabled`: 是否啟用自動更新
- `updateTime`: 每日更新時間（24小時制，格式：HH:MM）
- `intervalMinutes`: 間隔更新分鐘數（0 = 停用）
- `retryMaxAttempts`: 失敗重試次數
- `retryDelaySeconds`: 重試間隔秒數
- `logUpdates`: 是否記錄更新日誌

## 🔄 工作流程

### 啟動時自動初始化
```
服務啟動
    ↓
載入 system-settings.json
    ↓
檢查 studentDataSync.enabled
    ↓
檢查 autoUpdateEnabled
    ↓
啟動排程
    ├─ updateTime → 每日定時更新（cron job）
    └─ intervalMinutes > 0 → 間隔更新（setInterval）
```

### 每日定時更新流程
```
凌晨 2:00（預設）
    ↓
觸發 node-schedule 排程
    ↓
執行 updateStudentDataFromGoogleSheets()
    ↓
呼叫 Google Sheets API
    ↓
更新 student_data.json
    ↓
記錄日誌
```

### 間隔更新流程（如果啟用）
```
每 X 分鐘
    ↓
觸發 setInterval
    ↓
執行 updateStudentDataFromGoogleSheets()
    ↓
呼叫 Google Sheets API
    ↓
更新 student_data.json
    ↓
記錄日誌
```

## 📝 使用方式

### 1. 預設配置（推薦）

**每日凌晨 2:00 自動更新**

`system-settings.json`:
```json
{
  "studentDataSync": {
    "enabled": true,
    "autoUpdateEnabled": true,
    "updateTime": "02:00",
    "intervalMinutes": 0
  }
}
```

**不需要任何額外操作**，系統會自動執行。

### 2. 修改更新時間

**改為每天早上 8:00 更新**

```json
{
  "studentDataSync": {
    "updateTime": "08:00"
  }
}
```

重啟服務：
```bash
docker-compose restart
```

### 3. 啟用間隔更新

**每 30 分鐘更新一次**

```json
{
  "studentDataSync": {
    "updateTime": "02:00",
    "intervalMinutes": 30
  }
}
```

**注意**: 同時啟用兩種方式時，會並存運作。

### 4. 只使用間隔更新

```json
{
  "studentDataSync": {
    "updateTime": "",
    "intervalMinutes": 60
  }
}
```

將 `updateTime` 設為空字串即可停用每日定時更新。

### 5. 停用自動更新

```json
{
  "studentDataSync": {
    "enabled": true,
    "autoUpdateEnabled": false
  }
}
```

或透過 API：
```bash
curl -X POST http://localhost:3000/api/student-data-sync/stop
```

### 6. 手動觸發更新

透過 API：
```bash
curl -X POST http://localhost:3000/api/student-data-sync/trigger
```

或使用現有的按鈕介面。

## 🛠️ 故障排除

### 問題1：排程沒有執行

**檢查項目**:
```bash
# 1. 檢查設定檔
cat system-settings.json | jq .studentDataSync

# 2. 檢查系統狀態
curl http://localhost:3000/api/system-status | jq .data.studentDataSync

# 3. 檢查日誌
docker-compose logs | grep "學生資料自動更新"
```

**預期輸出**:
```
✅ 已啟動學生資料每日自動更新 (每天 02:00)
```

### 問題2：更新失敗

**常見原因**:
1. Google Sheets API 限制
2. 網路連線問題
3. Cookie 過期

**解決方式**:
- 系統會自動重試（預設 3 次）
- 檢查日誌中的錯誤訊息
- 確認 Google Sheets API URL 正確

### 問題3：想改變更新時間

**方法1：修改設定檔**
```bash
# 編輯設定檔
nano system-settings.json

# 重啟服務
docker-compose restart
```

**方法2：使用 API**
```bash
curl -X POST http://localhost:3000/api/student-data-sync/settings \
  -H "Content-Type: application/json" \
  -d '{"updateTime":"08:00"}'
```

### 問題4：暫時停用自動更新

```bash
curl -X POST http://localhost:3000/api/student-data-sync/stop
```

**恢復**:
```bash
curl -X POST http://localhost:3000/api/student-data-sync/start
```

## ⚙️ 進階設定

### 同時使用兩種更新方式

```json
{
  "studentDataSync": {
    "enabled": true,
    "autoUpdateEnabled": true,
    "updateTime": "02:00",
    "intervalMinutes": 360
  }
}
```

**說明**:
- 每天凌晨 2:00 執行一次
- 每 6 小時（360 分鐘）執行一次
- 兩種排程獨立運作

### 自訂重試機制

```json
{
  "studentDataSync": {
    "retryMaxAttempts": 5,
    "retryDelaySeconds": 120
  }
}
```

**說明**:
- 失敗時最多重試 5 次
- 每次重試間隔 120 秒

### 關閉更新日誌

```json
{
  "studentDataSync": {
    "logUpdates": false
  }
}
```

**說明**: 減少日誌輸出，只顯示錯誤訊息

## 📊 效能考量

### Google Sheets API 配額

- **每日請求限制**: 視 Google 帳號類型而定
- **建議頻率**: 
  - 每日更新：適合大多數情況
  - 間隔更新：不建議低於 30 分鐘

### 資源使用

- **記憶體**: node-schedule 佔用極小（< 5MB）
- **CPU**: 排程檢查幾乎無影響
- **網路**: 只在實際更新時發送請求
