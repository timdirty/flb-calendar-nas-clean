## ⚡ 3 分鐘快速設定

### 第 1 分鐘：基本設定 ⏱️

1. **開啟管理控制台**
   - 在瀏覽器中訪問上方網址
   - 看到漂亮的控制台介面 ✨

2. **設定管理員**（最重要！）
   - 點擊「<i class="fas fa-bell"></i> 通知設定」分頁
   - 在「管理員 LINE User ID」欄位確認：
     ```
     Udb51363eb6fdc605a6a9816379a38103
     ```
   - 點擊「💾 設定管理員」按鈕
   - 看到「✅ 管理員設定成功」

### 第 2 分鐘：查看數據 ⏱️

1. **查看講師列表**
   - 點擊「<i class="fas fa-user-tie"></i> 講師管理」分頁
   - 看到所有講師的 LINE User ID
   - 可以為每位講師設定專屬顏色 🎨

2. **查看學生資料**
   - 點擊「<i class="fas fa-user-graduate"></i> 學生管理」分頁
   - 看到所有學生資料

### 第 3 分鐘：測試功能 ⏱️

1. **測試 Google Sheets API**
   - 點擊「<i class="fab fa-google"></i> Google API」分頁
   - 點擊「📋 測試出席記錄 API」
   - 查看測試結果

2. **備份配置**（重要！）
   - 點擊「<i class="fas fa-exchange-alt"></i> 匯入/匯出」分頁
   - 點擊「📥 匯出所有配置」
   - 保存 JSON 文件 💾

## 🎨 JSON 編輯器（進階）

### 直接編輯配置

```
步驟：
1. 進入「匯入/匯出」分頁
2. 滾動到「JSON 編輯器」區域
3. 點擊「🔄 載入當前配置」
4. 在編輯器中修改 JSON
5. 點擊「📐 格式化」（可選）

7. 點擊「💾 儲存 JSON」
```

## 💡 使用技巧

### 1. 定期備份
```
建議：每週匯出一次完整配置
操作：匯入/匯出 → 匯出所有配置
儲存：以日期命名（如：flb-config-2025-10-10.json）
```

### 2. 測試後再應用
```
流程：
1. 匯出當前配置（備份）
2. 修改設定
3. 測試功能
4. 如果有問題，匯入備份
5. 如果正常，保留新設定
```

### 3. 使用搜尋功能
```
講師管理 → 搜尋框 → 輸入講師名稱
學生管理 → 搜尋框 → 輸入學生名稱
系統日誌 → 搜尋框 → 輸入關鍵字
```

### 4. 批量操作
```
方法：
1. 匯出當前配置
2. 在文字編輯器中批量修改 JSON
3. 驗證 JSON 格式（使用 jsonlint.com）
4. 匯入修改後的配置
```

## 🆘 常見問題

### Q: 配置沒有保存？
**A:** 確認點擊了「儲存」按鈕，並檢查瀏覽器是否允許 localStorage。

### Q: API 調用失敗？
**A:** 檢查網路連接，確認後端服務運行正常。打開瀏覽器控制台（F12）查看錯誤訊息。

### Q: 如何恢復預設設定？
**A:** 進入「系統配置」→ 點擊「🔄 恢復預設值」。

### Q: 講師顏色如何同步到行事曆？
**A:** 講師顏色會自動應用到行事曆中的課程顯示，無需額外操作。

### Q: Google Sheets 同步失敗？
**A:** 確認 Google Sheets API URL 正確，並測試 API 連接。
