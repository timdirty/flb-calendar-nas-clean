## 問題描述

所有課程時間都**差了 8 小時**：
- ❌ ESM 六 10:00-10:40 → 顯示 `02:00`

原因：時區轉換問題（台灣 UTC+8）

## 🔍 如果問題持續

如果修復後時間仍然不對，可能是代碼層級的問題。

### 診斷步驟

1. **檢查容器日誌**
   ```bash
   docker logs flb-calendar-nas --tail 100 | grep "創建.*提醒\|課程時間"
   ```

2. **執行完整診斷**
   ```bash
   cd /volume1/docker/flb-calendar-nas
   docker exec flb-calendar-nas node 診斷事件時間.js
   ```

3. **檢查 Synology Calendar API 返回數據**
   - 查看日誌中 `event.start` 的值
   - 確認是否為正確的台灣時間格式

### 可能的原因

1. **Synology Calendar API 返回的時間格式有誤**
   - 需要修改 `synology-calendar-client.js`

2. **reminder-scheduler.js 解析時間時出錯**
   - 檢查 `event.start.split('T')[1]` 的邏輯

3. **系統時區設定有問題**
   - 檢查 Docker 容器的時區設定
