# 🔧 修復上傳 502 錯誤指南

## 問題描述

上傳學習記錄時出現 502 Bad Gateway 錯誤，通常是由於：
- 後端服務未運行或崩潰
- 文件大小超過限制
- 路徑權限問題
- Nginx/代理服務器配置問題

## ✅ 已修復的問題

### 1. CSP (Content Security Policy) 錯誤
**問題**：圖片和影片預覽時被 CSP 阻擋
```
Refused to load the image 'blob:...' because it violates CSP directive
```

**解決方案**：已更新 `learning-record-upload.html` 的 CSP 設置，添加了 `blob:` 支持：
```html
<meta http-equiv="Content-Security-Policy" content="
  ...
  img-src 'self' data: https: blob:;
  connect-src 'self' blob:;
  media-src 'self' blob:;
  ...
">
```

### 2. 改進的錯誤處理
- 添加了詳細的上傳日誌
- 改進了錯誤訊息顯示
- 添加了文件大小統計
- 更好的服務器響應處理

## 🛠️ 解決方案

### 方案 1：重啟服務
```bash
# 停止現有服務
pkill -f "node.*server.js"

# 重新啟動
node server.js
# 或者後台運行
nohup node server.js > server.log 2>&1 &
```

### 方案 2：創建必要目錄
```bash
# 確保 NAS 路徑存在
mkdir -p "/volume1/Fun Learn Bar/學習歷程 automatic"

# 設置權限
chmod 755 "/volume1/Fun Learn Bar/學習歷程 automatic"

# 創建臨時上傳目錄
mkdir -p ./uploads
chmod 755 ./uploads
```

### 方案 3：增加文件上傳限制（Nginx）

如果使用 Nginx 作為反向代理，編輯 Nginx 配置：

```nginx
server {
    ...
    
    # 增加文件上傳大小限制
    client_max_body_size 100M;
    
    # 增加超時時間
    proxy_read_timeout 300;
    proxy_connect_timeout 300;
    proxy_send_timeout 300;
    
    location /api/ {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

重新載入 Nginx：
```bash
sudo nginx -t
sudo nginx -s reload
```

### 方案 4：檢查 Multer 配置

確保 `server.js` 中的 multer 配置正確：

```javascript
const storage = multer.diskStorage({
  destination: function (req, file, cb) {
    const targetPath = generateLearningPath(...);
    
    // 確保目錄存在
    if (!fs.existsSync(targetPath)) {
      fs.mkdirSync(targetPath, { recursive: true });
    }
    
    cb(null, targetPath);
  },
  filename: function (req, file, cb) {
    // 文件命名邏輯
    cb(null, filename);
  }
});

const upload = multer({ 
  storage: storage,
  limits: { 
    fileSize: 50 * 1024 * 1024  // 50MB
  }
});
```

## 🚨 常見錯誤

### 錯誤 1：502 Bad Gateway
**原因**：Node.js 服務未運行或崩潰
**解決**：重啟服務

### 錯誤 2：ENOENT: no such file or directory
**原因**：目標路徑不存在
**解決**：確保 NAS 路徑存在並有寫入權限

### 錯誤 3：EACCES: permission denied
**原因**：沒有目錄寫入權限
**解決**：
```bash
sudo chmod 755 "/volume1/Fun Learn Bar/學習歷程 automatic"
```

### 錯誤 4：File too large
**原因**：文件超過 multer 或 Nginx 限制
**解決**：增加限制配置

### 錯誤 5：Request Entity Too Large
**原因**：Nginx 的 client_max_body_size 限制
**解決**：修改 Nginx 配置
