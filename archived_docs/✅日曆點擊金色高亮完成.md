## 🎨 新的高亮效果

### 視覺效果對比

#### 修改前（藍紫色主題）
```css
.event-card.highlight-target {
    border: 3px solid #4f46e5;  /* 藍紫色 */
```

#### 修改後（金色主題）
```css
.event-card.highlight-target {
    border: 3px solid #ffd43b !important;  /* 金色 */
    box-shadow: 0 20px 40px rgba(255, 193, 7, 0.5), 
                0 0 0 4px rgba(255, 214, 107, 0.3) !important;  /* 光暈 */

    background: linear-gradient(160deg, rgba(255, 251, 235, 0.98), 
                rgba(255, 243, 205, 0.95)) !important;  /* 金色漸變背景 */
    animation: highlightPulse 2s ease-in-out infinite !important;  /* 呼吸動畫 */
}
```

效果：

## 🎯 完整使用流程

### 場景 1：點擊本週課程
```
1. 使用者在「本週」視圖
2. 點擊週日曆上的本週課程方塊
   ↓
3. 直接在當前視圖中高亮該課程
4. 用金色呼吸動畫標記
5. 右上角顯示「⭐ 從日曆跳轉的課程」
6. 滾動到該課程位置
```

```

```
