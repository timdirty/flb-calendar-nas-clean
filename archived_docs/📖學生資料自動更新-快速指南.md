# 📖 學生資料自動更新 - 快速指南

> 一分鐘快速了解如何使用學生資料自動更新功能

---

## 🎯 功能說明

系統會**自動從 Google Sheets 同步學生資料**到本地，無需手動操作。

### 支援兩種更新方式：

1. **每日定時更新** 🕐
   - 預設：每天凌晨 2:00 自動更新
   
2. **間隔定時更新** ⏱️
   - 可設定每 X 分鐘自動更新
   - 預設：關閉

---

## ⚙️ 快速設定

### 方式1：編輯設定檔（推薦）

**檔案**: `system-settings.json`

```json
{
  "studentDataSync": {
    "enabled": true,
    "autoUpdateEnabled": true,
    "updateTime": "02:00",
    "intervalMinutes": 0
  }
}
```

**修改後重啟**:
```bash
docker-compose restart
```

### 方式2：使用 API

**修改更新時間為早上 8:00**:
```bash
curl -X POST http://localhost:3000/api/student-data-sync/settings \
  -H "Content-Type: application/json" \
  -d '{"updateTime":"08:00"}'
```

**啟用每小時自動更新**:
```bash
curl -X POST http://localhost:3000/api/student-data-sync/settings \
  -H "Content-Type: application/json" \
  -d '{"intervalMinutes":60}'
```

## 📊 查看狀態

### 檢查自動更新狀態：

```bash
curl http://localhost:3000/api/system-status | jq .data.studentDataSync
```

**回應範例**:
```json
{
  "enabled": true,
  "autoUpdateEnabled": true,
  "updateTime": "02:00",
  "intervalMinutes": 0,
  "hasSchedule": true,  // ✅ 每日定時已啟動
  "hasInterval": false  // ⏹️ 間隔更新未啟動
}
```

### 查看更新日誌：

```bash
docker-compose logs -f | grep "學生資料"
```

## 🔧 常用操作

### 1. 立即手動更新

```bash
curl -X POST http://localhost:3000/api/student-data-sync/trigger
```

### 2. 暫停自動更新

```bash
curl -X POST http://localhost:3000/api/student-data-sync/stop
```

### 3. 恢復自動更新

```bash
curl -X POST http://localhost:3000/api/student-data-sync/start
```

### 4. 修改更新時間

**改為每天晚上 10:00**:
```bash
curl -X POST http://localhost:3000/api/student-data-sync/settings \
  -H "Content-Type: application/json" \
  -d '{"updateTime":"22:00"}'
```

## 📋 設定參數說明

| 參數 | 說明 | 預設值 | 範例 |
|------|------|--------|------|
| `enabled` | 是否啟用同步功能 | `true` | `true` / `false` |
| `autoUpdateEnabled` | 是否自動更新 | `true` | `true` / `false` |
| `updateTime` | 每日更新時間 | `"02:00"` | `"08:00"` |
| `intervalMinutes` | 間隔更新分鐘 | `0` | `60` = 每小時 |
| `retryMaxAttempts` | 失敗重試次數 | `3` | `5` |
| `retryDelaySeconds` | 重試間隔秒數 | `60` | `120` |
| `logUpdates` | 是否記錄日誌 | `true` | `true` / `false` |

## ⚠️ 常見問題

### Q1: 如何確認自動更新有在運作？

**A**: 查看系統狀態，確認 `hasSchedule: true`

```bash
curl http://localhost:3000/api/system-status | jq .data.studentDataSync.hasSchedule
# 應該回傳：true
```

### Q2: 想改變更新時間怎麼辦？

**A**: 使用 API 或編輯設定檔

```bash
# 使用 API（立即生效）
curl -X POST http://localhost:3000/api/student-data-sync/settings \
  -H "Content-Type: application/json" \
  -d '{"updateTime":"03:00"}'

# 或編輯 system-settings.json 後重啟
docker-compose restart
```

### Q3: 如何停用自動更新？

**A**: 有兩種方式

```bash
# 方式1：暫時停用（不改設定檔）
curl -X POST http://localhost:3000/api/student-data-sync/stop

# 方式2：永久停用（修改設定檔）
# 編輯 system-settings.json
# "autoUpdateEnabled": false
docker-compose restart
```

### Q4: 更新失敗了怎麼辦？

**A**: 系統會自動重試 3 次

**查看錯誤日誌**:
```bash
docker-compose logs | grep "失敗"
```

**手動重試**:
```bash
curl -X POST http://localhost:3000/api/student-data-sync/trigger
```

### Q5: 可以同時使用兩種更新方式嗎？

**A**: 可以！

```json
{
  "updateTime": "02:00",      // 每天凌晨 2:00
  "intervalMinutes": 360      // 每 6 小時
}
```

## 🎓 使用場景建議

### 場景 1：一般使用（推薦）

**設定**:
```json
{
  "updateTime": "02:00",
  "intervalMinutes": 0
}
```

**說明**: 每天凌晨 2:00 更新一次，適合大多數情況。

---

### 場景 2：頻繁更新

**設定**:
```json
{
  "updateTime": "02:00",
  "intervalMinutes": 180
}
```

**說明**: 
- 每天凌晨 2:00 更新
- 每 3 小時更新一次
- 適合學生資料經常變動的情況

---

### 場景 3：只在特定時間更新

**設定**:
```json
{
  "updateTime": "08:00",
  "intervalMinutes": 0
}
```

**說明**: 只在每天早上 8:00 更新一次。

---

### 場景 4：關閉自動更新

**設定**:
```json
{
  "autoUpdateEnabled": false
}
```

**說明**: 完全關閉自動更新，只能手動觸發。
