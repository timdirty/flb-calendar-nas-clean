## 🐛 常見問題排查

### Q1: Console 沒有顯示關鍵字數量？
**解決方案：**
1. 檢查 `student-filter.js` 是否正確載入
2. 硬刷新頁面（Ctrl+F5）清除快取
3. 檢查瀏覽器 Console 是否有錯誤訊息

### Q2: 修改關鍵字後學生篩選沒有變化？
**解決方案：**
1. 確認已點擊「儲存所有設定」
2. 檢查 Console 是否顯示「已清除特殊事件關鍵字快取」
3. 硬刷新頁面（Ctrl+F5）
4. 檢查 `localStorage` 快取是否已清除

### Q3: API 請求失敗？
**解決方案：**
1. 確認後端服務正在運行
2. 檢查 `/api/special-events-config` 端點是否可訪問
3. 查看後端日誌是否有錯誤訊息

### Q4: 學生篩選結果不正確？
**解決方案：**
1. 啟用調試模式：在 Admin Dashboard > 學生篩選規則 > 啟用詳細調試日誌
2. 查看 Console 詳細日誌
3. 確認關鍵字配置是否正確
4. 檢查學生資料中的時間格式
