# 🚨 時區問題最終診斷報告

## 嚴重問題發現！

### 問題位置
**`synology-calendar-client.js` Line 194**

### 問題描述

```javascript
// synology-calendar-client.js Line 182-194
const startDate = new Date(event.dtstart * 1000);  // dtstart 是 Unix timestamp
const endDate = new Date(event.dtend * 1000);

return {
    start: startDate.toISOString(),  // ❌ 問題在這裡！
    end: endDate.toISOString(),
    // ...
};
```

### 問題分析

1. **Synology API 返回的資料**：
   - `dtstart`: Unix timestamp (秒)
   - 例如：`dtstart = 1728630600`
   - 這是 **UTC 時間戳記**

2. **JavaScript 轉換**：
   ```javascript
   const startDate = new Date(1728630600 * 1000);
   // 假設這代表台灣時間 2025-10-11 16:10
   // 對應的 UTC 時間是 2025-10-11 08:10
   // 所以 startDate 內部儲存的是 UTC 2025-10-11 08:10
   ```

3. **toISOString() 輸出**：
   ```javascript
   startDate.toISOString()  // "2025-10-11T08:10:00.000Z"
   // 這是 UTC 時間！
   ```

4. **reminder-scheduler.js 的錯誤理解**：
   ```javascript
   // Line 891 的註釋
   // event.start 是台灣時間格式 ❌ 錯誤！
   const courseTimeStr = event.start;  // 實際是 UTC 時間！
   
   // Line 900
   const taiwanCourseTimeStr = `${year}-${month}-${day}T${hour}:${minute}:00+08:00`;
   // 這裡假設 hour:minute 是台灣時間，但實際是 UTC 時間！
   ```

### 實際影響

**範例：課程時間為台灣時間 16:10**

1. Synology 儲存：`dtstart = UTC 08:10 的 timestamp`
2. 轉換為 Date：`new Date(dtstart * 1000)` = UTC 08:10
3. 格式化：`toISOString()` = `"2025-10-11T08:10:00Z"`
4. reminder-scheduler 解析：
   ```javascript
   const [hour, minute] = "08:10:00Z".split(':')  // hour=08, minute=10
   // 誤以為是台灣時間 08:10
   const taiwanTimeStr = "2025-10-11T08:10:00+08:00"  // ❌ 錯誤！
   // 這代表台灣時間 08:10，UTC 00:10
   ```
5. **結果**：提醒時間錯了 8 小時！

## 解決方案

### 方案 A：修改 synology-calendar-client.js（推薦）

讓 `start` 和 `end` 欄位直接返回**台灣時間格式的字串**：

```javascript
// synology-calendar-client.js Line 179-212
parseEvents(events) {
    return events.map(event => {
        // Unix timestamp (UTC) 轉換為 Date 物件
        const startDate = new Date(event.dtstart * 1000);
        const endDate = new Date(event.dtend * 1000);
        
        // ✅ 轉換為台灣時區的格式化字串
        const startTaiwanStr = startDate.toLocaleString('sv-SE', { 
            timeZone: 'Asia/Taipei',
            year: 'numeric',
            month: '2-digit',
            day: '2-digit',
            hour: '2-digit',
            minute: '2-digit',
            second: '2-digit',
            hour12: false
        }).replace(' ', 'T');
        
        const endTaiwanStr = endDate.toLocaleString('sv-SE', { 
            timeZone: 'Asia/Taipei',
            year: 'numeric',
            month: '2-digit',
            day: '2-digit',
            hour: '2-digit',
            minute: '2-digit',
            second: '2-digit',
            hour12: false
        }).replace(' ', 'T');
        
        const summary = event.summary || '未命名事件';
        
        return {
            uid: event.ical_uid,
            evt_id: event.evt_id,
            summary: summary,
            title: summary,
            description: event.description || '',
            location: event.location_info?.name || '',
            start: startTaiwanStr,  // ✅ 現在是台灣時間格式："2025-10-11T16:10:00"
            end: endTaiwanStr,
            startDate: startDate,
            endDate: endDate,
            isAllDay: event.is_all_day || false,
            status: 'CONFIRMED',
            calendarId: event.cal_id,
            originalCalId: event.original_cal_id,
            color: event.color,
            timezone: event.tz_id || 'Asia/Taipei',  // 確保有時區資訊
            owner: event.owner_name,
            ownerId: event.owner_id,
            isRepeat: event.is_repeat_evt || false,
            participants: event.participant || [],
            attachments: event.attachments || []
        };
    });
}
```

**優點**：
- 統一所有地方使用台灣時間格式
- reminder-scheduler.js 的現有邏輯就正確了
- 前端顯示也會正確

**注意**：使用 `'sv-SE'` locale 和 `replace(' ', 'T')` 是為了得到 ISO 格式的時間字串（YYYY-MM-DDTHH:mm:ss），而不需要手動拼接。

### 方案 B：修改 reminder-scheduler.js（不推薦）

如果不修改 synology-calendar-client.js，就需要在 reminder-scheduler.js 中正確處理 UTC 時間：

```javascript

// 轉換為台灣時間的小時和分鐘

```

**缺點**：

### 測試案例

4. 課前提醒: `"2025-10-11T07:40:00.000Z"` (台灣 15:40 = UTC 07:40)
5. **顯示**: 台灣時間 15:40 ✅ **正確！**
