# 🧪 日曆點擊修復 v2 - 立即測試指南

## ⚠️ 測試前必做

```bash
# 1. 啟動服務（如果未運行）
docker-compose up -d

# 2. 等待 3 秒
sleep 3
```

然後在瀏覽器：
1. 訪問 http://localhost:3000
2. **按 Ctrl+Shift+R（Mac: Cmd+Shift+R）強制重新載入**
3. **按 F12 打開開發者工具**

## ✅ 快速檢查清單

### 階段 1：初始化檢查（30秒）

在 Console 中應該看到：
- [ ] `✅ 正在定義全域點擊處理函數...`
- [ ] `✅ 日曆視圖事件委派已設置完成`
- [ ] `window.scrollToDateCourses: function`
- [ ] `window.highlightEventCardFromCalendar: function`

❌ 如果看不到 → 清除快取重新載入（Ctrl+Shift+R）

### 階段 2：懸浮提示測試（1分鐘）

1. 切換到「本週」視圖
2. 將滑鼠懸停在**日曆方塊**上（等1-2秒）
   - [ ] 顯示：`10/19 - 1個課程\n10:00 SPIKE PRO 日 (Tim)`
3. 將滑鼠懸停在**課程方塊**上（黃色/粉色方塊）
   - [ ] 顯示：`📅 課程名稱\n⏰ 時間\n👨‍🏫 講師\n👆 點擊跳轉...`

❌ 如果看不到 → 可能是瀏覽器延遲，多等1-2秒

### 階段 3：點擊功能測試（2分鐘）

#### 測試 A：點擊日曆方塊（空白區域）

1. 點擊 10/19 的**空白區域**（不是課程方塊）
2. Console 應該顯示：
   - [ ] `🖱️ 點擊事件觸發: calendar-day DIV` 或類似
   - [ ] `🗓️ 點擊日曆方塊（事件委派）: 2025-10-19`
3. 頁面應該：
   - [ ] 滾動到下方的課程列表
   - [ ] 10/19 的課程被高亮

#### 測試 B：點擊課程方塊

1. 點擊 10/19 的**黃色 SPIKE 方塊**
2. Console 應該顯示：
   - [ ] `🖱️ 點擊事件觸發: time DIV` 或 `title DIV` 或 `event-chip DIV`
   - [ ] `🎯 點擊事件方塊（事件委派）: evt_...`
   - [ ] `🎯 高亮課程卡片（全域函數被調用）: evt_...`
3. 頁面應該：
   - [ ] 滾動到對應的課程卡片
   - [ ] 該課程卡片放大並發光
   - [ ] 其他課程卡片變暗

#### 測試 C：月視圖測試

1. 切換到「本月」視圖
2. 重複測試 A 和 B
3. 確認功能正常
