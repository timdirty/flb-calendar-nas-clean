- ✅ **啟動排程器** - 開始自動發送提醒
- ✅ **停止排程器** - 停止自動發送
- ✅ **查看狀態** - 實時顯示運行狀態

### ⚙️ 系統參數 (system-settings.json)
- ✅ **查看設定** - 顯示完整的系統配置

**資料位置**: `/system-settings.json`

## 🎯 使用場景

### 場景 1: 新增講師

```
1. 進入「講師管理」頁面
2. 點擊「新增講師」
3. 輸入講師姓名和 LINE User ID
4. 點擊「儲存變更」
```

### 場景 2: 設定管理員

```
1. 進入「管理員設定」頁面
2. 輸入管理員的 LINE User ID
3. 點擊「儲存」
4. 系統會立即更新
```

### 場景 3: 測試 LINE 通知

```
1. 進入「LINE 通知設定」頁面
2. 點擊「測試通知」
3. 管理員會收到測試訊息
```

### 場景 4: 管理排程器

```
1. 進入「排程器設定」頁面
2. 查看當前狀態
3. 使用「啟動」或「停止」按鈕控制
```

## ⚠️ 注意事項

### 📝 資料備份

- 修改 `teacher_data.json` 時會自動備份
- 備份檔案格式: `teacher_data.json.backup-{時間戳記}`
- 位於專案根目錄

### 🔒 權限要求

- 需要有檔案寫入權限
- 需要有環境變數讀取權限
- 需要有 LINE Bot 權限（測試通知）

### 🔄 重啟需求

以下設定修改後需要重啟服務：
- LINE Channel Token
- 行事曆連線資訊
- 環境變數相關設定

以下設定立即生效：
- 講師資料
- 管理員設定
- 排程器啟動/停止

## 🐛 故障排除

### Q1: 無法儲存講師資料

**解決方案**:
1. 檢查檔案權限
2. 確認 `/teacher_data.json` 可寫入
3. 查看 console 錯誤訊息

### Q2: 測試通知發送失敗

**解決方案**:
1. 確認已設定 LINE_CHANNEL_ACCESS_TOKEN
2. 確認已設定管理員 User ID
3. 檢查 TOKEN 是否有效

### Q3: 排程器無法啟動

**解決方案**:
1. 檢查系統健康狀態
2. 查看後端日誌
3. 確認行事曆連線正常

### Q4: 資料顯示不正確

**解決方案**:
1. 點擊「重新載入」按鈕
2. 清除瀏覽器快取
3. 檢查 API 回應格式
