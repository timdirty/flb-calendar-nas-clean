# 課程與學生匹配邏輯 - 統一架構說明

## 📅 建立日期
2025-10-19

## 🎯 目的
統一 `perfect-calendar-optimized-complete2.html`、`learning-record-upload.html` 和 `server.js` 的課程名稱提取和學生匹配邏輯，確保三者使用相同的邏輯，方便後續維護和更新。

---

## 📁 檔案結構

### 1. 共用模組
**檔案：** `public/js/course-student-matcher.js`

這是核心的共用模組，包含所有課程與學生匹配的邏輯。

#### 主要功能：

- ✅ **`extractCourseName(courseTitle)`**
  - 從完整的課程標題中提取課程代碼
  - 支持多種格式（見下方範例）
  
- ✅ **`findStudentsByCourse(courseName, studentData, options)`**
  - 根據課程名稱查找學生
  - 支持大小寫不敏感匹配
  - 可選是否包含剩餘堂數為0的學生
  
- ✅ **`matchStudentsByTitle(courseTitle, studentData, options)`**
  - 便利方法，結合上述兩個函數
  
- ✅ **`normalizeTimeFormat(timeStr)`**
  - 標準化時間格式用於比較
  
- ✅ **`isTimeMatch(studentPeriod, targetTime)`**
  - 智能時間匹配
  
- ✅ **`getAvailableCourses(studentData)`**
  - 取得所有可用的課程列表
  
- ✅ **`getCourseStats(courseName, studentData)`**
  - 取得課程統計資訊
  
- ✅ **`validateStudentMatch(student, courseName, targetTime)`**
  - 驗證學生是否匹配指定課程和時間

## 📖 課程名稱提取邏輯

### 支持的格式

| 課程標題 | 提取結果 | 說明 |
|---------|---------|------|
| `SPIKE — 1930-2100 客製化 第6週` | `SPIKE` | 使用 `—` 分隔符 |
| `SPM — 1930-2030 到府 第6週` | `SPM` | 使用 `—` 分隔符 |
| `BOOST 0930-1100` | `BOOST` | 提取開頭的大寫字母 |
| `Minecraft 0840-0920` | `MINECRAFT` | 轉換為大寫 |
| `ESM 1600-1700` | `ESM` | 短課程代碼 |
| `Scratch 1100-1300` | `SCRATCH` | 轉換為大寫 |
| `龍華 製程專題製作` | `龍華` | 使用空格分隔 |

### 提取規則

1. **優先處理 `—` 分隔符**
   - 如果標題包含 `—`，取分隔符前的部分
   
2. **正則提取大寫字母**
   - 使用 `/^([A-Z]+)/i` 提取開頭的連續字母
   - 轉換為大寫
   
3. **空格分隔**
   - 如果前兩種方法都失敗，使用空格分隔的第一個單詞

## 🔗 整合方式

### 1. perfect-calendar-optimized-complete2.html

```html
<!-- 在 <head> 中引入 -->
<script src="/js/course-student-matcher.js"></script>
```

```javascript
// 更新 parseCourseType 函數
function parseCourseType(title) {
    if (!title) return 'UNKNOWN';
    
    // 使用共用模組
    if (window.CourseStudentMatcher) {
        const courseName = window.CourseStudentMatcher.extractCourseName(title);
        return courseName || 'UNKNOWN';
    }
    
    // 備用邏輯...
}
```

### 2. learning-record-upload.html

```html
<!-- 在 <head> 中引入 -->
<script src="/js/course-student-matcher.js"></script>
```

```javascript
// 更新 parseCourseTitle 函數
function parseCourseTitle(title) {
    if (!title) return { courseName: '', period: '', raw: '' };
    
    // 使用共用模組
    const courseName = window.CourseStudentMatcher 
        ? window.CourseStudentMatcher.extractCourseName(title)
        : title.split(' ')[0] || '';
    
    // ... 其他邏輯
}
```

### 3. server.js

```javascript
// 在 API 處理函數中引入模組
const CourseStudentMatcher = require('./public/js/course-student-matcher.js');

// 使用共用模組提取課程名稱
const courseName = CourseStudentMatcher.extractCourseName(courseTitle);

// 使用共用模組查找學生
const students = CourseStudentMatcher.findStudentsByCourse(courseName, studentData, {
    includeZeroRemaining: true
});
```

## 📝 注意事項

1. **大小寫處理**
   - 學生匹配使用大小寫不敏感比較
   - `Minecraft` 和 `MINECRAFT` 都可以正確匹配

2. **剩餘堂數**
   - 預設包含剩餘堂數為0的學生
   - 可透過 `options.includeZeroRemaining` 控制

3. **模組相容性**
   - 支持瀏覽器環境（掛載到 `window`）
   - 支持 Node.js 環境（CommonJS 導出）

4. **錯誤處理**
   - 所有函數都有完整的錯誤處理
   - 會在 console 輸出詳細的診斷資訊

## 📞 疑難排解

### 問題：找不到學生

1. 檢查課程名稱是否正確提取
   ```javascript
   console.log(CourseStudentMatcher.extractCourseName('課程標題'));
   ```

2. 檢查 student_data.json 中的課程名稱
   ```javascript
   console.log(CourseStudentMatcher.getAvailableCourses(studentData));
   ```

3. 檢查匹配邏輯
   ```javascript
   console.log(CourseStudentMatcher.matchStudentsByTitle('課程標題', studentData));
   ```

### 問題：模組未載入

1. 確認檔案路徑正確
   - 前端：`/js/course-student-matcher.js`
   - 後端：`./public/js/course-student-matcher.js`

2. 檢查 CSP (Content Security Policy)
   - 確認允許載入本地 script

3. 查看瀏覽器 Console
   - 應該顯示 "✅ CourseStudentMatcher v1.0.0 已載入"
