**修復日期**: 2025-10-19  
**版本**: v1.1.0  
**影響範圍**: 學習歷程上傳系統、課程學生匹配邏輯

## 🐛 問題描述

### 症狀
- **SPIKE PRO** 課程顯示 **25 位學生**（❌ 錯誤）
- 實際只有 **2 位學生**（陳杰睿、顏世餘）
- 簽到系統顯示正確，但學習歷程上傳頁面顯示錯誤

### 根本原因
課程名稱提取邏輯錯誤：
```javascript
// ❌ 舊邏輯（錯誤）
const match = courseTitle.match(/^([A-Z]+)/i);
// "SPIKE PRO 日 10:00-12:00" → 只提取到 "SPIKE"
```

因為正則表達式 `/^([A-Z]+)/i` 只匹配**連續的大寫字母**，遇到空格就停止。

結果：
- `SPIKE PRO` 被誤識別為 `SPIKE`
- 匹配到所有 `course: "SPIKE"` 的學生（25位）
- 而不是只匹配 `course: "SPIKE PRO"` 的學生（2位）

---

## ✅ 修復方案

### 1. 更新正則表達式

**修改檔案**: `public/js/course-student-matcher.js`

```javascript
// ✅ 新邏輯（正確）
const match = courseTitle.match(/^([A-Z]+(?:\s+[A-Z]+)*)/i);
// "SPIKE PRO 日 10:00-12:00" → 正確提取到 "SPIKE PRO"
```

**正則表達式解析**:
- `^([A-Z]+(?:\s+[A-Z]+)*)` 
  - `[A-Z]+`: 第一個大寫單詞
  - `(?:\s+[A-Z]+)*`: 可選的「空格 + 大寫單詞」（可重複）
  - 這樣可以匹配：`SPIKE`、`SPIKE PRO`、`SPIKE ADVANCED` 等

### 2. 測試案例

| 課程標題 | 提取結果 |
|---------|---------|
| `SPIKE 日 10:00-12:00` | `SPIKE` ✅ |
| `SPIKE PRO 日 10:00-12:00` | `SPIKE PRO` ✅ |
| `SPIKE ADVANCED 日 10:00-12:00` | `SPIKE ADVANCED` ✅ |
| `SPM 日 13:30-15:00` | `SPM` ✅ |
| `龍華 製程專題製作` | `龍華` ✅ |

## ⚠️ 注意事項

### student_data.json 格式要求
確保學生資料中的 `course` 欄位與課程名稱一致：

```json
{
  "students": [
    {
      "name": "陳杰睿",
      "course": "SPIKE PRO",  // ✅ 必須與提取的課程名稱一致
      "period": "日 1000-1200",
      "remaining": 13
    },
    {
      "name": "顏世餘",
      "course": "SPIKE PRO",  // ✅ 必須與提取的課程名稱一致
      "period": "日 1000-1200",
      "remaining": 13
    }
  ]
}
```

### 如果還是顯示錯誤
1. **檢查 course 欄位**：
   ```bash
   cat /volume1/docker/flb-calendar/data/student_data.json | grep -A 5 "陳杰睿"
   ```
   確認 `course` 是 `"SPIKE PRO"` 而不是 `"SPIKE"`

2. **檢查 period 欄位**：
   確認時段格式正確：`"日 1000-1200"` 或 `"日 10:00-12:00"`

3. **查看後端日誌**：
   ```bash
   pm2 logs flb-calendar --lines 100 | grep "SPIKE PRO"
   ```
