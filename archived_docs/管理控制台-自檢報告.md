## 🚀 使用指南

### 快速開始

1. **訪問管理控制台**
   ```
   https://calendar.funlearnbar.synology.me/admin-dashboard.html
   ```

2. **首次設定**
   - 進入「系統配置」分頁
   - 檢查並調整 API 端點
   - 設定緩存時間
   - 選擇預設檢視模式
   - 點擊「儲存所有系統配置」

3. **設定管理員**
   - 進入「通知設定」分頁
   - 輸入管理員 LINE User ID
   - 點擊「設定管理員」

4. **管理講師**
   - 進入「講師管理」分頁
   - 查看現有講師列表
   - 使用「新增講師」按鈕添加新講師
   - 設定每位講師的專屬顏色

5. **管理學生**
   - 進入「學生管理」分頁
   - 使用「從 Google Sheets 同步」快速匯入學生
   - 或手動新增學生資料

6. **配置通知**
   - 進入「通知設定」分頁
   - 設定提醒時間
   - 自訂通知訊息模板
   - 使用「測試通知」驗證功能

7. **設定 Google API**
   - 進入「Google API」分頁
   - 填入 Google Sheets API URL
   - 使用「測試 API」驗證連接

8. **備份配置**
   - 進入「匯入/匯出」分頁
   - 點擊「匯出所有配置」
   - 保存 JSON 文件作為備份

### 常用操作

#### 清除緩存
```
緩存管理 → 選擇要清除的緩存類型 → 確認
```

#### 查看日誌
```
系統日誌 → 選擇日誌級別 → 使用搜尋框篩選
```

#### 匯入配置
```
匯入/匯出 → 選擇 JSON 文件 → 預覽 → 確認匯入
```

#### 編輯 JSON
```
匯入/匯出 → JSON 編輯器 → 載入當前配置 → 編輯 → 儲存
```

```json

    {
      "name": "Andy",
```

## 📞 技術支援

### 常見問題

**Q: 為什麼我的配置沒有保存？**
A: 檢查瀏覽器是否允許 localStorage，並確保點擊了「儲存」按鈕。

**Q: API 調用失敗怎麼辦？**
A: 檢查網路連接，確認後端服務正在運行，查看瀏覽器控制台的錯誤訊息。

**Q: 如何恢復預設配置？**
A: 進入「系統配置」→「恢復預設值」，或清除瀏覽器 localStorage。

**Q: 匯入配置後沒有變化？**
A: 確認 JSON 格式正確，並在匯入後重新載入頁面。

### 錯誤排查

1. **打開瀏覽器控制台**（F12）
2. **查看 Console 標籤**中的錯誤訊息
3. **查看 Network 標籤**檢查 API 請求狀態
4. **查看 Application 標籤** → **Local Storage** 檢查儲存的數據
