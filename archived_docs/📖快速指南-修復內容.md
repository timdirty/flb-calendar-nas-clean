## 🐛 常見問題

### Q: 為什麼還是看到錯誤？
A: 請清除瀏覽器快取（Ctrl+Shift+R 或 Cmd+Shift+R）

### Q: 顏色沒有顯示？
A: 檢查：
1. teacher_data.json 是否存在且格式正確
2. 課程顏色 API 是否可以訪問
3. 控制台是否有載入失敗的訊息

### Q: 篩選功能沒反應？
A: 檢查：
1. 控制台是否有 JavaScript 錯誤
2. 是否有課程資料
3. 選擇的條件是否有符合的課程

### Q: 手機上還是看到日曆視圖？
A: 這是快取問題，請：
1. 清除瀏覽器快取
2. 或使用無痕模式測試
