# 🔥 後端時區修復方案 - reminder-scheduler.js

## 問題診斷

### 嚴重問題發現 ⚠️

在 `reminder-scheduler.js` 中，所有提醒的 `scheduledTime` 都**錯誤地計算了時區**：

#### 問題 1: 當日提醒時間 (Line 876)
```javascript
// ❌ 錯誤：手動減 8 小時
const utcTime = new Date(Date.UTC(year, month - 1, day, todayReminderHour - 8, todayReminderMinute, 0));
scheduledTime = utcTime.toISOString();

// 範例：台灣時間 2025-10-11 08:00
// 錯誤計算：Date.UTC(2025, 9, 11, 8-8, 0) = 2025-10-11T00:00:00Z
// 前端顯示：會再加 8 小時 = 2025-10-11 08:00 ❌
// 實際應該：2025-10-11T00:00:00Z 對應台灣時間 08:00 ✅
```

#### 問題 2: 課前提醒時間 (Line 895)
```javascript
// ❌ 錯誤：手動減 8 小時
const courseTimeUTC = new Date(Date.UTC(year, month - 1, day, hour - 8, minute, 0));

// 範例：課程時間 2025-10-11 16:10 (台灣時間)
// 錯誤計算：Date.UTC(2025, 9, 11, 16-8, 10) = 2025-10-11T08:10:00Z
// 對應台灣時間：16:10 ✅（這個恰好對了）
// 但課前提醒（提前 30 分鐘）：08:10 - 30 = 07:40 UTC
// 顯示時間：07:40 UTC + 8 = 15:40 台灣時間 ❌ (應該是 15:40)
```

#### 問題 3: 隔日提醒時間 (Line 921)
```javascript
// ❌ 錯誤：手動減 8 小時
const utcTime = new Date(Date.UTC(..., tomorrowReminderHour - 8, tomorrowReminderMinute, 0, 0));

// 範例：台灣時間 19:30
// 錯誤計算：Date.UTC(..., 19-8, 30) = 11:30 UTC
// 對應台灣時間：19:30 ✅（這個也恰好對了）
```

---

## 根本原因

### 錯誤的做法
```javascript
// ❌ 試圖手動轉換時區：台灣時間 - 8 小時 = UTC
const utcTime = new Date(Date.UTC(year, month - 1, day, hour - 8, minute, 0));
```

**問題**：
1. `Date.UTC()` 本身就是創建 UTC 時間
2. 減 8 小時是錯誤的，因為參數應該是目標時區的時間
3. 當 `hour - 8 < 0` 時，會跨日，導致日期錯誤

### 正確的做法

#### 方法 A: 使用時區字串（推薦）
```javascript
// ✅ 明確指定台灣時區
const taiwanTimeStr = `${year}-${month.toString().padStart(2, '0')}-${day.toString().padStart(2, '0')}T${hour.toString().padStart(2, '0')}:${minute.toString().padStart(2, '0')}:00+08:00`;
const scheduledTime = new Date(taiwanTimeStr).toISOString();
```

#### 方法 B: 手動計算偏移（更可靠）
```javascript
// ✅ 正確的UTC轉換
// 台灣時間的 hour:minute 對應的 UTC 時間
const utcHour = (hour - 8 + 24) % 24;
const needsPreviousDay = hour < 8;

let utcYear = year, utcMonth = month - 1, utcDay = day;
if (needsPreviousDay) {
    const tempDate = new Date(year, month - 1, day);
    tempDate.setDate(tempDate.getDate() - 1);
    utcYear = tempDate.getFullYear();
    utcMonth = tempDate.getMonth();
    utcDay = tempDate.getDate();
}

const utcTime = new Date(Date.UTC(utcYear, utcMonth, utcDay, utcHour, minute, 0));
const scheduledTime = utcTime.toISOString();
```

### 修復 2: 課前提醒 (Line 882-905)

```javascript
// 課前提醒：課程時間前30分鐘（可從設定檔讀取）
const beforeClassMinutes = this.systemSettings?.reminders?.beforeClassMinutes || 30;

// event.start 是台灣時間格式，需要正確轉換為 UTC
const courseTimeStr = event.start;

// 解析台灣時間
const [datePart, timePart] = courseTimeStr.split('T');
const [year, month, day] = datePart.split('-').map(Number);
const [hour, minute] = timePart.split(':').map(Number);

// ✅ 正確方法：創建台灣時間字串並轉換
const taiwanCourseTimeStr = `${year}-${month.toString().padStart(2, '0')}-${day.toString().padStart(2, '0')}T${hour.toString().padStart(2, '0')}:${minute.toString().padStart(2, '0')}:00+08:00`;
const courseTimeUTC = new Date(taiwanCourseTimeStr);

// 計算課前提醒時間（提前指定分鐘）
const beforeClassTime = new Date(courseTimeUTC.getTime() - (beforeClassMinutes * 60 * 1000));
scheduledTime = beforeClassTime.toISOString();

console.log(`⏰ 創建課前提醒: ${event.title} - ${event.instructor}`);
console.log(`   課程時間 (台灣): ${taiwanCourseTimeStr}`);
console.log(`   課程時間 (UTC): ${courseTimeUTC.toISOString()}`);
console.log(`   課前提醒時間 (UTC): ${scheduledTime}`);
console.log(`   課前提醒時間 (台灣): ${beforeClassTime.toLocaleString('zh-TW', {timeZone: 'Asia/Taipei'})} (提前${beforeClassMinutes}分鐘)`);
```

修復後（正確）：

### 案例 2: 課前提醒
```
課程：2025-10-11 16:10 (台灣時間)
課前提醒：30 分鐘前

修復前（錯誤）：
- 課程時間 UTC: 2025-10-11T08:10:00Z (16-8=8)
- 課前提醒 UTC: 2025-10-11T07:40:00Z (08:10 - 30分鐘)
- 顯示：2025-10-11 15:40 (台灣時間)
- 結果：錯誤！應該是 15:40，但計算過程錯誤

修復後（正確）：
- 課程時間 UTC: 2025-10-11T08:10:00Z (正確轉換)
- 課前提醒 UTC: 2025-10-11T07:40:00Z
- 顯示：2025-10-11 15:40 (台灣時間)
- 結果：正確
```

### 案例 3: 跨日情況（最容易出錯）
```
課程：2025-10-12 02:00 (台灣時間，凌晨2點)
課前提醒：30 分鐘前 = 01:30

修復前（錯誤）：
- 課程時間計算: Date.UTC(2025, 9, 12, 2-8, 0) = Date.UTC(2025, 9, 12, -6, 0)
- 結果：2025-10-11T18:00:00Z (自動跨日，但日期錯誤)
- 顯示：2025-10-12 02:00 (看起來對，但UTC時間錯了)
- 課前提醒：2025-10-11T17:30:00Z
- 顯示：2025-10-12 01:30 ❌ 錯誤！

修復後（正確）：
- 課程時間字串: "2025-10-12T02:00:00+08:00"
- 課程時間 UTC: 2025-10-11T18:00:00Z ✅
- 課前提醒 UTC: 2025-10-11T17:30:00Z ✅
- 顯示：2025-10-12 01:30 (台灣時間) ✅ 正確！
```

### 影響
- 所有新創建的提醒將使用正確的台灣時間
- 舊的提醒可能仍有錯誤的時間（需要重新生成）
- 建議部署後清除舊提醒，讓系統重新生成
