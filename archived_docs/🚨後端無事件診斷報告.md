## 🔍 可能原因分析

### 1. CalDAV 連線問題
- CalDAV 客戶端初始化失敗
- CalDAV 登入失敗（帳號/密碼錯誤）
- Synology Calendar API 連線逾時

### 2. 權限問題
- CalDAV 帳號沒有讀取行事曆的權限
- 行事曆共享設定有變更

### 3. 日期範圍問題
- 查詢的日期範圍沒有事件
- 時區設定導致日期錯誤

### 4. API 變更
- Synology Calendar API 格式有變更
- API endpoint 變更

## 💡 補充說明

### 為什麼講師 API 正常但事件為 0？

講師資料來自本地檔案 `teacher_data.json`，不依賴 CalDAV。
事件資料必須從 Synology Calendar 透過 CalDAV API 抓取。

因此：
- ✅ 講師 API 正常 → 後端本身沒問題
- ❌ 事件為 0 → CalDAV 連線或資料查詢有問題

### 之前為什麼會有資料？

如果之前可以正常抓到事件，可能的變化：
1. Synology Calendar 服務重啟或更新
2. 網路設定變更
3. 帳號權限變更
4. Docker 容器完全重建後環境變數遺失
