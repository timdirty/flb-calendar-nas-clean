# 🎨 系統設定使用指南

## 📋 概述

全新的**系統設定介面**整合了所有設定功能，採用 Meta 設計系統風格，提供現代化、直觀的使用體驗。

## 🌐 訪問方式

1. **直接訪問**：`https://calendar.funlearnbar.synology.me/系統設定.html`
2. **從管理頁面**：點擊右上角的「系統設定」按鈕

## 🔧 功能模塊

### 1. 管理員設定 👨‍💼
- **設定管理員 LINE User ID**
- 管理員將收到所有系統通知：
  - 學生簽到通知
  - 講師報表通知
  - 課程提醒通知
- 可查看當前管理員資訊

### 2. LINE 通知設定 💬
- **配置 LINE Bot 憑證**：
  - Channel Access Token
  - Channel Secret
- **測試模式**：
  - 開啟後僅發送給測試用戶
  - 適合開發和測試階段
- **安全提示**：憑證輸入框使用密碼模式保護

### 3. 行事曆設定 📅
- **Synology Calendar 連線**：
  - Calendar API URL
  - 用戶名稱和密碼
  - 行事曆 ID
- **測試連線**：一鍵測試配置是否正確
- **注意**：修改後需要重啟 Docker 服務

### 4. 提醒設定 ⏰
- **當日提醒時間**：設定每天提醒的時間（小時和分鐘）
- **隔日提醒時間**：設定明日課程提醒的時間
- **課前提醒**：設定課程開始前多少分鐘提醒（5-120分鐘）
- 所有時間使用台灣時區（UTC+8）

### 5. 排程器設定 ⚡
- **即時狀態**：
  - 運行中 / 已停止
  - 上次執行時間
- **統計資訊**：
  - 總提醒數
  - 待發送數量
  - 已發送數量
- **控制操作**：
  - 啟動排程器
  - 停止排程器
  - 刷新狀態（每30秒自動刷新）

### 6. 系統參數 🔍
- **系統資訊**：
  - 版本號
  - 容器狀態
  - API 基礎 URL
- **健康檢查**：一鍵檢查系統運行狀態

## 🎨 設計特色

### Meta 設計系統
- **配色**：Meta 藍（#0866FF）主題色
- **灰階系統**：9 級灰階，細膩的層次感
- **陰影**：4 級陰影系統，營造深度感

### 用戶體驗
- **側邊欄導航**：固定左側，方便快速切換
- **實時通知**：右上角滑入式通知提示
- **響應式設計**：支援桌面和移動設備
- **狀態徽章**：直觀顯示運行狀態

### 交互細節
- **按鈕懸停效果**：微妙的陰影和顏色變化
- **表單驗證**：即時反饋，友好的錯誤提示
- **載入狀態**：優雅的旋轉動畫
- **切換開關**：平滑的 iOS 風格開關

## 📝 使用流程

### 初次設定
1. 設定管理員 User ID
2. 配置 LINE Bot 憑證
3. 設定 Synology Calendar 連線
4. 調整提醒時間參數
5. 啟動排程器

### 日常維護
1. 檢查排程器狀態
2. 查看提醒統計
3. 執行系統健康檢查
4. 根據需要調整參數

## ⚠️ 重要提示

### 需要重啟的修改
以下設定修改後**需要重啟 Docker 服務**才能生效：
- LINE Bot 憑證
- Synology Calendar 連線參數

### 重啟命令
```bash
cd /volume1/homes/ctctim14/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas
sudo docker-compose restart
```

### 不需重啟的修改
以下設定**立即生效**，無需重啟：
- 管理員設定
- 提醒時間參數
- 排程器啟動/停止

## 🔐 安全建議

1. **定期更換密碼**：建議每季度更換 Calendar 密碼
2. **保護 Token**：不要將 LINE Channel Token 分享給他人
3. **測試模式**：生產環境請關閉測試模式
4. **備份設定**：系統會自動備份，建議也手動備份重要配置

## 📞 支援

如遇問題，請：
1. 先執行「系統健康檢查」
2. 查看日誌：`sudo docker logs flb-calendar-nas`
