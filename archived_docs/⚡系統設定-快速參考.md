## 🔥 新增 API 端點

### 系統設定 API
```javascript
// 讀取系統設定
GET /api/system-settings

// 更新系統設定
POST /api/system-settings
{
  "scheduler": {...},
  "reminders": {...},
  ...
}
```

### 行事曆配置 API
```javascript
// 更新行事曆設定
POST /api/calendar-config
{
  "baseUrl": "https://...",
  "username": "...",
  "password": "...",
  "calendarId": "..."
}
```

### 提醒配置 API
```javascript
// 更新提醒設定
POST /api/reminder-config
{
  "todayReminderHour": 8,
  "todayReminderMinute": 0,
  "tomorrowReminderHour": 19,
  "tomorrowReminderMinute": 30,
  "beforeClassMinutes": 30
}
```

## ⚙️ 設定項目詳解

### 1. 管理員設定
```
輸入項：LINE User ID
效果：立即生效
重啟：不需要
```

### 2. LINE 通知設定
```
輸入項：
  - Channel Access Token
  - Channel Secret
  - 測試模式開關
  - 測試用戶 ID

效果：寫入 .env.nas
重啟：需要重啟 Docker
```

### 3. 行事曆設定
```
輸入項：
  - Calendar URL
  - 用戶名稱
  - 密碼
  - 行事曆 ID

效果：寫入 .env.nas
重啟：需要重啟 Docker
測試：可測試連線
```

### 4. 提醒設定
```
輸入項：
  - 當日提醒時間（時、分）
  - 隔日提醒時間（時、分）
  - 課前提醒（分鐘）

效果：立即生效
重啟：不需要
```

### 5. 排程器設定
```
功能：
  - 啟動排程器
  - 停止排程器
  - 查看狀態
  - 統計資料

刷新：自動每 30 秒
手動：點擊刷新按鈕
```

### 6. 系統參數
```
顯示：
  - 系統版本
  - 容器狀態
  - API 基礎 URL

功能：
  - 系統健康檢查
  - 返回管理頁面
```

## 🚀 快速操作

### 初次設定流程
```
1. 設定管理員 User ID
   ↓
2. 配置 LINE Bot 憑證
   ↓
3. 重啟 Docker 服務
   ↓
4. 設定行事曆連線
   ↓
5. 測試連線
   ↓
6. 重啟 Docker 服務
   ↓
7. 調整提醒時間
   ↓
8. 啟動排程器
   ↓
9. 完成！
```

### 修改 LINE 設定
```bash
# 1. 在網頁上修改設定
# 2. 重啟服務
cd /volume1/homes/ctctim14/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas
sudo docker-compose restart

# 3. 等待 30 秒
# 4. 驗證設定
```

### 調整提醒時間
```
# 在網頁上直接修改即可，無需重啟
1. 進入「提醒設定」
2. 修改時間
3. 點擊「儲存設定」
4. 立即生效
```

### 控制排程器
```
# 網頁操作
1. 進入「排程器設定」
2. 點擊「啟動排程器」或「停止排程器」
3. 等待幾秒鐘
4. 查看狀態變化
```

## 🔧 故障排除

### 頁面無法訪問
```bash
# 檢查容器狀態
sudo docker ps | grep flb-calendar-nas

# 查看日誌
sudo docker logs flb-calendar-nas --tail 50

# 重啟服務
sudo docker-compose restart
```

### API 無響應
```bash
# 測試 API
curl http://localhost:3000/api/health

# 如果失敗，檢查 server.js 是否正確部署
sudo docker exec flb-calendar-nas ls -la /app/server.js
```

### 設定不生效
```bash
# 檢查設定檔案
sudo docker exec flb-calendar-nas cat /app/system-settings.json

# 檢查環境變數
sudo docker exec flb-calendar-nas printenv | grep -E "LINE|CALDAV"
```
