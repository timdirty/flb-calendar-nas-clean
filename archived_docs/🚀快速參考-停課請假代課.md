# 🚀 快速參考 - 停課/請假/代課

## ⚡ 一頁速查

### 📌 停課

```
✅ 做法: 在課程標題加上「停課」
   例: SPM 六 0930-1100 → SPM 六 0930-1100 停課

✅ 結果: 系統自動跳過，不發送提醒
```

---

### 📌 請假

```
✅ 做法 A: 在課程標題加上「請假」
   例: ESM 一 1530-1700 → ESM 一 1530-1700 請假

✅ 做法 B: 直接刪除 CalDAV 課程

✅ 結果: 系統自動跳過，不發送提醒
```

---

### 📌 代課 ⭐ 重要

```
❌ 錯誤: 只改標題
   SPM 六 0930-1100 代課
   (講師欄位仍是原講師)
   → 提醒會發給原講師 ❌

✅ 正確: 修改講師欄位
   1. 編輯課程
   2. 講師: 王老師 → 李老師
   3. 儲存
   → 提醒會發給李老師 ✅
```

---

### 📌 學生請假

```
✅ 做法: 在 Google Sheets 標記請假
   present = false 或 "leave"

✅ 結果: 
   - 系統每 5 分鐘更新
   - 生成時自動跳過
   - 發送前二次驗證
   - 自動標記為「已取消」
```

---

## 🔧 系統跳過關鍵字

```json
[
  "停課",
  "請假", 
  "取消",
  "暫停"
]
```

**注意**：「代課」不在清單中！需要修改講師欄位！

---

## ⏰ 已創建提醒怎麼辦？

### 方案 A：手動刪除（立即生效）
```
1. 前往提醒管理介面
2. 找到提醒
3. 點擊「刪除」🗑️
```

### 方案 B：等午夜清理（次日生效）
```
1. 修改 CalDAV 加上「停課」
2. 等待 00:00 午夜清理
3. 系統重新創建提醒時會跳過
```

---

## 📊 快速檢查指令

### 查看跳過的提醒
```bash
tail -f server.log | grep "跳過"
```

### 查看提醒的講師
```bash
cat reminders.json | jq '.reminders[] | {teacherName, courseName}'
```

### 查看學生請假狀態
```bash
cat public/student_data.json | jq '.students[] | select(.name == "學生姓名") | .attendance'
```

## ✅ 記住三件事

1. **停課/請假** → 標題加關鍵字或刪除課程 ✅
2. **代課** → 必須改講師欄位，不能只改標題 ⭐
3. **學生請假** → Google Sheets 標記，系統自動處理 ✅
