
## 🚀 使用方式

### 1. 訪問頁面

```
http://localhost:3000/系統設定管理.html
```

### 2. 管理講師資料

1. 點擊側邊欄「講師管理」
2. 可以新增、編輯、刪除講師
3. 點擊「儲存變更」保存到 `teacher_data.json`

### 3. 查看講師列表

1. 點擊側邊欄「講師列表」
2. 查看從 `teacher_list_data.csv` 讀取的資料

### 4. 設定管理員

1. 點擊側邊欄「管理員設定」
2. 輸入 LINE User ID
3. 點擊「儲存」

### 5. 測試功能

- **LINE 通知**: 點擊「測試通知」
- **行事曆連線**: 點擊「測試連線」
- **排程器**: 使用啟動/停止按鈕
