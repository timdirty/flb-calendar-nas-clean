## ⏭️ 請假/停課跳過機制

### 🎯 雙重檢查機制

#### **檢查 1：行事曆標題關鍵字**

**位置**：`generateStudentReminders()` (第 1666 行)

```javascript
// 檢查是否包含跳過關鍵字
const skipKeywords = this.systemSettings?.skipKeywords?.keywords || ['停課', '請假'];
const skipEnabled = this.systemSettings?.skipKeywords?.enabled !== false;

if (skipEnabled && skipKeywords.length > 0) {
    const hasSkipKeyword = skipKeywords.some(keyword => event.title.includes(keyword));
    
    if (hasSkipKeyword) {
        console.log(`⏭️ 跳過學生提醒 - 行事曆標題包含跳過關鍵字: ${event.title}`);
        continue; // ✅ 跳過此事件，不創建任何學生提醒
    }
}
```

**例如**：
- ❌ `"ESM 六 9:30-10:30 到府 第4週請假"` → 跳過
- ❌ `"SPIKE 五 16:10-17:40 停課"` → 跳過
- ✅ `"SPIKE 五 16:10-17:40 第5週"` → 創建提醒

## 🔧 問題排查

### Q1: 學生請假了，但還是收到提醒？

**檢查清單**：
1. ✅ 確認 Google Sheets 中的請假記錄是否正確
2. ✅ 確認 `student_data.json` 是否已更新（查看 `lastUpdated` 時間戳）
3. ✅ 確認排程器是否正常運行
4. ✅ 查看日誌：`⏭️ 跳過學生提醒` 或 `❌ 學生請假，跳過`

**解決方案**：
```bash
# 手動觸發更新學生資料
curl -X POST http://localhost:3000/api/update-student-data

# 查看日誌
tail -f server.log | grep "請假\|跳過"
```

---

### Q2: 行事曆標題有「請假」，但學生還是收到提醒？

**檢查清單**：
1. ✅ 確認 `system-settings.json` 中 `skipKeywords.enabled` 是否為 `true`
2. ✅ 確認關鍵字列表是否包含「請假」
3. ✅ 查看日誌是否有 `⏭️ 跳過學生提醒` 訊息

**解決方案**：
```json
// system-settings.json
{
  "skipKeywords": {
    "enabled": true,  // ✅ 確保啟用
    "keywords": ["停課", "請假"]  // ✅ 確保包含關鍵字
  }
}
```
