## 🎯 配色建議

### 建議 1：色相差異要大

```
✅ 好的組合（易區分）
講師A → 櫻花粉（粉色）
講師B → 天空藍（藍色）
講師C → 檸檬黃（黃色）
講師D → 薄荷綠（綠色）

❌ 不好的組合（難區分）
講師A → 櫻花粉
講師B → 蜜桃粉
講師C → 玫瑰粉
（全部是粉色，難以區分）
```

### 建議 2：使用對比色

```
色輪對比色配對：
紅/橙 ↔ 藍/綠
黃 ↔ 紫
粉 ↔ 綠

範例：
如果講師A用「珊瑚橙」
建議講師B用「薄荷藍」
（形成強烈對比，易辨識）
```

### 建議 3：依課程類型分組

```
📘 STEM課程組 → 藍色系
   - 數學：天空藍
   - 程式：寶石藍
   - 科學：薄荷藍

🎨 藝術課程組 → 暖色系
   - 美術：玫瑰粉
   - 音樂：檸檬黃
   - 舞蹈：珊瑚橙

🌱 運動課程組 → 綠色系
   - 球類：薄荷綠
   - 游泳：冰晶藍
   - 跑步：鮮嫩綠
```

### 建議 4：季節性配色

```
🌸 春季主題
櫻花粉、薄荷綠、青檸綠、蜜桃粉

☀️ 夏季主題
陽光黃、薄荷藍、西瓜紅、冰晶藍

🍂 秋季主題
蜜橙色、琥珀黃、柿子橙、玫瑰金

❄️ 冬季主題
冰晶藍、薰衣草、灰藍色、薄荷奶綠
```

## 💡 使用小秘訣

### 秘訣 1：先選主色
```
1. 找出3-5位最常出現的講師
2. 為他們選擇最鮮明、易辨的顏色
3. 其他講師使用次要顏色
```

### 秘訣 2：建立色彩規則
```
例如：
• 所有主任級講師 → 深色系（專業）
• 所有年輕講師 → 亮色系（活力）
• 所有資深講師 → 暖色系（溫暖）
```

### 秘訣 3：定期調整
```
• 每季更換主題色
• 根據課程變化調整
• 聽取講師和學生的反饋
```

### 秘訣 4：保存配色方案
```
記錄下成功的配色組合：
方案A（春季）：櫻花粉、薄荷綠、天空藍...
方案B（夏季）：西瓜紅、冰晶藍、檸檬黃...
方案C（秋季）：蜜橙色、森林綠、琥珀黃...
```
