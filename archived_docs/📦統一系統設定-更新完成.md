## ⚠️ 重要提示

### 需要重啟的設定
以下設定修改後**必須重啟 Docker 服務**：
- LINE Bot Channel Access Token
- LINE Bot Channel Secret
- Synology Calendar URL
- Synology Calendar 用戶名稱
- Synology Calendar 密碼

**重啟命令**:
```bash
cd /volume1/homes/ctctim14/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas
sudo docker-compose restart
```

### 立即生效的設定
以下設定**立即生效**，無需重啟：
- 管理員 User ID
- 提醒時間參數（當日/隔日/課前）
- 排程器啟動/停止
