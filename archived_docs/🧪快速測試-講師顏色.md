cd /Users/apple/Library/CloudStorage/SynologyDrive-FLBTim/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas

## 🎯 測試步驟

### 步驟 1：測試管理控制台（2分鐘）

```
1️⃣ 開啟管理控制台
   → http://calendar.funlearnbar.synology.me/admin-dashboard.html

2️⃣ 點擊「講師管理」分頁

3️⃣ 捲動到「講師顏色配置」區塊
   → ✅ 應該顯示所有講師及其顏色選擇器

4️⃣ 調整 YOKI 的顏色為紅色 (#FF0000)

5️⃣ 點擊「儲存顏色配置」按鈕
   → ✅ 應該顯示「講師顏色配置已儲存」

6️⃣ 按 F12 開啟瀏覽器控制台
   → ✅ 應該看到「✅ 講師顏色已保存到後端」
```

### 步驟 2：測試前端顯示（2分鐘）

```
1️⃣ 開啟前端行事曆
   → http://calendar.funlearnbar.synology.me/perfect-calendar-optimized-complete2.html

2️⃣ 按 F12 開啟瀏覽器控制台

3️⃣ 檢查載入訊息
   → ✅ 應該看到「🎨 開始從後端載入講師顏色...」
   → ✅ 應該看到「✅ 載入講師 YOKI 的顏色: rgba(255, 0, 0, 0.8)」
   → ✅ 應該看到「✅ 已從後端載入講師顏色配置」

4️⃣ 尋找 YOKI 的課程
   → ✅ 課程卡片應該顯示紅色背景

5️⃣ 按 Ctrl+Shift+R 強制重新整理
   → ✅ YOKI 的課程仍然是紅色（不再隨機）
```

### 步驟 3：測試持久性（1分鐘）

```
1️⃣ 在瀏覽器控制台執行：
   localStorage.clear();
   location.reload();

2️⃣ 再次檢查 YOKI 的課程
   → ✅ 仍然是紅色（證明不依賴 localStorage）

3️⃣ （可選）在另一台裝置或瀏覽器開啟
   → ✅ 顏色應該相同（證明同步到伺服器）
```

## ❌ 如果測試失敗

### 情況 1：管理控制台保存失敗

```bash
# 檢查後端 API
grep "app.put('/api/teachers'" server.js

# 如果沒有找到，重新部署
./🚀立即部署-講師顏色修復.sh
```

### 情況 2：前端仍然隨機顏色

```bash
# 檢查 teacher_data.json 是否有顏色
cat teacher_data.json | grep "color"

# 如果沒有，檢查檔案是否正確更新
```

### 情況 3：控制台顯示 404 錯誤

```bash
# 重啟服務
docker-compose restart
# 或
pm2 restart all
```
