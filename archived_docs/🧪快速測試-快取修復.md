## 🧪 測試案例 5：錯誤處理（資料未準備好）

### 模擬場景
後端 CalDAV 連線失敗，資料無法載入

### 步驟
```bash
# 1. 停止 CalDAV 服務（模擬連線失敗）
# 修改 docker-compose.yml 中的 CALDAV_URL 為錯誤的值

docker-compose restart

# 3. 開啟頁面並觀察 Console
```

## 🔍 除錯指令集

### 檢查後端快取狀態
```bash
curl http://localhost:3002/api/events/cache-status | jq
```

### 手動刷新後端快取
```bash
curl -X POST http://localhost:3002/api/events/refresh-cache
```

### 檢查後端健康狀態
```bash
curl http://localhost:3002/api/health | jq
```

### 查看後端日誌
```bash
# 即時日誌
docker-compose logs -f

# 最近 50 行
docker-compose logs --tail=50

# 只看 server 服務
docker-compose logs -f server
```

### 檢查前端全域變數
```javascript
// 在瀏覽器 Console 執行
console.log('allInstructors:', allInstructors);
console.log('allEvents:', allEvents.length);
console.log('currentUser:', currentUser);
```

### 清除前端快取
```javascript
// 在瀏覽器 Console 執行
localStorage.clear();
sessionStorage.clear();
location.reload();
```
