## 📱 頁面結構

### 1️⃣ 儀表板 (Dashboard)

**功能**: 系統概覽和快速操作

**顯示內容**:
- 系統狀態（運行/異常）
- 排程器狀態（運行中/已停止）
- 待發送提醒數量
- 當前管理員資訊

**後端API**:
- `GET /api/health` - 系統健康檢查
- `GET /api/reminder-scheduler/status` - 排程器狀態
- `GET /api/admin/info` - 管理員資訊

**刷新頻率**: 30秒自動刷新

---

### 2️⃣ 管理員設定 (Admin)

**功能**: 設定系統管理員

**可設定項目**:
- LINE User ID - 管理員的 LINE 用戶ID
- 當前管理員顯示

**後端API**:
- `GET /api/admin/info` - 取得管理員資訊
- `POST /api/admin/set` - 設定管理員

**使用流程**:
1. 輸入管理員的 LINE User ID
2. 點擊「儲存設定」
3. 系統會驗證並保存到環境變數

**注意事項**:
- User ID 可從 LINE Bot 獲取
- 管理員會收到所有系統通知
- 設定後立即生效

---

### 3️⃣ LINE 通知設定 (LINE)

**功能**: 配置 LINE Bot 通知功能

**可設定項目**:
- Channel Access Token
- Channel Secret
- 配置狀態顯示

**後端API**:
- `GET /api/line-config` - 取得LINE配置
- `POST /api/line-config` - 儲存LINE配置
- `POST /api/test-line-notification` - 測試通知

**使用流程**:
1. 從 LINE Developers Console 取得憑證
2. 輸入 Channel Access Token 和 Secret
3. 點擊「儲存設定」
4. 使用「測試通知」驗證配置

**注意事項**:
- ⚠️ Token 修改後需要重啟 Docker 容器
- Token 不會明文顯示，僅顯示長度
- 測試通知會發送給管理員

---

### 4️⃣ 行事曆設定 (Calendar)

**功能**: 設定 Synology Calendar 連線

**可設定項目**:
- Calendar URL（NAS地址）
- 用戶名稱
- 密碼
- 行事曆 ID

**後端API**:
- `POST /api/calendar-config` - 儲存行事曆配置
- `GET /api/events` - 測試連線（獲取事件）

**預設值**:
- URL: `https://funlearnbar.synology.me:9102`
- 用戶: `testacount`

**使用流程**:
1. 輸入 Synology Calendar 連線資訊
2. 點擊「測試連線」驗證
3. 確認無誤後「儲存設定」

**注意事項**:
- 需要有效的 Synology Calendar 帳號
- 密碼會加密存儲在 .env.nas
- 連線失敗請檢查網路和憑證

---

### 5️⃣ 提醒設定 (Reminder)

**功能**: 配置各類提醒的發送時間

**可設定項目**:
- 當日提醒時間（時、分）
- 隔日提醒時間（時、分）
- 課前提醒（分鐘）

**後端API**:
- `GET /api/system-settings` - 取得系統設定
- `POST /api/reminder-config` - 儲存提醒配置

**預設值**:
- 當日提醒: 08:00
- 隔日提醒: 19:30
- 課前提醒: 30分鐘

**使用流程**:
1. 調整提醒時間參數
2. 點擊「儲存設定」
3. 設定會寫入 system-settings.json

**注意事項**:
- 時間採用24小時制
- 課前提醒範圍: 5-120分鐘
- 修改後立即生效

---

### 6️⃣ 排程器設定 (Scheduler)

**功能**: 管理自動排程任務

**顯示內容**:
- 當前狀態（運行中/已停止）
- 上次執行時間
- 總提醒數
- 待發送提醒數
- 已發送提醒數

**後端API**:
- `GET /api/reminder-scheduler/status` - 取得狀態
- `POST /api/reminder-scheduler/start` - 啟動排程器
- `POST /api/reminder-scheduler/stop` - 停止排程器

**使用流程**:
1. 查看當前排程器狀態
2. 使用「啟動/停止」按鈕控制
3. 使用「刷新狀態」更新資訊

**注意事項**:
- 排程器負責自動發送提醒
- 停止後不會發送任何提醒
- 狀態每30秒自動刷新

---

### 7️⃣ 系統參數 (System)

**功能**: 檢視系統資訊和進階設定

**顯示內容**:
- 系統版本
- 容器狀態
- API 基礎 URL
- 系統設定檔案內容

**後端API**:
- `GET /api/health` - 健康檢查
- `GET /api/system-settings` - 取得系統設定

**功能按鈕**:
- 系統健康檢查
- 重新載入設定
- 返回管理頁面

**使用流程**:
1. 查看系統運行狀態
2. 檢視完整配置檔案
3. 執行健康檢查診斷

**注意事項**:
- 設定檔案僅供查看
- 健康檢查會驗證所有服務
- API URL 為唯讀

## 🔌 API 端點清單

### GET 請求

| API端點 | 功能 | 回應格式 |
|--------|------|---------|
| `/api/health` | 系統健康檢查 | `{ success: boolean }` |
| `/api/admin/info` | 取得管理員資訊 | `{ success: boolean, data: { userId, hasToken } }` |
| `/api/line-config` | 取得LINE配置 | `{ success: boolean, data: { hasToken, tokenLength } }` |
| `/api/system-settings` | 取得系統設定 | `{ success: boolean, data: {...} }` |
| `/api/reminder-scheduler/status` | 排程器狀態 | `{ success: boolean, data: { isRunning, ... } }` |
| `/api/events` | 測試行事曆連線 | `{ success: boolean, data: [...] }` |

### POST 請求

| API端點 | 功能 | 請求體 |
|--------|------|--------|
| `/api/admin/set` | 設定管理員 | `{ adminUserId: string }` |
| `/api/line-config` | 儲存LINE配置 | `{ lineChannelToken?, channelSecret? }` |
| `/api/calendar-config` | 儲存行事曆配置 | `{ baseUrl, username, password, calendarId }` |
| `/api/reminder-config` | 儲存提醒配置 | `{ todayReminderHour, todayReminderMinute, ... }` |
| `/api/reminder-scheduler/start` | 啟動排程器 | `{}` |
| `/api/reminder-scheduler/stop` | 停止排程器 | `{}` |
| `/api/test-line-notification` | 測試LINE通知 | `{ message?: string }` |

## 🚀 快速開始

### 1. 訪問頁面

```bash
http://localhost:3000/新系統設定.html
```

### 2. 基本設置流程

**第一步: 設定管理員**
1. 進入「管理員設定」
2. 輸入管理員的 LINE User ID
3. 儲存設定

**第二步: 配置 LINE Bot**
1. 進入「LINE 通知設定」
2. 輸入 Channel Access Token
3. 測試通知是否正常

**第三步: 測試行事曆連線**
1. 進入「行事曆設定」
2. 點擊「測試連線」
3. 確認能正常讀取事件

**第四步: 調整提醒時間**
1. 進入「提醒設定」
2. 設定當日/隔日提醒時間
3. 儲存設定

**第五步: 啟動排程器**
1. 進入「排程器設定」
2. 點擊「啟動排程器」
3. 確認狀態為「運行中」

### 3. 日常使用

**檢視系統狀態**
- 進入「儀表板」查看概覽
- 每30秒自動刷新

**管理排程器**
- 在「排程器設定」頁面
- 隨時啟動/停止

**修改設定**
- 進入對應設定頁面
- 修改後點擊「儲存」
- 部分設定需重啟服務

## ⚠️ 注意事項

### 重啟需求

**需要重啟 Docker 的情況**:
- 修改 LINE Channel Token
- 修改 Channel Secret
- 更改行事曆連線資訊

**立即生效的設定**:
- 管理員 User ID
- 提醒時間設定
- 排程器啟動/停止

### 權限要求

**需要的權限**:
- LINE Bot 管理權限
- Synology Calendar 讀取權限
- 系統檔案寫入權限

### 安全建議

1. **定期更新憑證** - 定期更換 LINE Token
2. **備份設定** - 修改前先備份
3. **限制訪問** - 僅授權人員訪問
4. **監控日誌** - 定期檢查系統日誌

## 🔍 故障排除

### 常見問題

**Q1: LINE 通知發送失敗**
- 檢查 Token 是否正確
- 確認管理員 User ID 已設定
- 使用「測試通知」功能

**Q2: 行事曆連線失敗**
- 檢查 NAS 網路連線
- 驗證帳號密碼
- 確認 Calendar 服務運行

**Q3: 排程器無法啟動**
- 檢查系統健康狀態
- 查看後端日誌
- 重啟 Docker 容器

**Q4: 設定無法保存**
- 檢查檔案權限
- 確認磁碟空間
- 查看錯誤訊息

### 診斷工具

**系統健康檢查**:
```
進入「系統參數」→ 點擊「系統健康檢查」
```

**查看設定檔案**:
```
進入「系統參數」→ 檢視系統設定JSON
```

**測試 API**:
```bash
# 健康檢查
curl http://localhost:3000/api/health

# 檢視系統設定
curl http://localhost:3000/api/system-settings
```
