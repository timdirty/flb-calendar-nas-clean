## 🐛 常見問題排查

### 問題 1：點擊無反應

**檢查項目**：
- [ ] Console 是否有錯誤訊息
- [ ] 是否看到「✅ 日曆視圖事件委派已設置完成」
- [ ] 函數是否正確定義（檢查 `window.scrollToDateCourses`）

**解決方案**：
```bash
# 強制重新載入頁面
Ctrl+Shift+R (Windows/Linux)
Cmd+Shift+R (macOS)
```

### 問題 2：懸浮提示不顯示

**檢查項目**：
- [ ] 滑鼠是否正確懸停在方塊上
- [ ] 等待 1-2 秒（瀏覽器原生延遲）
- [ ] 檢查 title 屬性是否存在

**測試方法**：
```javascript
// 在 Console 中執行
document.querySelector('.calendar-day').getAttribute('title')
document.querySelector('.event-chip').getAttribute('title')
```

### 問題 3：Console 顯示函數未定義

**錯誤訊息**：
```
❌ window.scrollToDateCourses 未正確定義！
```

**解決方案**：
```bash
# 1. 確認文件已正確部署
cat public/perfect-calendar-optimized-complete2.html | grep "window.scrollToDateCourses"

# 2. 重啟服務
docker-compose restart

# 3. 清除快取並重新載入
```

### 問題 4：點擊後頁面不滾動

**檢查項目**：
- [ ] 課程列表是否已載入
- [ ] Console 是否顯示「找到 X 個課程」
- [ ] 目標課程卡片是否存在

**調試命令**：
```javascript
// 在 Console 中執行
document.querySelectorAll('.event-card').length  // 應該 > 0
```
