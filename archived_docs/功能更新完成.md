- 回傳 Token 長度和預覽

- 驗證 Token 格式
- 更新 .env.nas 文件
- 回傳儲存結果

## 🎯 使用流程

### 簡化版（5 分鐘）

1. **取得 Token**
   - 訪問 https://developers.line.biz/console/
   - 複製 Channel Access Token

2. **設定 Token**
   - 打開 https://calendar.funlearnbar.synology.me/admin-dashboard.html
   - 通知設定 → LINE API 設定
   - 貼上 Token → 儲存

3. **重啟服務**
   ```bash
   cd flb-calendar-nas && sudo docker-compose restart
   ```

4. **測試通知**
   - 點擊「測試 LINE 通知」
   - 檢查 LINE 是否收到訊息

### 詳細版

請參考 `LINE配置介面使用說明.md`

## 🔒 安全性

### Token 保護機制

✅ **前端保護**:
- Token 輸入框為密碼模式
- 可切換顯示/隱藏
- 不在前端儲存完整 Token
- 只顯示前 20 字元預覽

✅ **後端保護**:
- Token 儲存在伺服器端 .env.nas
- 環境變數只在服務啟動時載入
- API 回應不包含完整 Token
- 僅管理員可訪問設定介面

✅ **傳輸保護**:
- HTTPS 加密傳輸
- POST 請求防止快取
- 無 Token 記錄在瀏覽器歷史
