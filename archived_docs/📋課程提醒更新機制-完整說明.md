## 🔄 每 5 分鐘執行的完整流程

### runScheduledTasks() 執行順序

```javascript
async runScheduledTasks() {
  // ⭐ 步驟 1: 檢查是否為午夜（00:00-00:10）
  if (當前時間在 00:00-00:10) {
    await forceMidnightCleanupAndReload();
    return; // 直接返回，不執行後續任務
  }
  
  // ⭐ 步驟 2: 更新學生資料（每 5 分鐘）
  await this.updateStudentData();  // 從 Google Sheets 更新
  
  // ⭐ 步驟 3: 清理過期提醒
  this.cleanupExpiredReminders();
  
  // ⭐ 步驟 4: 創建新的課程提醒 ✅ 重點！
  await this.createRemindersFromCalendar();
  
  // ⭐ 步驟 5: 生成學生提醒
  await this.generateStudentReminders();
  
  // ⭐ 步驟 6: 重置課前提醒狀態
  this.resetBeforeClassReminders();
  
  // ⭐ 步驟 7: 處理重試提醒
  await this.processRetryReminders();

  await this.processTodayReminders();
  
  // ⭐ 步驟 9: 處理隔日提醒
  await this.processTomorrowReminders();
  
  // ⭐ 步驟 10: 處理課前提醒
  await this.processBeforeClassReminders();
  
  // ⭐ 步驟 11: 處理學生提醒
```

```javascript:2534-2603:reminder-scheduler.js
  } catch (error) {
    console.error('❌ 排程任務執行失敗:', error);
```

## 📅 課程提醒創建邏輯

### createRemindersFromCalendar() 詳細流程

```javascript
async createRemindersFromCalendar() {
  // 1. 獲取行事曆事件
  const events = await this.getCalendarEvents();
  console.log(`📊 獲取到 ${events.length} 個行事曆事件`);
  
  // 2. 使用台灣時區
  const taiwanTime = this.getTaiwanTime();
  const today = new Date(taiwanTime);
  const tomorrow = new Date(taiwanTime);
  tomorrow.setDate(tomorrow.getDate() + 1);
  
  const todayStr = today.toISOString().split('T')[0];      // 例: 2025-10-17
  const tomorrowStr = tomorrow.toISOString().split('T')[0]; // 例: 2025-10-18
  
  // 3. 篩選今天和明天的事件
  const relevantEvents = events.filter(event => {
    const eventDate = event.start.split('T')[0];
    return eventDate === todayStr || eventDate === tomorrowStr;
  });
  
  console.log(`找到 ${relevantEvents.length} 個相關事件`);
  
  // 4. 載入現有提醒
  const existingReminders = remindersData.reminders || [];
  
  // 5. 為每個事件創建提醒
  for (const event of relevantEvents) {
    const eventDate = event.start.split('T')[0];
    const isToday = eventDate === todayStr;
    const isTomorrow = eventDate === tomorrowStr;
    
    // 今日課程: 創建「當日提醒」+「課前提醒」
    if (isToday) {
      await this.createRemindersForEvent(event, eventDate, 'today', existingReminders);
      await this.createRemindersForEvent(event, eventDate, 'before-class', existingReminders);
    } 
    // 明日課程: 創建「隔日提醒」
    else if (isTomorrow) {
      await this.createRemindersForEvent(event, eventDate, 'tomorrow', existingReminders);
    }
  }
  
  // 6. 儲存更新後的提醒
  this.saveReminders(remindersData);
}
```

## 🎯 三種課程提醒類型

### 1️⃣ 當日提醒（Today Reminders）

- **創建時機**: 當行事曆有「今天」的課程時
- **發送時間**: 上午 8:00（可設定）
- **提醒內容**: 今天有哪些課程

**範例**：
```
🔔 今日課程提醒
講師：王老師

📅 今天有以下課程：
• 09:30 - SPM 程式設計課程
• 14:00 - Python 進階班

請準備好課程資料！
```

### 2️⃣ 隔日提醒（Tomorrow Reminders）

- **創建時機**: 當行事曆有「明天」的課程時
- **發送時間**: 晚上 18:00（可設定）
- **提醒內容**: 明天有哪些課程

**範例**：
```
🔔 明日課程提醒
講師：王老師

📅 明天有以下課程：
• 09:30 - SPM 程式設計課程
• 14:00 - Python 進階班

請提前準備課程資料！
```

### 3️⃣ 課前提醒（Before Class Reminders）

- **創建時機**: 當行事曆有「今天」的課程時
- **發送時間**: 課程開始前 30 分鐘（可設定）
- **提醒內容**: 即將開始的課程

**範例**：
```
⏰ 課前提醒
講師：王老師

📍 30 分鐘後有課程：
• 09:30 - SPM 程式設計課程

請準備開始上課！
```

```javascript

  type: type,

  courseDate: eventDate,
  courseTime: eventTime,
```

## ⚙️ 設定檔控制

### system-settings.json

```json
{
  "scheduler": {
    "checkInterval": 5,        // ⭐ 檢查間隔（分鐘）
    "timeout": 60000,          // API 超時時間（毫秒）
    "retryDelay": 1000         // 重試延遲（毫秒）
  },
  "reminders": {
    "todayReminderHour": 8,          // 今日提醒發送時間（小時）
    "tomorrowReminderHour": 18,      // 隔日提醒發送時間（小時）
    "beforeClassMinutes": 30,        // 課前提醒提前時間（分鐘）
    "sendDelay": 3000                // 發送間隔（毫秒）
  }
}
```

### 修改檢查間隔

如果想改為每 10 分鐘檢查一次：

```json
{
  "scheduler": {
    "checkInterval": 10  // 改為 10 分鐘
  }
}
```

**⚠️ 注意**：修改後需要重啟服務

## 🐛 常見問題

### Q1: 為什麼明明是每 5 分鐘，但提醒沒有立即更新？

**A**: 提醒的**創建**是每 5 分鐘，但**發送**是在指定時間：
- 今日提醒: 08:00 才發送
- 隔日提醒: 18:00 才發送
- 課前提醒: 課程前 30 分鐘才發送

**範例**：
```
09:00 - 創建了一個 18:00 的隔日提醒
09:05 - 檢查已存在，不重複創建
09:10 - 檢查已存在，不重複創建
...
18:00 - 實際發送提醒 ✅
```

### Q2: 如果在 CalDAV 新增課程，多久會反映在系統中？

**A**: 最多 5 分鐘

```
14:00 - 在 Synology Calendar 新增明天 10:00 的課程
14:05 - 系統檢查 CalDAV，發現新課程，創建提醒 ✅
18:00 - 發送隔日提醒給講師 📤
```

### Q3: 如果在 CalDAV 刪除課程，提醒會自動消失嗎？

**A**: 不會立即消失，但會在**午夜清理**時移除

```
15:00 - 在 Synology Calendar 刪除明天的課程
15:05 - 系統檢查，但已創建的提醒仍存在
18:00 - 仍然會發送提醒 ⚠️
00:00 - 午夜清理，重新從 CalDAV 獲取，提醒消失 ✅
```

**解決方案**: 手動在前端刪除提醒，或等待午夜清理

### Q4: 可以改為每 1 分鐘檢查一次嗎？

**A**: 技術上可以，但不建議：

**不建議原因**：
- 增加 CalDAV API 呼叫頻率
- 增加系統負載
- 提醒發送時間是固定的（08:00, 18:00, 課前 30 分鐘）
- 5 分鐘已經足夠及時

**如果真的需要**：
```json
{
  "scheduler": {
    "checkInterval": 1  // 改為 1 分鐘
  }
}
```

## 📝 總結

### 核心重點

1. **✅ 課程提醒每 5 分鐘更新一次**
   - 不是只有午夜才更新
   - 從啟動開始，每 5 分鐘執行一次 `createRemindersFromCalendar()`

   - 清空所有舊提醒

   - 重新創建所有提醒
   - 確保新的一天從乾淨狀態開始

3. **✅ 三種提醒類型都是每 5 分鐘檢查**
   - 今日提醒（發送時間：08:00）
   - 隔日提醒（發送時間：18:00）
   - 課前提醒（發送時間：課前 30 分鐘）
