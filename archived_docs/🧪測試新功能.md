## 🐛 常見問題排查

### 問題 1：綁定選單沒有自動跳出

**可能原因：**
- teacher_data.json 中已有該用戶記錄
- API 請求失敗

**排查步驟：**
```javascript
// Console 執行
console.log('當前用戶:', currentUser);
fetch('/api/teachers')
  .then(r => r.json())
  .then(data => console.log('講師列表:', data));
```

### 問題 2：強制刷新沒有獲取最新資料

**可能原因：**
- 後端沒有收到 X-Force-Refresh header
- CalDAV 連線問題

**排查步驟：**
```bash
# 檢查後端日誌
sudo docker-compose logs --tail=100 | grep -i "refresh\|caldav"

# 檢查 header 是否正確發送
# 在 Chrome DevTools Network 中查看 /api/events 請求
# 確認 Request Headers 包含 X-Force-Refresh: true
```

### 問題 3：teacher_data.json 沒有更新

**可能原因：**
- API 請求失敗
- 檔案權限問題

**排查步驟：**
```bash
# 檢查檔案權限
ls -l teacher_data.json

# 檢查 API 回應
curl -X POST http://localhost:3000/api/teacher-binding \
  -H "Content-Type: application/json" \
  -d '{"userId":"test123","displayName":"測試用戶","teacherName":"TIM"}'

# 查看後端日誌
sudo docker-compose logs --tail=50 | grep "綁定"
```
