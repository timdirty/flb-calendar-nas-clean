=== 🔥 完整修復時間問題 - 正確步驟 ===

問題：所有課程時間都差了 8 小時
- ESM 10:00 顯示為 02:00
- BOOST 12:30 顯示為 04:30

原因：時區轉換問題

=== 正確的修復步驟 ===

# 1. 使用 ftpuser 登入（有足夠權限）
ssh ftpuser@192.168.50.242

# 2. 進入 Docker 容器（容器內有完整權限）
cd /volume1/docker/flb-calendar-nas
docker exec -it flb-calendar-nas /bin/sh

# 3. 在容器內執行以下指令
# --------------------------------

# 備份現有數據
cp ./data/reminders.json ./data/reminders.json.backup-$(date +%Y%m%d-%H%M%S)

# 清除所有提醒
cat > ./data/reminders.json << 'EOF'
{
  "reminders": [],
  "studentReminders": []
}
EOF

# 驗證清除成功
cat ./data/reminders.json

# 檢查檔案權限
ls -la ./data/reminders.json

# 退出容器
exit

# --------------------------------
# 4. 重啟容器（回到 SSH 層級）
docker restart flb-calendar-nas

# 5. 等待容器啟動並重新生成提醒
echo "等待 30 秒..."
sleep 30

# 6. 檢查結果
docker exec flb-calendar-nas node -e "
const fs = require('fs');
try {
  const data = JSON.parse(fs.readFileSync('./data/reminders.json', 'utf8'));
  const reminders = data.reminders || [];
  
  console.log('\n✅ 提醒總數:', reminders.length);
  console.log('\n前 5 個提醒的時間檢查：\n');
  
  reminders.slice(0, 5).forEach((r, i) => {
    const match = r.courseName.match(/(\d{1,2}):(\d{2})/);
    const nameTime = match ? match[0] : '無';
    const timeMatch = nameTime !== '無' && r.courseTime === nameTime;
    const icon = timeMatch ? '✅' : (nameTime === '無' ? '⚪' : '❌');
    
    console.log(\`\${icon} \${i + 1}. \${r.courseName}\`);
    console.log(\`   courseTime: \${r.courseTime} | 標題時間: \${nameTime}\`);
    console.log(\`   scheduledTime: \${r.scheduledTime}\`);
    console.log('');
  });
  
  // 統計匹配情況
  let totalWithTime = 0;
  let matchCount = 0;
  
  reminders.forEach(r => {
    const match = r.courseName.match(/(\d{1,2}):(\d{2})/);
    if (match) {
      totalWithTime++;
      if (r.courseTime === match[0]) {
        matchCount++;
      }
    }
  });
  
  console.log(\`\n📊 統計：\${matchCount}/\${totalWithTime} 個時間匹配\`);
  
  if (matchCount === totalWithTime && totalWithTime > 0) {
    console.log('\n🎉 所有時間都正確！修復成功！\n');
  } else {
    console.log('\n⚠️  仍有時間不匹配的問題\n');
  }
  
} catch (error) {
  console.error('❌ 讀取失敗:', error.message);
}
"

# 7. 查看容器日誌（如果需要）
docker logs flb-calendar-nas --tail 50
