## 🐛 問題診斷

### 發現的問題
1. **全域點擊事件攔截**: 全域的 `document.addEventListener('click', ..., true)` 使用 capture 模式，會攔截所有點擊事件
2. **缺乏事件保護**: 沒有 `preventDefault()` 和 `stopPropagation()` 來防止事件冒泡
3. **重複點擊保護不足**: 沒有防止快速連續點擊的機制
4. **事件監聽器重複綁定**: 可能重複綁定導致多次觸發
5. **控制台訊息過多**: 所有點擊都會輸出診斷日誌，影響效能

## 📝 技術細節

### 事件委派 vs 直接綁定

**採用方案**: 直接綁定 + 事件保護

**原因**:
- 排序按鈕數量固定（只有 2 個）
- 不需要動態創建/刪除
- 直接綁定更可控，更容易除錯
- 使用 `replaceWith` 確保不會重複綁定

### Capture vs Bubble

**全域監聽器**: 使用 **Capture 模式** (true)
- 優先攔截事件
- 但需要排除不相關的元素

**排序按鈕**: 使用 **Bubble 模式** (false)
- 正常的事件流
- 配合 `stopPropagation()` 防止冒泡

### 防抖機制

使用**簡單的標記變數**而非防抖函數:
```javascript
let isSortChanging = false;

// 點擊時設為 true
isSortChanging = true;

// 300ms 後重置
setTimeout(() => {
    isSortChanging = false;
}, 300);
```

**優點**:
- 簡單直接
- 不會丟失點擊
- 響應速度快
