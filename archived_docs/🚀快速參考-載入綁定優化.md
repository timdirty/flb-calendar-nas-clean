## 🔍 問題排查

### 問題 1：載入還是很慢
**檢查項目**：
1. Console 是否有錯誤？
2. 後端快取是否正常建立？
3. 網路連線是否穩定？

**解決方法**：
```javascript
// 在 Console 執行檢查
console.log('快取狀態:', {
    v3快取: localStorage.getItem('synology_events_cache_v3'),
    快取時間: localStorage.getItem('synology_events_cache_time_v3')
});

// 清除快取重試
localStorage.clear();
location.reload();
```

### 問題 2：綁定失敗
**檢查項目**：
1. `allInstructors` 是否有資料？
2. `currentUser` 是否存在？
3. 事件是否被觸發？

**解決方法**：
```javascript
// 在 Console 執行檢查
console.log('綁定狀態:', {
    資料完成: window.dataLoadingComplete,
    講師列表: allInstructors,
    用戶資料: currentUser,
    事件數: allEvents.length
});

// 手動觸發綁定
if (currentUser) {
    autoMatchTeacher(currentUser.userId, currentUser.displayName);
}
```

### 問題 3：事件未觸發
**檢查項目**：
```javascript
// 監聽事件
window.addEventListener('dataLoadingComplete', (e) => {
    console.log('✅ 事件已觸發！', e.detail);
});

// 檢查是否已載入
console.log({
    dataLoadingComplete: window.dataLoadingComplete,
    allEvents: allEvents.length,
    allInstructors: allInstructors.length
});
```

## 💡 使用技巧

### 清除快取強制重新載入
```bash
# 在瀏覽器 Console 執行
localStorage.clear();
sessionStorage.clear();
location.reload(true);
```

### 檢查載入性能
```javascript
// 在 Console 查看時間統計
console.log('載入時間統計：');
performance.getEntriesByType('navigation').forEach(entry => {
    console.log({
        總時間: entry.loadEventEnd - entry.fetchStart,
        DOM載入: entry.domContentLoadedEventEnd - entry.fetchStart,
        頁面載入: entry.loadEventEnd - entry.loadEventStart
    });
});
```

### 強制重新綁定
```javascript
// 清除綁定快取並重新綁定
Object.keys(localStorage).forEach(key => {
    if (key.startsWith('teacher_match_')) {
        localStorage.removeItem(key);
    }
});

// 重新執行綁定
if (currentUser) {
    autoMatchTeacher(currentUser.userId, currentUser.displayName);
}
```
