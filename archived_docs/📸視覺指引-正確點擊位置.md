# 📸 視覺指引 - 正確的點擊位置

## ⚠️ 重要：請確認以下步驟

### 步驟 1：確認已切換到正確視圖

在頁面上方，您應該看到類似這樣的按鈕：

```
┌─────┬─────┬─────┬─────┐
│今日 │本週 │本月 │全部 │
└─────┴─────┴─────┴─────┘
```

**請點擊「本週」或「本月」按鈕！**

- ❌ 不要點擊「今日」（今日視圖沒有日曆網格）
- ❌ 不要點擊「全部」（全部視圖沒有日曆網格）
- ✅ 必須點擊「本週」或「本月」

### 步驟 2：確認看到日曆網格

點擊「本週」後，您應該看到類似這樣的**日曆網格**：

```
┌──────────────────────────────────────────────┐
│  日    一    二    三    四    五    六        │
├─────┬─────┬─────┬─────┬─────┬─────┬─────┤
│ 19  │ 20  │ 21  │ 22  │ 23  │ 24  │ 25  │
│     │     │     │     │     │     │     │
│     │ 課程 │ 課程 │     │ 課程 │     │     │
│     │ 方塊 │ 方塊 │     │ 方塊 │     │     │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘
       ↑                    ↑
    要點這裡             或這裡
```

**這才是日曆網格！**

### 步驟 3：區分不同的區域

#### ❌ 不要點擊這些區域（這些是 controls）

```
┌──────────────────────────────────────┐
│ 選擇講師: [下拉選單]                  │  ← 這是 controls
│ 時段篩選: [下拉選單]                  │  ← 這是 controls
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│ 📅 本週 (2025/10/19)                  │  ← 這是標題
│ [上一期] [今天] [下一期]              │  ← 這些是導航按鈕
└──────────────────────────────────────┘
```

#### ✅ 要點擊這個區域（這才是日曆）

```
┌──────────────────────────────────────┐
│  日    一    二    三    四    五    六  │
├─────┬─────┬─────┬─────┬─────┬─────┬───┤
│ 19  │ 20  │ 21  │ 22  │ 23  │ 24  │ 25│
│10:00│     │     │     │     │     │   │
│SPIKE│     │     │     │     │     │   │
└─────┴─────┴─────┴─────┴─────┴─────┴───┘
  ↑ 點這個黃色方塊
```

### 步驟 4：正確的點擊測試

1. **切換到「本週」視圖**
   - 點擊頁面上方的「本週」按鈕
   - 等待 1-2 秒

2. **向下滾動**
   - 找到日曆網格（有 7 個縱列的格子）

3. **點擊日曆格子中的課程方塊**
   - 點擊黃色/粉色/灰色的小方塊
   - 不要點擊空白的日期格子

4. **查看 Console**
   - 應該顯示：`closest(.event-chip): ✅ 找到`
   - 而不是：`target: DIV controls`

- [ ] Console 的輸出不再是 `target: DIV controls`

## ❓ 如果還是看不到日曆網格

請在 Console 執行：

```javascript
// 檢查日曆是否渲染
document.querySelectorAll('.calendar-day').length
```

如果返回 **0**，表示日曆沒有渲染，可能原因：
1. 您沒有點擊「本週」或「本月」按鈕
2. 瀏覽器快取問題（按 Ctrl+Shift+R 清除）
3. JavaScript 錯誤（查看 Console 是否有紅色錯誤訊息）

如果返回 **> 0**（例如 7 或 35），表示日曆已經渲染，請確認您點擊的位置是否正確。
