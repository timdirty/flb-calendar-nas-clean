### ✅ 5. 系統設定管理 (system-settings.json)

**功能：**
- ✅ 顯示所有系統設定（分區域顯示）
- ✅ 編輯各項設定
- ✅ 儲存變更（自動備份，立即生效）
- ✅ 重置設定（重新載入）

**設定區域：**

#### 📅 排程器設定 (scheduler)
- checkInterval - 檢查間隔（分鐘）
- timeout - 超時時間（毫秒）
- retryDelay - 重試延遲（毫秒）

#### 🌏 時區設定 (timezone)
- offset - 時區偏移（小時）
- name - 時區名稱

#### ⏰ 提醒設定 (reminders)
- todayReminderHour - 今日提醒時間（小時）
- todayReminderMinute - 今日提醒時間（分鐘）
- tomorrowReminderHour - 隔日提醒時間（小時）
- tomorrowReminderMinute - 隔日提醒時間（分鐘）
- beforeClassMinutes - 課前提醒時間（分鐘）
- sendDelay - 發送延遲（毫秒）

#### 👨‍🎓 學生提醒設定 (studentReminders)
- defaultHour - 預設提醒時間（小時）
- defaultMinute - 預設提醒時間（分鐘）
- defaultDuration - 預設提醒持續時間（分鐘）
- defaultEnabled - 預設是否啟用

#### 🔗 API 設定 (api)
- baseUrl - API 基礎網址
- timeout - 超時時間（毫秒）

**API 端點：**
- `GET /api/settings/system` - 獲取系統設定
- `POST /api/settings/system` - 儲存系統設定

**代碼位置：**
- 前端：`public/js/settings-manager.js` (行 189-273)
- 後端：`server.js` (行 2400-2464)
