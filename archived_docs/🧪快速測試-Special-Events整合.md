# 🧪 快速測試指南 - Special Events Manager 整合

## 📋 測試前準備

### 1. 啟動服務
```bash
cd /Users/apple/Library/CloudStorage/SynologyDrive-FLBTim/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas

# 啟動服務器
node server.js
```

### 2. 訪問頁面
打開瀏覽器訪問：
- 本地：`http://localhost:3002/perfect-calendar-optimized-complete2.html`
- 或您的 NAS 地址

## ✅ 功能測試清單

### 測試 1：頁面載入檢查
**目標**：確認新組件正確顯示

✓ **檢查項目**：
1. [ ] 頁面是否正常載入
2. [ ] 控制台是否顯示「🎨 從外部 API 載入課程顏色...」
3. [ ] 控制台是否顯示「✅ 課程顏色載入完成」或「⚠️ 載入課程顏色失敗，使用預設值」
4. [ ] 是否出現「時間範圍選擇器」（今日/本週/本月按鈕）
5. [ ] 是否出現「今日課程」區塊
6. [ ] 今日課程數量徽章是否顯示正確數字
7. [ ] 是否出現「配色說明面板」
8. [ ] 配色面板是否顯示課程類型和講師顏色

**預期結果**：
- ✅ 所有組件正常顯示
- ✅ 今日課程區塊顯示當天的課程
- ✅ 課程卡片使用正確顏色（講師顏色優先）

### 測試 3：日曆 Chip 互動
**目標**：確認高亮功能正常

✓ **操作步驟**：
1. [ ] 切換到「本週」視圖
2. [ ] 點擊任意課程 chip
3. [ ] 觀察課程卡片列表
4. [ ] 確認目標卡片是否：
   - 浮出（放大 1.05 倍，向上移動 8px）
   - 藍色邊框（3px solid #4f46e5）
   - 藍色陰影
5. [ ] 確認其他卡片是否：
   - 變暗（opacity: 0.3）
   - 灰度濾鏡（filter: grayscale(0.6)）
   - 縮小（scale: 0.98）
6. [ ] 確認頁面是否平滑滾動到目標卡片
7. [ ] 確認來源 chip 是否有藍色邊框高亮
8. [ ] 等待 3 秒，確認所有效果是否自動恢復

**預期結果**：
- ✅ 點擊 chip 後立即高亮
- ✅ 目標卡片浮出且滾動到視野中心
- ✅ 其他卡片變暗
- ✅ 3 秒後自動恢復原狀
- ✅ 動畫流暢（60fps）

## 🔍 Debug 檢查點

如果功能不正常，請檢查：

### 1. 控制台錯誤
打開瀏覽器控制台（F12），檢查是否有：
- ❌ JavaScript 錯誤
- ❌ API 請求失敗
- ❌ 資源載入失敗

### 2. 網路請求
檢查 Network 標籤：
- `https://course-viewer.funlearnbar.synology.me/api/course-colors` 是否成功
- `/api/events` 是否成功
- `/api/teachers` 是否成功

### 3. 元素檢查
檢查元素是否存在：
```javascript
// 在控制台執行
document.getElementById('todayEventsSection')
document.getElementById('calendarSection')
document.getElementById('colorLegendPanel')
document.getElementById('todayEventsGrid')
document.getElementById('calendarView')
```

### 4. 函數檢查
檢查函數是否定義：
```javascript
// 在控制台執行
typeof changeTimeRange
typeof renderTodayEvents
typeof renderWeekCalendar
typeof renderMonthCalendar
typeof highlightEventCardFromCalendar
typeof renderColorLegend
```

### 5. 數據檢查
檢查數據是否載入：
```javascript
// 在控制台執行
allEvents.length  // 應該 > 0
COURSE_TYPE_COLORS  // 應該有課程顏色物件
instructorColors  // 應該有講師顏色物件
```
