### 1. 前端調用 (course-reminder-management.html)

**函數定義**（第 3540 行）：
```javascript
async function loadStudents() {
    try {
        const response = await fetch('/api/students', {
            timeout: 10000
        });
        
        if (response.ok) {
            const data = await response.json();
            students = data.data || [];  // ✅ 獲取學生陣列
            console.log('✅ 成功載入學生資料，數量:', students.length);
            return students;
        }
    } catch (error) {
        console.error('❌ 載入學生資料失敗:', error);
        students = [];
        return [];
    }
}
```

**調用時機**：
1. 頁面初始化時（第 2936 行）
2. 載入學生提醒時（第 3596 行）
3. 生成學生提醒時（第 6517 行）

### 2. 後端 API (server.js)

**路由定義**（第 3672 行）：
```javascript
app.get('/api/students', (req, res) => {
  try {
    console.log('👨‍🎓 獲取學生資料...');
    
    // ✅ 固定讀取 public/student_data.json
    const studentDataPath = path.join(__dirname, 'public', 'student_data.json');
    
    if (!fs.existsSync(studentDataPath)) {
      return res.status(404).json({
        success: false,
        message: '學生資料檔案不存在',
        data: []
      });
    }
    
    // ✅ 解析 JSON 檔案
    const studentData = JSON.parse(fs.readFileSync(studentDataPath, 'utf8'));
    console.log('✅ 成功讀取學生資料，數量:', studentData.students.length);
    
    // ✅ 返回學生陣列
    res.json({
      success: true,
      data: studentData.students || []
    });
  } catch (error) {
    console.error('❌ 讀取學生資料失敗:', error);
    res.status(500).json({
      success: false,
      message: '讀取學生資料失敗',
      data: []
    });
  }
});
```

## ⚠️ 發現並修復的問題

### 問題：重複的 API 路由定義

**原始狀態**：
- ❌ 第 3672 行：第一個 `/api/students` 路由（正常使用）
- ❌ 第 5384 行：第二個 `/api/students` 路由（**永遠不會執行**）

**問題原因**：
- Express.js 遇到相同路由時，只會使用第一個匹配的
- 第二個路由永遠不會被執行，造成程式碼冗餘

**修復方案**：
```diff
- // 第 5384-5407 行：重複的路由定義
- app.get('/api/students', (req, res) => { ... });

+ // 第 5382 行：註解說明
+ // 注意：/api/students 路由已在第 3672 行定義，此處不需重複
```

**修復結果**：
- ✅ 刪除重複路由定義
- ✅ 保留唯一的路由（第 3672 行）
- ✅ 程式碼更清晰，避免混淆
