### 1️⃣ 主要課程列表排序邏輯
**檔案位置**: `perfect-calendar-optimized-complete2.html` (第 14758-14782 行)

**新排序規則**:
```javascript
// 排序課程：越靠近當前時間的課程排在越上面（包含已結束的課程）
filteredEvents.sort((a, b) => {
    const now = new Date();
    const eventA = new Date(a.start);
    const eventB = new Date(b.start);
    const endA = new Date(a.end);
    const endB = new Date(b.end);
    
    // 判斷課程是否正在進行中
    const isEventAOngoing = eventA <= now && endA > now;
    const isEventBOngoing = eventB <= now && endB > now;
    
    // 正在進行中的課程，距離為 0（最優先）
    const distanceA = isEventAOngoing ? 0 : Math.abs(now - eventA);
    const distanceB = isEventBOngoing ? 0 : Math.abs(now - eventB);
    
    // 按照距離當前時間的遠近排序（距離越小越靠前）
    // 這會讓剛結束的課程和即將開始的課程都按距離排序
    if (distanceA !== distanceB) {
        return distanceA - distanceB;
    }
    
    // 如果距離相同，按開始時間排序（時間較早的在前）
    return eventA - eventB;
});
```

### 2️⃣ 今日課程區塊排序邏輯
**檔案位置**: `perfect-calendar-optimized-complete2.html` (第 8951-8974 行)

**新排序規則**: 與主要課程列表使用相同的排序邏輯

## 🎯 排序邏輯說明

### 優先順序
1. **正在進行中的課程** → 距離 = 0，最優先顯示
2. **其他課程（已結束 + 即將開始）** → 按距離當前時間的遠近排序

### 範例場景
假設現在是 **2025/10/19 15:00**

**課程列表**:
- 課程A: 14:30-15:30 (進行中) → 距離 = 0
- 課程B: 15:30-16:30 (30分鐘後開始) → 距離 = 30分鐘
- 課程C: 14:00-14:30 (30分鐘前結束) → 距離 = 30分鐘
- 課程D: 16:30-17:30 (90分鐘後開始) → 距離 = 90分鐘
- 課程E: 13:00-13:30 (90分鐘前結束) → 距離 = 90分鐘

**排序結果**:
1. 課程A (進行中)
2. 課程B (距離 30分鐘，未來)
3. 課程C (距離 30分鐘，過去)
4. 課程D (距離 90分鐘，未來)
5. 課程E (距離 90分鐘，過去)
