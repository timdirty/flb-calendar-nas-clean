核心問題：

2. 前端顯示時沒有正確轉換為台灣時間
3. courseDate 和 courseTime 的顯示也可能有時區問題

=== 立即修復方案 ===

修復關鍵點：
1. 所有顯示 scheduledTime 的地方，使用 formatToTaiwanTime() 函數
2. 所有顯示 courseDate + courseTime 的地方，確保是台灣時間
3. 倒數計時器要使用台灣時間計算

=== 前端修復 ===

在 course-reminder-management.html 中添加或修改以下函數：

```javascript
// 格式化台灣時間顯示
function formatToTaiwanTime(dateStr) {
    if (!dateStr) return '未設定';
    
    try {
        const date = new Date(dateStr);
        if (isNaN(date.getTime())) return dateStr;
        
        return date.toLocaleString('zh-TW', {
            timeZone: 'Asia/Taipei',
            year: 'numeric',
            month: '2-digit',
            day: '2-digit',
            hour: '2-digit',
            minute: '2-digit',
            second: '2-digit',
            hour12: false
        });
    } catch (error) {
        console.error('時間格式化錯誤:', error);
        return dateStr;
    }
}

// 格式化課程時間顯示
function formatCourseDateTime(courseDate, courseTime) {
    if (!courseDate) return '未設定';
    
    try {
        // courseDate 格式: "2025-10-11"
        // courseTime 格式: "10:00" 或 "10:00:00"
        
        const [year, month, day] = courseDate.split('-').map(Number);
        const timeParts = courseTime.split(':');
        const hour = parseInt(timeParts[0]);
        const minute = parseInt(timeParts[1]);
        
        // 創建本地時間（已經是台灣時間）
        const dateTime = new Date(year, month - 1, day, hour, minute, 0);
        
        return dateTime.toLocaleString('zh-TW', {
            timeZone: 'Asia/Taipei',
            year: 'numeric',
            month: '2-digit',
            day: '2-digit',
            hour: '2-digit',
            minute: '2-digit',
            hour12: false
        });
    } catch (error) {
        console.error('課程時間格式化錯誤:', error);
        return `${courseDate} ${courseTime}`;
    }
}
```

3. 倒數計時器：
```javascript
function updateCountdown() {
    const now = getTaiwanNow(); // 使用台灣時間
    
    reminders.forEach(reminder => {
        if (!reminder.scheduledTime) return;
        
        // 將 scheduledTime 轉為台灣時間
        const scheduledDate = new Date(reminder.scheduledTime);
        const diff = scheduledDate.getTime() - now.getTime();
        
        // 計算時分秒
        const hours = Math.floor(diff / 3600000);
        const minutes = Math.floor((diff % 3600000) / 60000);
        const seconds = Math.floor((diff % 60000) / 1000);
        
        // 更新顯示
        const countdownEl = document.querySelector(`[data-countdown="${reminder.id}"]`);
        if (countdownEl) {
            if (diff > 0) {
                countdownEl.textContent = `${hours}:${minutes.toString().padStart(2, '0')}:${seconds.toString().padStart(2, '0')}`;
            } else {
                countdownEl.textContent = '已到時間';
            }
        }
    });
}
```

=== 後端修復（如果需要）===

如果後端返回的 scheduledTime 是錯誤的，需要修改 server.js：

```javascript
// 在返回提醒數據前，確保 scheduledTime 是正確的台灣時間
reminders = reminders.map(reminder => {
    if (reminder.scheduledTime) {
        // 如果是字串，轉為 Date 對象
        const scheduledDate = new Date(reminder.scheduledTime);
        
        // 轉換為 ISO 字串（包含時區信息）
        reminder.scheduledTime = scheduledDate.toISOString();
    }
    
    return reminder;
});
```
