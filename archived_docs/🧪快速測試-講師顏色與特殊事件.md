### 測試 1：講師顏色穩定性

#### 步驟 1：檢查後端 API

2. 記下每位講師的顏色
3. 按 `Ctrl+Shift+R` 強制重新載入
4. 檢查講師顏色是否相同

- 每次載入顏色都相同
- 顏色與 API 返回的一致

## 🔍 快速診斷

### 問題：講師顏色每次都不同

#### 診斷步驟
1. 打開瀏覽器開發者工具（F12）
2. 切換到 Console 標籤
3. 重新載入頁面
4. 搜索以下訊息：

**✅ 應該看到**：
```
👨‍🏫 從後端載入講師顏色配置...
✅ 使用 API 載入講師顏色
✅ 講師顏色載入成功: {...}
✅ 已從後端載入講師顏色配置，共 X 位講師
```

**❌ 不應該看到**：
```
🎨 從後端載入失敗，使用隨機顏色
generateRandomInstructorColors()
```

#### 解決方案
如果看到使用隨機顏色：

1. **檢查 API**：
```bash
curl http://localhost:3002/api/teachers
```

2. **檢查 teacher_data.json 格式**：
```bash
cat teacher_data.json | jq
```

3. **重啟伺服器**：
```bash
npm restart
```

### 問題：特殊事件沒有外框顏色

#### 診斷步驟
1. 打開開發者工具
2. 檢查事件元素
3. 查看 `style` 屬性

**✅ 應該看到**：
```html
<div class="event-chip has-special-event" 
     style="background: ...; border: 3px solid rgba(220, 53, 69, 0.5); box-shadow: 0 0 8px rgba(220, 53, 69, 0.3);"
     data-event-type="停課">
```

**❌ 不應該看到**：
```html
<div class="event-chip" 
     style="background: ...;"
     data-event-type="">
```

#### 解決方案
如果沒有 border 樣式：

1. **確認特殊事件檢測**：
```javascript
// 在 Console 中執行
window.detectSpecialEventType('停課通知')
// 應該返回: "停課"
```

2. **確認外框顏色函數**：
```javascript
// 在 Console 中執行
window.getSpecialEventBorderColors('停課')
// 應該返回: {color: "rgba(220, 53, 69, 0.5)", ...}
```

3. **清除快取並重新載入**：
```
Ctrl+Shift+R (Windows/Linux)
Cmd+Shift+R (Mac)
```
