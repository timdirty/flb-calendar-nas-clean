🔧 立即修復學生簽到權限問題
================================

請在 NAS 上依序執行以下指令：

1️⃣ 進入專案目錄
-----------------------------------
cd /volume1/homes/ctctim14/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas


2️⃣ 賦予執行權限
-----------------------------------
chmod +x 🔧修復學生簽到權限-正確版.sh


3️⃣ 執行修復腳本
-----------------------------------
bash 🔧修復學生簽到權限-正確版.sh


📝 腳本會自動：
- 備份檔案
- 修改權限為 666
- 重啟 Docker 容器
- 驗證修復結果


⚡ 或者手動快速修復（單行指令）
================================
cd /volume1/homes/ctctim14/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas && chmod 666 public/student_data.json && sudo docker-compose restart


🧪 修復後測試
================================
1. 打開前端頁面
2. 長按課程 → 打開學生簽到
3. 簽到幾位學生
4. 關閉頁面
5. 重新長按相同課程
6. 確認簽到狀態是否保留 ✅


❓ 如果還有問題
================================
查看日誌：
sudo docker-compose logs --tail=50 | grep -E "(EACCES|permission|student_data)"

如果沒有任何輸出 = 權限問題已解決！
