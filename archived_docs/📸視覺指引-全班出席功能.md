## 🎬 使用流程動畫

### Step 1: 打開簽到頁面
```
長按課程 (1.5秒)
    ↓
┌─────────────┐
│ 課程簽到系統 │
└─────────────┘
```

### Step 2: 找到全班出席按鈕
```
👥 學生名單 (5 人)    [✅✅ 全班出席]
                           ↑
                      點擊這裡！
```

### Step 3: 處理過程
```
[🔄 處理中...]
    ↓
學生 1: ✅ 標記出席
學生 2: ✅ 標記出席
學生 3: ✓ 已出席，跳過
學生 4: ✅ 標記出席
學生 5: ✅ 標記出席
```

### Step 4: 完成通知
```
┌───────────────────────────┐
│ ✅ 已標記 4 位學生出席    │
└───────────────────────────┘
```

### Step 5: 統計更新
```
✅ 出席: 5  ❌ 缺席: 0  ⚠️ 請假: 0  ⏰ 待簽: 0
  ↑
自動更新！
```

## 💡 視覺提示

### 按鈕位置記憶法
```
👥 學生名單標題
    └─ 右側就是「全班出席」按鈕

記住：標題和按鈕在同一行！
```

### 顏色辨識
```
✅ 綠色按鈕 = 全班出席功能
✅ 綠色學生卡片 = 已出席學生
⏰ 灰色按鈕 = 課程尚未開始（禁用）
```

## 🎬 動畫效果

### 按鈕懸浮動畫
```
transform: scale(1)
          ↓
     滑鼠移入
          ↓
transform: scale(1.05)  ← 放大 5%
```

### 處理中動畫
```
🔄 (旋轉 0°)
    ↓
🔄 (旋轉 90°)
    ↓
🔄 (旋轉 180°)
    ↓
🔄 (旋轉 270°)
    ↓
🔄 (旋轉 360°) → 循環
```

### Toast 通知動畫
```
   (隱藏)
     ↓
  淡入 + 滑入
     ↓
  停留 3 秒
     ↓
  淡出 + 滑出
     ↓
   (消失)
```

## 📊 處理速度視覺化

```
學生數量    處理時間    視覺感受
─────────────────────────────────
  5 人      < 1 秒      ⚡ 瞬間完成

 20 人      3-4 秒      ⏳ 稍微等待
 25+ 人     4-5 秒      ⏰ 需要耐心
```
