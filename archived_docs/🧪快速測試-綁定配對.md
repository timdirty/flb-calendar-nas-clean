## 📊 效能基準

### 正常網速（4G/WiFi）
```
✅ 載入進度：0% → 100%
   預期時間：2-3 秒
   
✅ 配對過程：等待下拉選單
   預期等待：1-5 次（100-500ms）
   
✅ 進入畫面：100% → 顯示
   預期延遲：150-300ms
   
📈 總時間：< 3 秒
```

### 慢速網路（3G）
```
⏳ 載入進度：0% → 100%
   預期時間：5-8 秒
   
⏳ 配對過程：等待下拉選單
   預期等待：10-20 次（1-2秒）
   
⚠️ 超時處理：最多等待 2 秒
   
📈 總時間：< 10 秒（含超時處理）
```

## ❌ 常見問題排查

### 問題1：仍然配對失敗
**症狀：** 沒有自動配對，需要手動選擇

**檢查：**
1. Console 是否顯示「等待下拉選單」？
2. 是否顯示「下拉選單載入超時」？
3. 網路是否極慢？

**解決：**
- 如果超時：增加 maxWait（第8533行）
- 如果沒有等待：檢查修復是否正確部署

### 問題2：載入很慢
**症狀：** 超過 5 秒才進入

**檢查：**
1. 網路速度（DevTools → Network）
2. LIFF 初始化時間
3. API 回應時間

**解決：**
- 檢查 NAS 網路連接
- 檢查 LIFF 設定
- 查看伺服器日誌

### 問題3：載入卡住
**症狀：** 卡在某個進度不動

**檢查：**
1. Console 錯誤訊息
2. Network 請求狀態
3. 是否有 JavaScript 錯誤

**解決：**
- 重新整理頁面
- 清除所有快取
- 檢查伺服器狀態
