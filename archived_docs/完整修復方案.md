# 🔧 完整修復方案 - 管理控制台問題

## 🎯 發現的問題

### 1. LINE 通知發送失敗 ❌
**錯誤訊息**: `Request failed with status code 500`

**根本原因**:
- `LINE_CHANNEL_ACCESS_TOKEN` 環境變數未設定
- LINE API 無法發送訊息

**影響範圍**:
- 學生提醒發送失敗
- 課程提醒發送失敗
- 所有 LINE 通知功能

### 2. 講師管理顯示 [object Object] ❌
**問題**:
- 講師列表顯示 `[object Object]` 而非實際資料
- LINE User ID 欄位未正確顯示

**根本原因**:
- `teacher_data.json` 格式問題
- 前端未正確解析講師物件

### 3. 訊息模板管理不完整 ❌
**問題**:
- 只有學生簽到和課程提醒模板
- 缺少其他通知類型的模板

**缺少的模板**:
- 當日提醒
- 隔日提醒
- 課前提醒
- 系統通知
- 錯誤通知

### 4. API 端點缺失 ⚠️
**缺少的 API**:
- `POST /api/teachers` - 新增講師
- `PUT /api/teachers/:id` - 更新講師
- `DELETE /api/teachers/:id` - 刪除講師
- `POST /api/templates` - 新增模板
- `PUT /api/templates/:id` - 更新模板
- `DELETE /api/templates/:id` - 刪除模板

## ✅ 修復方案

### 方案 1: 設定 LINE Channel Access Token

#### 步驟 1: 取得 LINE Channel Access Token
1. 登入 [LINE Developers Console](https://developers.line.biz/console/)
2. 選擇您的 Messaging API Channel
3. 在 "Messaging API" 分頁找到 "Channel access token"
4. 複製 Token

#### 步驟 2: 更新 .env.nas 檔案
```bash
# 在 NAS 上執行
cd /volume1/homes/ctctim14/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas

# 編輯 .env.nas
vi .env.nas
```

添加以下行：
```env
LINE_CHANNEL_ACCESS_TOKEN=您的_Channel_Access_Token
```

#### 步驟 3: 重啟服務
```bash
sudo docker-compose down
sudo docker-compose up -d
```
