# 📖 學習歷程上傳系統 - 快速開始指南

## 🚀 一鍵部署

```bash
./🚀立即部署-學習歷程系統.sh
```

## 📱 講師使用流程

### 1. 進入系統
訪問主行事曆頁面，點擊 **「學習歷程上傳」** 按鈕

```
http://localhost:3002/perfect-calendar-optimized-complete2.html
```

### 2. 選擇課程
- 系統自動顯示 **今天已結束的課程**
- 點擊要上傳的課程卡片

### 3. 上傳學生記錄

為每個學生上傳：

#### 📸 照片（至少 3 張）
- 點擊或拖放照片到上傳區
- 支援格式：JPG, PNG, HEIC
- 最大 5MB/張

#### 🎥 影片（至少 1 個）
- 點擊或拖放影片到上傳區
- 支援格式：MP4, MOV, AVI
- 最大 50MB/個

#### 💬 評語（至少 20 字）
- 在文字框輸入評語
- 系統會即時顯示字數

#### ✅ 完成上傳
- 三項要求都滿足後，上傳按鈕會啟用
- 點擊「上傳學習記錄」
- 等待上傳完成提示

### 4. 上傳課程總覽（選填）

- 上傳課程照片（不限張數）
- 填寫課程摘要
- 點擊「上傳課程總覽」

### 5. 查看歷史記錄

- 點擊右上角「查看歷史記錄」
- 使用篩選器查詢
- 查看已上傳的記錄

## 🗓️ 學期自動判斷

系統會根據當前月份自動判斷學期：

| 月份 | 學期資料夾 | 說明 |
|------|-----------|------|
| 1-2月 | `冬令營-2025` | 寒假營隊 |
| 3-6月 | `113-2` | 下學期 |
| 7-8月 | `夏令營-2025` | 暑期營隊 |
| 9-12月 | `114-1` | 上學期 |

## ⚠️ 注意事項

### 上傳要求
- ✅ **照片**: 至少 3 張，最多 10 張
- ✅ **影片**: 至少 1 個，最多 5 個
- ✅ **評語**: 至少 20 個字

### 檔案限制
- 📸 照片：JPG, PNG, HEIC（最大 5MB）
- 🎥 影片：MP4, MOV, AVI（最大 50MB）

### 瀏覽器支援
- ✅ Chrome 90+
- ✅ Safari 14+
- ✅ Firefox 88+
- ✅ Edge 90+

## 🔧 常見問題

### Q: 為什麼找不到今天的課程？
**A:** 只有已結束的課程才會顯示。請確認：
1. 課程結束時間已過
2. 課程存在於行事曆系統中
3. 嘗試點擊「重新整理」按鈕

### Q: 上傳按鈕為什麼無法點擊？
**A:** 請檢查是否滿足所有要求：
- ✅ 至少 3 張照片
- ✅ 至少 1 個影片  
- ✅ 至少 20 字評語

### Q: 上傳失敗怎麼辦？
**A:** 
1. 檢查網路連線
2. 確認檔案格式和大小
3. 查看錯誤訊息提示
4. 點擊「上傳學習記錄」重試

### Q: 可以重新上傳嗎？
**A:** 可以！已上傳的記錄可以：
- 查看歷史記錄
- 補充更多照片/影片
- 更新評語

### Q: 如何查看已上傳的記錄？
**A:** 
1. 點擊「查看歷史記錄」按鈕
2. 使用篩選器（學期/課程/日期）
3. 點擊記錄查看詳情
