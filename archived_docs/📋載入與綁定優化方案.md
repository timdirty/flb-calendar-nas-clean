# 📋 載入與綁定優化方案

**日期**: 2025-10-17  
**問題**: 載入慢 + 綁定不穩定

---

## 🔴 當前問題

### 1. 載入速度慢
```
載入流程：
DOMContentLoaded 
→ initializeSystemOptimized()
→ loadEventsOptimized()
  → 檢查快取 (30分鐘過期)
  → 後端快取未就緒？等待最多 40秒 ⏱️
  → fetch('/api/events', timeout 35秒) ⏱️
→ processEventsData()
  → 設置 dataLoadingComplete = true
→ autoMatchTeacher()
  → waitForDataLoading(10秒) ⏱️
  → 比對邏輯...

總計：最差情況 40 + 35 + 10 = 85 秒！
```

### 2. 綁定機制不穩定
- `autoMatchTeacher` 必須等待 `waitForDataLoading`
- 如果 `processEventsData` 還沒完成，`waitForDataLoading` 可能超時
- 超時後雖然會顯示綁定選單，但體驗不佳

---

## ✅ 優化策略

### 階段 1：減少不必要的等待

#### 1.1 優化後端快取等待時間
```javascript
// 修改前：等待 40 秒
const maxWaitTime = 40000;

// 修改後：減少為 15 秒
const maxWaitTime = 15000; // 足夠建立快取
```

#### 1.2 優化輪詢間隔
```javascript
// 修改前：每 2 秒檢查
await new Promise(resolve => setTimeout(resolve, 2000));

// 修改後：每 500ms 檢查（更快響應）
await new Promise(resolve => setTimeout(resolve, 500));
```

#### 1.3 優化 fetch timeout
```javascript
// 修改前：35 秒
timeout: 35000

// 修改後：20 秒（配合後端快取）
timeout: 20000
```

### 階段 2：改進綁定觸發機制

#### 2.1 使用事件驅動取代輪詢
```javascript
// 當前：waitForDataLoading 使用輪詢
const checkInterval = setInterval(() => {
    if (window.dataLoadingComplete && allEvents.length > 0 && allInstructors.length > 0) {
        resolve(true);
    }
}, 100);

// 優化：processEventsData 完成後立即觸發事件
function processEventsData(data) {
    // ... 處理資料 ...
    
    // 設置完成標記
    window.dataLoadingComplete = true;
    
    // 🔥 立即觸發自定義事件
    window.dispatchEvent(new CustomEvent('dataLoadingComplete', {
        detail: {
            eventsCount: allEvents.length,
            instructorsCount: allInstructors.length
        }
    }));
    
    // 解析等待的 Promise
    if (window.dataLoadingPromiseResolve) {
        window.dataLoadingPromiseResolve();
        window.dataLoadingPromiseResolve = null;
    }
}

// 修改 waitForDataLoading
async function waitForDataLoading(timeout = 10000) {
    // 如果已經載入完成，直接返回
    if (window.dataLoadingComplete && allEvents.length > 0 && allInstructors.length > 0) {
        console.log('✅ 資料已載入完成');
        return true;
    }
    
    // 🔥 使用事件監聽取代輪詢
    return new Promise((resolve, reject) => {
        const timeoutId = setTimeout(() => {
            cleanup();
            console.warn('⏰ 等待資料載入超時');
            reject(new Error('等待資料載入超時'));
        }, timeout);
        
        function onDataLoaded(event) {
            cleanup();
            console.log('✅ 接收到資料載入完成事件', event.detail);
            resolve(true);
        }
        
        function cleanup() {
            clearTimeout(timeoutId);
            window.removeEventListener('dataLoadingComplete', onDataLoaded);
        }
        
        // 監聽載入完成事件
        window.addEventListener('dataLoadingComplete', onDataLoaded, { once: true });
    });
}
```

### 階段 4：添加視覺反饋

```javascript
// 在載入期間顯示詳細進度
function addLoadingLog(message, type = 'info') {
    console.log(`[${type}] ${message}`);
    
    // 在 UI 顯示
    const logContainer = document.getElementById('loadingLogs');
    if (logContainer) {
        const logEntry = document.createElement('div');
        logEntry.className = `loading-log-entry ${type}`;
        logEntry.innerHTML = `
            <span class="log-time">${new Date().toLocaleTimeString('zh-TW')}</span>
            <span class="log-message">${message}</span>
        `;
        logContainer.appendChild(logEntry);
        
        // 自動滾動到底部
        logContainer.scrollTop = logContainer.scrollHeight;
    }
}
```
