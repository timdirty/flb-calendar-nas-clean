# ❌ 學生簽到不保存問題 - 完整修復方案

## 📌 問題描述
學生簽到完成後，重新打開簽到頁面，所有學生又變成「待簽到」狀態，資料沒有正確保存到 `student_data.json`。

---

## 🔍 問題根源（最可能）

### ⚠️ 檔案路徑不一致
系統中有**兩個** `student_data.json` 檔案：
1. `/volume1/web/flb-calendar/public/student_data.json`（前端讀取）
2. `/volume1/docker/flb-calendar-nas/public/student_data.json`（後端寫入）

**問題**：
- 當學生簽到時，後端更新 Docker 目錄的檔案
- 當重新打開簽到頁面時，前端讀取 Web 目錄的檔案（舊資料）
- 兩個檔案不同步，導致簽到記錄"丟失"

---

## 🚀 快速修復（3 步驟）

### 方法 1：使用自動修復腳本 ✅ **推薦**

在 NAS 上執行：

```bash
cd /volume1/docker/flb-calendar-nas

# 執行診斷
bash 🔍診斷學生簽到保存.sh

# 如果診斷發現問題，執行自動修復
bash 🔧自動修復學生簽到保存.sh
```

腳本會自動：
- ✅ 備份現有檔案
- ✅ 統一兩個 `student_data.json` 檔案（使用軟連結）
- ✅ 修復檔案權限
- ✅ 重啟服務（如需要）

---

### 方法 2：手動修復

#### 步驟 1：備份檔案
```bash
# 創建備份目錄
mkdir -p /volume1/docker/flb-calendar-nas/backups

# 備份兩個檔案
cp /volume1/web/flb-calendar/public/student_data.json \
   /volume1/docker/flb-calendar-nas/backups/student_data_web_$(date +%Y%m%d).json

cp /volume1/docker/flb-calendar-nas/public/student_data.json \
   /volume1/docker/flb-calendar-nas/backups/student_data_docker_$(date +%Y%m%d).json
```

#### 步驟 2：建立軟連結統一檔案
```bash
# 刪除舊的 Docker 檔案（如果存在）
rm -f /volume1/docker/flb-calendar-nas/public/student_data.json

# 建立軟連結，讓 Docker 目錄指向 Web 目錄
ln -s /volume1/web/flb-calendar/public/student_data.json \
      /volume1/docker/flb-calendar-nas/public/student_data.json

# 驗證連結
ls -lh /volume1/docker/flb-calendar-nas/public/student_data.json
```

#### 步驟 3：修復權限
```bash
# 確保檔案可讀寫
chmod 666 /volume1/web/flb-calendar/public/student_data.json

# 確保所有者正確
chown http:http /volume1/web/flb-calendar/public/student_data.json
```

#### 步驟 4：重啟服務
```bash
# 找到 server.js 進程
ps aux | grep "node.*server.js"

# 重啟（假設 PID 是 12345）
kill 12345
sleep 2
cd /volume1/docker/flb-calendar-nas
nohup node server.js > server.log 2>&1 &
```

## 🐛 其他可能的問題

### 問題 2：檔案權限不足
**症狀**：Console 顯示 `500 Internal Server Error`

**修復**：
```bash
chmod 666 /volume1/web/flb-calendar/public/student_data.json
chown http:http /volume1/web/flb-calendar/public/student_data.json
```

### 問題 3：後端服務未運行
**症狀**：Console 顯示 `Failed to fetch` 或 `ERR_CONNECTION_REFUSED`

**修復**：
```bash
# 檢查服務狀態
ps aux | grep "node.*server.js"

# 如果沒有運行，啟動服務
cd /volume1/docker/flb-calendar-nas
nohup node server.js > server.log 2>&1 &
```

### 問題 4：API 端點錯誤
**症狀**：Console 顯示 `404 Not Found` 或 `Cannot POST /api/update-student-attendance`

**修復**：
1. 檢查 `server.js` 是否有 `/api/update-student-attendance` 端點
2. 確認 server.js 檔案完整無誤
3. 重新啟動服務
