# 🧪 快速測試 - 學生資料自動更新

## 📋 測試目的
驗證學生資料自動從 Google Sheets 更新的功能正常運作

---

## 🚀 前置準備

### 1. 確認已部署
```bash
cd /volume1/docker/flb-calendar

# 檢查服務狀態
docker-compose ps

# 應該看到服務正在運行
```

### 2. 確認設定檔
```bash
cat system-settings.json | jq .studentDataSync
```

**預期輸出**:
```json
{
  "enabled": true,
  "autoUpdateEnabled": true,
  "updateTime": "02:00",
  "intervalMinutes": 0,
  "retryMaxAttempts": 3,
  "retryDelaySeconds": 60,
  "logUpdates": true
}
```

- ✅ 檔案修改時間已更新

## ✅ 測試 4：停止和啟動排程

### 測試步驟

### 通過條件

- ✅ 啟動後 `hasSchedule` 變為 `true`

## ❌ 故障排除

### 問題 1：hasSchedule 為 false

**原因**: 可能是 updateTime 格式錯誤

**檢查**:
```bash
cat system-settings.json | jq .studentDataSync.updateTime
```

**修復**:
```bash
# 確保格式為 "HH:MM"
curl -X POST http://localhost:3000/api/student-data-sync/settings \
  -H "Content-Type: application/json" \
  -d '{"updateTime":"02:00"}'
```

### 問題 2：手動觸發失敗

**檢查**:
```bash
# 查看詳細錯誤
curl -X POST http://localhost:3000/api/student-data-sync/trigger -v
```

**常見原因**:
- Google Sheets API URL 錯誤
- 網路連線問題
- Cookie 過期

### 問題 3：日誌中沒有啟動訊息

**檢查**:
```bash
# 檢查服務是否正常啟動
docker-compose logs | head -50

# 應該看到：
# ✅ 已啟動學生資料每日自動更新 (每天 02:00)
```

**修復**:
```bash
docker-compose restart
```

## 📋 完整測試流程腳本

```bash
#!/bin/bash

echo "================================"
echo "🧪 學生資料自動更新測試"
echo "================================"
echo ""

# 測試 1
echo "測試 1：檢查排程狀態"
curl -s http://localhost:3000/api/system-status | jq .data.studentDataSync
echo ""

# 測試 2
echo "測試 2：手動觸發更新"
echo "更新前："
ls -lh public/student_data.json
curl -X POST http://localhost:3000/api/student-data-sync/trigger
sleep 2
echo "更新後："
ls -lh public/student_data.json
echo ""

# 測試 3
echo "測試 3：查看日誌"
docker-compose logs --tail=20 | grep "學生資料"
echo ""

# 測試 4
echo "測試 4：停止排程"
curl -X POST http://localhost:3000/api/student-data-sync/stop
sleep 1
echo "狀態："
curl -s http://localhost:3000/api/system-status | jq .data.studentDataSync.hasSchedule
echo ""

echo "啟動排程"
curl -X POST http://localhost:3000/api/student-data-sync/start
sleep 1
echo "狀態："
curl -s http://localhost:3000/api/system-status | jq .data.studentDataSync.hasSchedule
echo ""

echo "================================"
echo "✅ 測試完成"
echo "================================"
```

**儲存為**: `test-auto-sync.sh`

**執行**:
```bash
chmod +x test-auto-sync.sh
./test-auto-sync.sh
```
