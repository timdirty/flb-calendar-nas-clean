# 📖 快速開始 - 設定管理功能

## 🚀 立即開始

### 1. 部署到系統
```bash
# 執行部署腳本
./🚀部署-系統設定管理.sh
```

1. 開啟行事曆系統

3. 設定面板自動彈出

## 📚 三大功能

### ✅ 功能1：講師資料管理

**管理檔案：** `teacher_data.json`

**操作步驟：**
1. 點擊「📚 講師資料」分頁
2. 查看目前所有講師

**新增講師：**
```
點擊「➕ 新增講師」
→ 填寫姓名和 User ID
→ 點擊「💾 儲存」
```

**編輯講師：**
```
直接在表格中修改
→ 點擊「💾 儲存」
```

**刪除講師：**
```
點擊「🗑️ 刪除」
→ 確認刪除
→ 點擊「💾 儲存」
```

**範例資料：**
| 講師姓名 | User ID |
|---------|---------|
| YOKI | Ucf9b239b708001ed44f0710704282655 |
| TED | U213b36e8024ab1d2b895b24082c21270 |

### ✅ 功能3：系統設定管理

**管理檔案：** `system-settings.json`

**操作步驟：**
1. 點擊「⚙️ 系統設定」分頁
2. 查看所有系統設定

**修改設定：**
```
找到要修改的設定
→ 修改數值
→ 點擊「💾 儲存」（立即生效）
```

**重置設定：**
```
點擊「🔄 重置」
→ 恢復到目前檔案中的值
```

**主要設定項目：**

#### ⏰ 提醒時間設定
```json
{
  "reminders": {
    "todayReminderHour": 8,         // 今日提醒時間（小時）
    "todayReminderMinute": 0,       // 今日提醒時間（分鐘）
    "tomorrowReminderHour": 19,     // 隔日提醒時間（小時）
    "tomorrowReminderMinute": 30,   // 隔日提醒時間（分鐘）
    "beforeClassMinutes": 30        // 課前提醒時間（分鐘）
  }
}
```

#### 🌏 時區設定
```json
{
  "timezone": {
    "offset": 8,                    // 時區偏移（GMT+8）
    "name": "Asia/Taipei"           // 時區名稱
  }
}
```

#### 📅 排程器設定
```json
{
  "scheduler": {
    "checkInterval": 5,             // 檢查間隔（分鐘）
    "timeout": 60000,               // 超時時間（毫秒）
    "retryDelay": 1000              // 重試延遲（毫秒）
  }
}
```

## ⚡ 快速操作

### 場景1：新增一位講師

```
1. 點擊「設定」按鈕
2. 選擇「講師資料」分頁
3. 點擊「新增講師」
4. 填寫：
   - 姓名：ALICE
   - User ID：U1234567890abcdef
5. 點擊「儲存」
6. 關閉設定面板
7. 完成！
```

### 場景2：修改提醒時間

```
1. 點擊「設定」按鈕
2. 選擇「系統設定」分頁
3. 找到「reminders」區域
4. 修改：
   - todayReminderHour：改為 9（早上9點提醒）
   - tomorrowReminderHour：改為 20（晚上8點提醒）
5. 點擊「儲存」
6. 設定立即生效！
```

### 場景3：更新講師 API 網址

```
1. 點擊「設定」按鈕
2. 選擇「講師列表」分頁
3. 找到要修改的講師
4. 更新「Web API」或「讀報表 API」欄位
5. 點擊「儲存」
6. 完成！
```

## 🎯 常見使用情境

### 情境1：講師離職
```

```

```
4. 儲存

（可選）如果講師需要報表功能：
5. 開啟「講師列表」
6. 新增講師列表項目（含 API 網址）
7. 儲存
```

### 情境3：調整提醒時間
```
✅ 解決方案：
1. 開啟「系統設定」
2. 修改 reminders 相關設定
3. 儲存
4. 設定立即生效！
```

## ⚠️ 重要提示

### ✅ 自動備份
- 每次儲存時，系統會自動備份舊檔案
- 備份檔案格式：`檔名.backup-時間戳記`
- 例如：`teacher_data.json.backup-1698765432000`

### ✅ 變更生效時間
- **講師資料/列表：** 需要用戶重新載入頁面
- **系統設定：** 立即生效（無需重啟）

### ✅ User ID 格式
- 正確格式：`U` + 32位英數字
- 範例：`Ucf9b239b708001ed44f0710704282655`
- 可從 LINE 開發者控制台取得

### ✅ 安全性
- 建議只讓管理員使用設定功能
- 定期備份重要配置文件
- 謹慎刪除資料

## 🔍 故障排除

### 問題：點擊設定按鈕沒反應
```bash
# 解決方案1：檢查 JS 是否載入
開啟瀏覽器 Console
輸入：typeof SettingsManager
應該顯示：'function'

# 解決方案2：清除快取
Ctrl + Shift + R（強制重新載入）
```

### 問題：儲存失敗
```bash
# 解決方案1：檢查伺服器日誌
docker-compose logs -f --tail=50

# 解決方案2：檢查檔案權限
ls -la teacher_data.json
ls -la public/teacher_list_data.csv
ls -la system-settings.json
```

### 問題：資料沒有更新
```javascript
// 解決方案：清除瀏覽器快取
localStorage.clear();
sessionStorage.clear();
location.reload();
```
