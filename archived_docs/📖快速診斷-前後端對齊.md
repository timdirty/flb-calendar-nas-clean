## 🔍 常見問題診斷

### 問題 1：講師顏色沒有顯示

#### 診斷步驟

**步驟 1**: 檢查後端 API
```bash
curl http://localhost:3002/api/teachers
```

**如果 API 正常但顏色仍未顯示**，檢查前端：

1. 打開瀏覽器開發者工具（F12）
2. 切換到 Console 標籤
3. 重新載入頁面
4. 查找以下訊息：

```
✅ 應該看到：
👨‍🏫 從後端載入講師顏色配置...
✅ 使用 API 載入講師顏色
✅ 講師顏色載入成功: { ... }
📋 共載入 X 位講師的顏色

❌ 如果看到：
❌ 載入講師顏色失敗: ...
⚠️ API 載入失敗，嘗試使用 JSON 文件: ...
```

**步驟 2**: 檢查 `teacher_data.json` 格式
```bash
cat teacher_data.json | jq
```

**正確格式**：
```json
{
  "teachers": [
    {
      "name": "講師A",
      "userId": "U1234567890abcdef",
      "color": "rgba(116, 185, 255, 0.8)"
    },
    {
      "name": "講師B", 
      "userId": "U9876543210fedcba",
      "color": "rgba(255, 118, 117, 0.8)"
    }
  ]
}
```

**步驟 3**: 重啟伺服器
```bash
npm restart
```

---

### 問題 2：特殊事件「改時間」沒有識別

#### 診斷步驟

**步驟 1**: 檢查 API 配置
```bash
curl http://localhost:3002/api/special-events-config | grep "改時間"
```

**應該看到**：
```
"改時間"
```

**步驟 2**: 檢查前端配置

打開 `perfect-calendar-optimized-complete2.html`，搜索：
```javascript
const SPECIAL_EVENT_TYPES = {
```

確認補課陣列包含「改時間」：
```javascript
"補課": ["補課", "調課", "延後", "提前", "改時間"]
```

**步驟 3**: 通過管理後台更新

1. 訪問 `http://localhost:3002/admin-dashboard.html`
2. 切換到「特殊事件」標籤
3. 檢查補課的關鍵字欄位
4. 如果沒有「改時間」，添加後點擊「儲存設定」

---

### 問題 3：管理後台 API 調用失敗

#### 診斷步驟

**步驟 1**: 檢查所有 API 端點
```bash
# 系統設定
curl http://localhost:3002/api/system-settings

# 講師資料
curl http://localhost:3002/api/teachers

# LINE 配置
curl http://localhost:3002/api/line-config

# Google API 配置
curl http://localhost:3002/api/google-api-config

# 特殊事件配置
curl http://localhost:3002/api/special-events-config
```

**步驟 2**: 查看伺服器日誌
```bash
tail -f server.log
```

**步驟 3**: 檢查網絡請求

在管理後台：
1. 打開開發者工具（F12）
2. 切換到 Network 標籤
3. 重新載入頁面
4. 查看失敗的請求
5. 點擊失敗的請求查看詳細錯誤

## 🛠️ 快速修復

### 修復 1：重置特殊事件配置
```bash
# 刪除現有配置（將使用預設值）
rm special-events-config.json

# 重啟伺服器
npm restart

# 通過管理後台重新設定
# 訪問 http://localhost:3002/admin-dashboard.html
```

### 修復 2：重新載入講師資料
```bash
# 檢查 JSON 格式
cat teacher_data.json | jq

# 如果格式錯誤，修復後重啟
npm restart
```

### 修復 3：清除快取
```bash
# 方法 1：使用 API
curl -X POST http://localhost:3002/api/cache/clear-all

# 方法 2：通過管理後台
# 訪問管理後台 → 快取管理 → 清除所有快取
```
