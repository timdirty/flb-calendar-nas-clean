## 🔧 修復的問題

### 問題 1：講師資訊未正確傳遞
**症狀：** 從日曆點擊「上傳學習歷程」後，顯示所有老師的課程

**原因：** `goToLearningRecordUpload()` 函數定義中沒有接收 `instructor` 參數

**修復：**
```javascript
// 修改前
function goToLearningRecordUpload(eventId, date, time) { ... }

// 修改後
function goToLearningRecordUpload(eventId, date, time, instructor = '') {
    let url = `/learning-record-upload.html?eventId=...&date=...&time=...`;
    if (instructor) {
        url += `&instructor=${encodeURIComponent(instructor)}`;
    }
    window.location.href = url;
}
```

### 問題 2：課程名稱提取邏輯不一致
**症狀：** 無法正確匹配學生資料

**原因：** 
- 前端使用簡單的正則提取
- 後端使用不同的邏輯
- 大小寫處理不一致

**修復：**
- 創建統一的課程名稱提取函數
- 支持多種格式（`—` 分隔符、大寫字母、空格分隔）
- 大小寫不敏感匹配

### 問題 3：學生資料匹配失敗
**症狀：** `Minecraft` 和 `MINECRAFT` 無法匹配

**原因：** 
- 前端提取為 `MINECRAFT`（全大寫）
- `student_data.json` 中是 `Minecraft`（首字母大寫）
- 比較時未使用大小寫不敏感

**修復：**
```javascript
// 大小寫不敏感匹配
const students = studentData.students.filter(student => {
    const studentCourse = (student.course || '').toUpperCase();
    const targetCourse = courseName.toUpperCase();
    return studentCourse === targetCourse;
});
```

## 🔍 使用方式

### 前端（瀏覽器）
```javascript
// 提取課程名稱
const courseName = CourseStudentMatcher.extractCourseName('SPIKE — 1930-2100 客製化 第6週');
// 結果: "SPIKE"

// 查找學生
const students = CourseStudentMatcher.findStudentsByCourse('SPIKE', studentData);
// 結果: 25 位學生

// 便利方法
const result = CourseStudentMatcher.matchStudentsByTitle('SPIKE — 1930-2100 客製化 第6週', studentData);
// 結果: { courseName: 'SPIKE', courseTitle: '...', students: [...], studentsCount: 25 }
```

### 後端（Node.js）
```javascript
const CourseStudentMatcher = require('./public/js/course-student-matcher.js');

// 提取課程名稱
const courseName = CourseStudentMatcher.extractCourseName(courseTitle);

// 查找學生
const students = CourseStudentMatcher.findStudentsByCourse(courseName, studentData, {
    includeZeroRemaining: true  // 包含剩餘堂數為0的學生
});
```
