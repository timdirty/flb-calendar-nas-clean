### ✅ 缺席狀態顯示機制

系統會讀取 `student_data.json` 中每位學生的 `attendance` 陣列：

```json
{
  "name": "張小明",
  "course": "SPIKE",
  "period": "六 1600-1800",
  "attendance": [
    {
      "date": "2025-09-20",
      "present": true        // ✅ 出席
    },
    {
      "date": "2025-09-27",
      "present": false       // ❌ 缺席
    },
    {
      "date": "2025-10-04",
      "present": "leave"     // 🏥 請假
    }
  ]
}
```

### 🎯 支援的狀態類型

1. **`present: true`** → ✅ 已簽到（綠色勾勾）
2. **`present: false`** → ❌ 缺席（紅色叉叉）
3. **`present: "leave"`** → 🏥 請假（黃色標記）
4. **無記錄** → ⚪ 未簽到（灰色）

### 🔧 技術特點

#### ✅ 強制獲取最新資料
- 使用 `cache: 'no-cache'`
- 加上 `Cache-Control: 'no-cache'` 和 `Pragma: 'no-cache'` headers
- 確保每次打開都讀取最新的 JSON 檔案

#### ✅ 精準課程匹配
- 比對課程名稱（normalize 處理）
- 比對上課時間（支援時間範圍重疊檢查）
- 只顯示符合當前課程的學生

#### ✅ 日期精確匹配
```javascript
const today = new Date().toISOString().split('T')[0]; // YYYY-MM-DD
const todayAttendance = student.attendance.find(record => record.date === today);
```
