# 🧪 快速測試 - 請假取消顯示

## 📋 測試目的
驗證學生請假時，提醒會被自動取消，並在前端正確顯示取消原因。

---

## ✅ 測試步驟

### 步驟 1：準備測試環境
```bash
# 1. 確保系統正在運行
pm2 status

# 2. 查看當前提醒
cat reminders.json | jq '.studentReminders[] | select(.status == "pending")'
```

### 步驟 2：模擬學生請假

#### 方法 A：直接修改 student_data.json（快速測試）
```bash
# 1. 備份原始檔案
cp public/student_data.json public/student_data.json.backup-test

# 2. 編輯檔案，找到對應學生，修改 attendance
# 將對應日期的 present 改為 false 或 "leave"
nano public/student_data.json
```

範例修改：
```json
{
  "name": "沈嘉桐(桐桐)",
  "attendance": [
    {
      "date": "2025-10-18",
      "present": false  // ← 改為 false 或 "leave"
    }
  ]
}
```

#### 方法 B：透過 Google Sheets（真實情境）
1. 開啟學生出席 Google Sheets
2. 找到對應學生和日期
3. 標記為請假
4. 等待 5 分鐘讓系統自動更新

### 步驟 3：等待系統處理

```bash
# 查看系統日誌
tail -f server.log | grep -E "請假|取消"
```

預期日誌輸出：
```
🔍 發送前重新驗證學生請假狀態...
❌ 學生 沈嘉桐(桐桐) 在 2025-10-18 請假，取消發送提醒
🚫 取消 1 個提醒（學生請假）
```

### 步驟 4：檢查提醒狀態

```bash
# 查看被取消的提醒
cat reminders.json | jq '.studentReminders[] | select(.status == "cancelled")'
```

預期輸出：
```json
{
  "id": "student_20251017_xxx",
  "type": "student",
  "status": "cancelled",
  "cancelReason": "學生請假",
  "cancelledAt": "2025-10-17T10:00:00.000Z",
  "studentName": "沈嘉桐(桐桐)",
  "courseName": "SPM",
  "courseDate": "2025-10-18",
  "courseTime": "09:30"
}
```

### 步驟 5：前端驗證

1. **開啟提醒管理介面**
   ```
   https://calendar.funlearnbar.synology.me/course-reminder-management.html
   ```

2. **切換到「學生家長提醒」頁籤**

3. **檢查篩選器**
   - 應該看到：全部、待發送、已發送、**已取消**、發送失敗

4. **點擊「已取消」篩選器**
   - 應該顯示所有 status = 'cancelled' 的提醒

5. **檢查提醒卡片**
   ✅ 應顯示：
   - 狀態：🚫 已取消（灰色）
   - 取消原因框（灰色邊框）
   - 📌 取消原因: 學生請假
   - 🕐 取消時間: 2025/10/17 下午6:00
   - 整個卡片半透明
   - 只有「刪除」按鈕（沒有「發送」和「編輯」）

### 步驟 6：恢復測試資料（如果使用方法 A）

```bash
# 恢復原始學生資料
mv public/student_data.json.backup-test public/student_data.json
```

## 🔍 進階測試情境

### 情境 1：學生在提醒生成後請假

1. **時間點 A（10:00）**：系統生成提醒
   ```bash
   # 查看生成的提醒
   cat reminders.json | jq '.studentReminders[] | select(.studentName == "沈嘉桐(桐桐)" and .status == "pending")'
   ```

2. **時間點 B（14:00）**：學生家長標記請假
   ```bash
   # 修改 student_data.json
   nano public/student_data.json
   ```

3. **時間點 C（18:00）**：系統準備發送提醒
   ```bash
   # 觀察日誌
   tail -f server.log | grep "沈嘉桐"
   ```
   
   ✅ **預期結果**：發送前驗證機制攔截，取消發送

### 情境 2：多個學生請假

1. 修改多個學生的請假狀態
2. 查看批次取消日誌
   ```bash
   tail -f server.log | grep "🚫 取消"
   ```
   
   預期輸出：
   ```
   🚫 取消 3 個提醒（學生請假）
   ```

3. 前端查看「已取消」列表
   ✅ 應顯示多個被取消的提醒

### 情境 3：請假狀態恢復

1. **學生原本請假** → 提醒被取消
2. **學生取消請假** → 修改 `present: true`
3. **下次生成提醒時** → 會重新生成新的 pending 提醒

## 🐛 常見問題排查

### 問題 1：前端未顯示「已取消」篩選器
**檢查**：
```bash
grep -n "已取消" public/course-reminder-management.html
```
應該找到：
```html
<button class="filter-btn" data-status="cancelled">已取消</button>
```

### 問題 2：取消原因框未顯示
**檢查**：
```bash
grep -n "cancel-reason-box" public/course-reminder-management.html
```
應該找到 CSS 樣式定義和 HTML 模板

### 問題 3：提醒未被取消
**檢查日誌**：
```bash
# 確認系統有執行發送前驗證
tail -f server.log | grep "🔍 發送前重新驗證"
```

**檢查學生資料**：
```bash
# 確認請假狀態正確
cat public/student_data.json | jq '.students[] | select(.name == "沈嘉桐(桐桐)") | .attendance'
```

### 問題 4：取消時間格式錯誤
**檢查**：
前端應使用 `toLocaleString('zh-TW', { timeZone: 'Asia/Taipei' })`

**測試**：
```javascript
// 在瀏覽器 Console 執行
new Date('2025-10-17T10:00:00.000Z').toLocaleString('zh-TW', { 
  timeZone: 'Asia/Taipei',
  year: 'numeric',
  month: '2-digit',
  day: '2-digit',
  hour: '2-digit',
  minute: '2-digit'
})
```
