## ⚡ 快速測試（3分鐘）

### 步驟 1：開啟管理控制台


```
1. 點擊頁面上方的「講師管理」分頁
2. 往下滾動到「講師顏色配置」區塊
```

### 步驟 3：檢查UI是否正確顯示

**應該看到：**
- ✅ 上方有「快速選擇顏色」標題

- ✅ 下方顯示所有講師列表
- ✅ 每位講師有：名稱、顏色預覽、顏色選擇器、顏色代碼

## 🐛 常見問題快速檢查

### 問題：看不到預設顏色面板

```bash
# 檢查 1：確認檔案已更新
grep "PRESET_COLORS" public/admin-dashboard.html

# 檢查 2：清除瀏覽器快取
按 Ctrl+Shift+Delete 清除快取

# 檢查 3：強制重新整理
按 Ctrl+F5
```

### 問題：點擊顏色沒反應

```bash
# 檢查 1：開啟瀏覽器控制台（F12）
看是否有 JavaScript 錯誤

# 檢查 2：確認已選擇講師
講師行應該有藍色邊框

# 檢查 3：確認函數存在
在控制台執行：
typeof selectTeacherForColoring
// 應該返回 "function"
```

### 問題：保存失敗

```bash
# 檢查 1：確認 PUT API 存在
grep "app.put('/api/teachers'" server.js

# 檢查 2：檢查後端日誌
tail -f server.log

# 檢查 3：檢查網路請求
開啟瀏覽器 Network 分頁
查看 PUT /api/teachers 請求
```
