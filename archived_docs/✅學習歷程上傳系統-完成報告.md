## 🎯 完成項目

### 1. ✅ 後端開發

#### 1.1 套件安裝
- ✅ 安裝 `multer@1.4.5-lts.1` 處理檔案上傳
- ✅ 更新 `package.json` 依賴項

#### 1.2 核心工具函數
- ✅ `getCurrentSemester()` - 學期判斷函數
  - 3-6月 → `{年度}-2`（下學期）
  - 7-8月 → `夏令營-{年份}`
  - 9-12月 → `{年度}-1`（上學期）
  - 1-2月 → `冬令營-{年份}`

- ✅ `generateLearningPath()` - 路徑生成函數
  - 自動創建學期/課程/日期/學生的目錄結構
  - 支援課程總覽路徑生成

- ✅ `isPathSafe()` - 路徑安全驗證
  - 防止路徑遍歷攻擊（`../` 注入）

#### 1.3 檔案上傳配置
- ✅ Multer 存儲配置
  - 自動創建目錄結構
  - 智能檔案命名（學生姓名_類型_序號_時間戳）
  - 檔案類型驗證

- ✅ 檔案大小限制
  - 照片：5MB（jpg, jpeg, png, heic）
  - 影片：50MB（mp4, mov, avi）

#### 1.4 API 端點

**✅ GET `/api/learning-records/today-completed-courses`**
- 獲取今天已結束的課程列表
- 自動關聯學生名單
- 顯示課程時段和學生數量

**✅ POST `/api/learning-records/upload`**
- 處理學生和課程總覽上傳
- 驗證：至少3張照片、1個影片、20字評語
- 自動創建目錄並儲存檔案

**✅ GET `/api/learning-records/history`**
- 查詢學習記錄歷史
- 支援多層級篩選（學期/課程/日期/學生）
- 遞迴讀取目錄結構

**✅ GET `/api/learning-records/check-completion`**
- 檢查特定學生的上傳完成度
- 返回缺少的項目（照片/影片/評語）

**✅ DELETE `/api/learning-records/:recordId`**
- 刪除單一檔案或整個學生記錄
- 路徑安全驗證

**✅ PUT `/api/learning-records/:recordId`**
- 更新評語或補充檔案
- 支援新增照片和影片

## 📝 使用流程

### 講師操作流程

1. **進入系統**
   - 從主行事曆點擊「學習歷程上傳」按鈕

2. **選擇課程**
   - 系統自動顯示今天已結束的課程
   - 點擊要上傳的課程卡片

3. **上傳學生記錄**
   - 為每個學生上傳：
     - 至少 3 張照片
     - 至少 1 個影片
     - 至少 20 字評語
   - 系統會即時顯示上傳進度
   - 完成要求後，上傳按鈕才會啟用

4. **上傳課程總覽**
   - 上傳課程照片（不限張數）
   - 填寫課程摘要

5. **查看歷史記錄**
   - 點擊「查看歷史記錄」按鈕
   - 使用篩選器查詢
   - 查看學生的評語和照片數量

## 📚 API 文件

### 1. 獲取今天已結束的課程
```http
GET /api/learning-records/today-completed-courses
```

**回應範例：**
```json
{
  "success": true,
  "date": "2025-10-17",
  "courses": [
    {
      "id": "event-123",
      "title": "SPIKE 六 1600-1800",
      "start": "2025-10-17T08:00:00.000Z",
      "end": "2025-10-17T10:00:00.000Z",
      "courseName": "SPIKE",
      "students": [
        { "name": "吳昀衡", "remaining": 13, "userId": "..." },
        { "name": "簡筠恩", "remaining": 15, "userId": "..." }
      ]
    }
  ]
}
```

### 2. 上傳學習記錄
```http
POST /api/learning-records/upload
Content-Type: multipart/form-data
```

**參數：**
- `course` (string) - 課程名稱
- `period` (string) - 時段
- `date` (string) - 日期 (YYYY-MM-DD)
- `studentName` (string) - 學生姓名
- `comment` (string) - 評語（至少20字）
- `photos` (files) - 照片檔案（至少3張）
- `videos` (files) - 影片檔案（至少1個）
- `isOverview` (boolean) - 是否為課程總覽

### 3. 查詢歷史記錄
```http
GET /api/learning-records/history?semester=114-1&course=SPIKE&date=2025-10-17
```

### 4. 檢查完成度
```http
GET /api/learning-records/check-completion?course=SPIKE&period=六1600-1800&date=2025-10-17&studentName=吳昀衡
```

### 5. 刪除記錄
```http
DELETE /api/learning-records/:recordId?course=SPIKE&period=六1600-1800&date=2025-10-17&studentName=吳昀衡
```

### 6. 更新記錄
```http
PUT /api/learning-records/:recordId
Content-Type: multipart/form-data
```
