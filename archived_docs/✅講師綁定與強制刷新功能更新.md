### 1️⃣ 首次使用者自動綁定機制

#### 問題：
之前首次使用者需要手動點擊按鈕才能綁定講師，體驗不佳。

#### 解決方案：
**自動偵測並跳出綁定選單**

#### 流程：
```

    ↓

    ↓

    ↓

    ↓
用戶選擇講師身份
    ↓
自動寫入 teacher_data.json
    ↓
下次自動比對成功 ✅
```

- **檔案：** `perfect-calendar-optimized-complete2.html`
- **行數：** 8313-8327

#### 修改內容：

### 3️⃣ 強制整理按鈕真正觸發後端刷新

#### 問題：
右下角的「強制整理」浮動按鈕只清除前端快取，但後端可能還在使用舊的快取資料（10分鐘有效期）。

#### 解決方案：
**前端發送 `X-Force-Refresh: true` header，後端檢測並強制重新從 CalDAV 讀取**

#### 前端實現：
- **檔案：** `perfect-calendar-optimized-complete2.html`
- **行數：** 9466
- **已存在：** ✅ 前端已經正確設置 header

```javascript
const response = await apiOptimizer.fetchWithRetry(`/api/events?t=${timestamp}`, {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json',
        'Cache-Control': 'no-cache, no-store, must-revalidate',
        'Pragma': 'no-cache',
        'Expires': '0',
        'X-Force-Refresh': 'true',  // ✅ 強制刷新標記
        'X-Timestamp': timestamp.toString()
    }
}, false);
```

#### 後端實現：
- **檔案：** `server.js`
- **行數：** 811-832
- **新增功能：** ✅ 檢查 X-Force-Refresh header

```javascript
app.get('/api/events', async (req, res) => {
  try {
    // 🆕 檢查是否要求強制刷新（忽略快取）
    const forceRefresh = req.headers['x-force-refresh'] === 'true';
    
    // 優先使用快取的資料（如果快取存在且未過期，且非強制刷新）
    const cacheAge = eventsCache.lastUpdate ? (Date.now() - eventsCache.lastUpdate) / 1000 : Infinity;
    const cacheMaxAge = 600; // 10分鐘
    
    if (eventsCache.data && cacheAge < cacheMaxAge && !forceRefresh) {
      console.log(`📦 使用快取的事件資料（快取年齡: ${Math.floor(cacheAge)}秒）`);
      return res.json({
        ...eventsCache.data,
        cached: true,
        cacheAge: Math.floor(cacheAge)
      });
    }
    
    // 如果快取不存在或已過期，或要求強制刷新，則即時獲取
    if (forceRefresh) {
      console.log('🔄 收到強制刷新請求，忽略快取，直接從 CalDAV 獲取事件...');
    } else {
      console.log('⚠️ 快取不存在或已過期，即時從 CalDAV 獲取事件...');
    }
    
    // ... 繼續從 CalDAV 獲取資料
  }
});
```

#### 完整流程：
```
用戶點擊右下角「強制整理」按鈕
    ↓
清除前端快取（localStorage、API優化器快取）
    ↓
發送 API 請求：/api/events?t={timestamp}
    header: X-Force-Refresh: true
    ↓
後端檢測到 forceRefresh = true
    ↓
🔄 忽略後端快取（即使未過期）
    ↓
直接從 CalDAV 伺服器重新讀取最新資料
    ↓
返回最新事件資料
    ↓
前端更新顯示 ✅
```

```json
{
  "teachers": {
    "TIM": "Udb51363eb6fdc605a6a9816379a38103",
    "YOKI": "Ucf9b239b708001ed44f0710704282655",
    ...
  },

```

#### 寫入時機：
1. **新用戶綁定：** POST /api/teacher-binding
2. **用戶重新綁定：** POST /api/teacher-binding（自動覆蓋舊綁定）
3. **解除綁定：** POST /api/teacher-unbinding（移除該用戶）

#### 讀取時機：
1. **頁面載入：** GET /api/teachers
2. **自動比對：** 每次 LIFF 登入後
3. **綁定選單：** 顯示可用講師列表

#### 自動備份：
- 每次更新前自動備份到 `teacher_data.json.backup`
