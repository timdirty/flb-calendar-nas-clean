# 📖 課程卡片排序功能 - 完整指南

## 🎯 功能概述

課程卡片排序功能允許使用者選擇兩種排序方式：
- **由近到遠**: 越靠近當前時間的課程排在越上面（預設）
- **由遠到近**: 越遠離當前時間的課程排在越上面

## 📍 功能位置

在主頁面的控制面板中，緊鄰視圖按鈕（今日/本週/本月/全部）的右側。

### 視覺特徵
- 🎨 膠囊形狀的按鈕容器
- 💙 選中狀態為藍色漸層背景
- ⚪ 未選中狀態為透明背景
- ✨ 懸浮時有白色半透明背景和上移效果
- 📱 手機端自動延展填滿寬度

### 按鈕圖標
- ⬇️ 由近到遠：向下箭頭
- ⬆️ 由遠到近：向上箭頭

## 🔧 使用方式

### 基本操作
1. 點擊想要的排序方式按鈕

3. 出現成功通知訊息

### 排序邏輯

#### 由近到遠（預設）
```
正在進行的課程（距離 = 0）
↓
30分鐘後開始的課程（距離 = 30分鐘）
↓
30分鐘前結束的課程（距離 = 30分鐘）
↓
1小時後開始的課程（距離 = 1小時）
↓
1小時前結束的課程（距離 = 1小時）
```

#### 由遠到近
```
1天後的課程（距離 = 1天）
↓
1小時後的課程（距離 = 1小時）
↓
30分鐘後的課程（距離 = 30分鐘）
↓
30分鐘前的課程（距離 = 30分鐘）
↓
正在進行的課程（距離 = 0）
```

### 排序演算法
```javascript
filteredEvents.sort((a, b) => {
    const now = new Date();
    const eventA = new Date(a.start);
    const eventB = new Date(b.start);
    const endA = new Date(a.end);
    const endB = new Date(b.end);
    
    // 判斷課程是否正在進行中
    const isEventAOngoing = eventA <= now && endA > now;
    const isEventBOngoing = eventB <= now && endB > now;
    
    // 正在進行中的課程，距離為 0（最優先）
    const distanceA = isEventAOngoing ? 0 : Math.abs(now - eventA);
    const distanceB = isEventBOngoing ? 0 : Math.abs(now - eventB);
    
    // 根據排序方向決定排序
    let result = 0;
    if (distanceA !== distanceB) {
        result = distanceA - distanceB;
    } else {
        result = eventA - eventB;
    }
    
    // 如果是「由遠到近」，反轉結果
    return sortDirection === 'far-to-near' ? -result : result;
});
```

## 🐛 已修復的問題

### 問題 1: 有時候點不到按鈕
**原因**: 全域點擊事件監聽器使用 capture 模式攔截了所有點擊
**解決**: 在全域監聽器中排除排序按鈕的點擊

### 問題 2: 切換後沒有完全更新
**原因**: 只重新渲染了主列表，忽略了其他視圖
**解決**: 確保所有相關視圖都重新渲染

### 問題 3: 快速點擊會重複觸發
**原因**: 沒有防抖保護
**解決**: 增加防止重複點擊的機制

### 問題 4: 控制台訊息過多
**原因**: 所有點擊都輸出診斷日誌
**解決**: 增加開發模式開關，生產環境關閉診斷日誌

## ❓ 常見問題

### Q1: 為什麼重新整理後排序會恢復？
A: 不會。排序設定會儲存在 localStorage 中，重新整理後會自動恢復。

### Q2: 可以添加更多排序方式嗎？
A: 可以。只需要：
1. 在 HTML 中添加新按鈕
2. 在排序邏輯中添加新的排序方式
3. 更新事件監聽器

### Q3: 排序會影響搜尋和篩選嗎？
A: 不會。排序只影響顯示順序，不影響篩選結果。

### Q4: 手機版的按鈕太小點不到？
A: 手機版的按鈕會自動延展，並且有觸控友善的大小設定。

### Q5: 可以用鍵盤快捷鍵切換嗎？
A: 目前還不支援，這是未來的優化方向。
