# 🧪 快速測試 - 日曆點擊智慧切換

## 🎯 測試目標

驗證點擊週日曆/月日曆上的課程方塊時，如果該課程不在當前視圖中，系統會自動切換到「全部」視圖並高亮該課程。

## 📋 前置準備

1. ✅ 已部署最新版本（執行 `🚀立即部署-日曆點擊智慧切換.sh`）
2. ✅ 已清除瀏覽器快取（Ctrl+Shift+R 或 Cmd+Shift+R）
3. ✅ 開啟瀏覽器開發者工具（F12）
4. ✅ 切換到 Console 標籤頁

## 🧪 測試案例

### 測試案例 1：本週視圖點擊本週課程

**步驟：**
1. 登入 LINE 並選擇講師（例如：TIM）
2. 點擊「本週」按鈕
3. 觀察週日曆（7天的格子）
4. 點擊**本週內**的任何課程方塊（藍色小方塊）

**預期結果：**
- ✅ 直接高亮該課程卡片（不切換視圖）
- ✅ 滾動到該課程位置
- ✅ 該課程卡片變亮，其他課程變暗

**控制台日誌：**
```
🎯 高亮課程卡片（全域函數被調用）: [eventId]
✅ 執行高亮邏輯
```

---

### 測試案例 2：本週視圖點擊非本週課程

**步驟：**
1. 確保在「本週」視圖
2. 觀察週日曆上是否有其他週的課程（通常會有）
3. 點擊**非本週**的課程方塊

**預期結果：**
- ✅ 系統自動切換到「全部」視圖
- ✅ 找到並高亮該課程卡片
- ✅ 滾動到該課程位置
- ✅ 顯示所有課程列表

**控制台日誌：**
```
🎯 高亮課程卡片（全域函數被調用）: [eventId]
⚠️ 當前視圖找不到對應的課程卡片: [eventId]
📍 該課程存在於資料中，但不在當前視圖
🔄 自動切換到「全部」視圖以顯示該課程...
[1秒後]
✅ 成功在「全部」視圖中找到課程卡片
```

**步驟：**
1. 點擊「今日」按鈕
2. 點擊「本週」按鈕以顯示週日曆
3. 點擊**非今日**的課程方塊

**預期結果：**
- ✅ 系統自動切換到「全部」視圖
- ✅ 找到並高亮該課程卡片
- ✅ 滾動到該課程位置

**控制台日誌：**
```
🔄 自動切換到「全部」視圖以顯示該課程...
✅ 成功在「全部」視圖中找到課程卡片
```

---

### 測試案例 4：月日曆點擊

**步驟：**
1. 點擊「每月」按鈕
2. 觀察月日曆（整月的格子）
3. 點擊任何日期的課程方塊

**預期結果：**
- ✅ 如果該課程在當前視圖中 → 直接高亮
- ✅ 如果不在 → 自動切換到「全部」視圖並高亮

---

### 測試案例 5：點擊日期格子（非課程）

**步驟：**
1. 在週日曆或月日曆中
2. 點擊日期格子的**空白區域**（不是課程方塊）

**預期結果：**
- ✅ 滾動到該日期的課程區域
- ✅ 高亮該日期的所有課程
- ✅ 不切換視圖

**控制台日誌：**
```
🗓️ 點擊日曆方塊，滾動到日期: 2025-10-24
📊 找到 X 個課程在 2025/10/24
```

## ⚠️ 常見問題

### Q1：點擊後沒有反應？

**解答：**
1. 確認已清除瀏覽器快取
2. 檢查控制台是否有錯誤訊息
3. 確認已登入 LINE 並選擇講師
4. 確認點擊的是課程方塊（藍色小方塊），不是空白區域

---

### Q2：自動切換後仍然找不到課程？

**解答：**
1. 檢查該課程是否真的存在於 `allEvents` 中
2. 在控制台執行：
   ```javascript
   allEvents.find(e => e.id === '[課程ID]')
   ```
3. 如果返回 `undefined`，表示該課程不存在

---

### Q3：切換太慢？

**解答：**
- 目前設置為 1 秒延遲（`setTimeout(..., 1000)`）
- 這是為了確保視圖完全切換完成
- 如果需要更快，可以調整延遲時間

---

### Q4：點擊日期格子沒有反應？

**解答：**
1. 確認該日期有課程
2. 在控制台查看日誌：
   ```
   ⚠️ 該日期沒有課程
   ```
3. 這是正常行為
