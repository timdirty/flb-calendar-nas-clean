# ✅ 日曆點擊不跳轉視圖完成

## 📋 修復內容

根據使用者反饋修復了以下問題：

### 1️⃣ 高亮時課程卡片消失問題

**問題：** 點擊日曆方塊後，課程卡片會直接不見

**原因：**
- `.event-card` 初始設定 `opacity: 0` 用於進入動畫
- 高亮效果可能與動畫衝突
- `z-index` 設置過高導致被遮擋
- `transform: scale(1.05)` 可能超出容器

**解決方案：**
```css
/* 修改前 */
.event-card {
    opacity: 0;  /* ❌ 可能導致消失 */
    transform: translateY(20px);
    animation: slideUp 0.8s forwards;
}

.event-card.highlight-target {
    transform: scale(1.05) translateY(-6px);  /* ❌ 可能超出容器 */
    z-index: 100;  /* ❌ 太高 */
}

.event-card.dimmed {
    opacity: 0.3;  /* ❌ 太暗 */
    filter: grayscale(0.6);
}
```

```css
/* 修改後 */
.event-card {
    opacity: 1;  /* ✅ 始終可見 */
    transform: translateY(0);
    /* 暫時關閉動畫 */
}

.event-card.highlight-target {
    transform: scale(1.03);  /* ✅ 減小縮放 */
    z-index: 50;  /* ✅ 降低層級 */
    margin: 8px 0;  /* ✅ 增加間距 */
}

.event-card.dimmed {
    opacity: 0.4;  /* ✅ 保持可見 */
    filter: grayscale(0.4);
    pointer-events: auto;  /* ✅ 確保可點擊 */
}
```

### 2️⃣ 移除自動視圖切換

**問題：** 點擊日曆方塊後，系統會自動跳轉到「每月」或「全部」視圖

**解決方案：** 完全移除視圖切換邏輯

```javascript
// 修改前
if (!targetCard) {
    // 自動切換到「每月」視圖
    switchView('每月', 'month');
    // ... 複雜的切換邏輯
}
```

```javascript
// 修改後
if (!targetCard) {
    console.warn('⚠️ 當前視圖找不到對應的課程卡片');
    console.log('💡 提示：該課程可能不在當前視圖範圍內');
    
    // 只滾動到課程列表區域，不切換視圖
    const eventsContainer = document.getElementById('eventsContainer');
    if (eventsContainer) {
        eventsContainer.scrollIntoView({ 
            behavior: 'smooth', 
            block: 'start' 
        });
    }
    
    return;
}
```

## 📝 備註

### 為什麼不自動切換視圖？

1. **尊重用戶選擇**：用戶明確選擇了「本週」視圖，不應該自動改變
2. **避免混淆**：自動切換可能讓用戶困惑（我剛才不是在本週視圖嗎？）
3. **提升穩定性**：減少複雜邏輯，降低 bug 機率
4. **更好的控制**：用戶可以決定何時切換視圖

### 為什麼移除進入動畫？

1. **避免衝突**：進入動畫的 `opacity: 0` 與高亮效果衝突
2. **提升效能**：減少不必要的動畫計算
3. **更快顯示**：課程列表立即可見，不需等待動畫
