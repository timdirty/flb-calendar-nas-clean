# 🧪 課程卡片排序切換功能 - 快速測試指南

## 🎯 測試目標
驗證課程卡片排序切換功能是否正常運作。

## 📍 功能位置
在主頁面的控制面板中，視圖按鈕（今日/本週/本月/全部）旁邊，會看到新增的「排序方式」控制項。

## ✅ 測試步驟

### 測試 1: 基本切換功能
1. 打開課程檢視系統
2. 找到「排序方式」標籤下的兩個按鈕
3. 預設應該是「由近到遠」被選中（藍色背景）
4. 點擊「由遠到近」按鈕
5. **預期結果**:
   - 按鈕變為藍色背景
   - 「由近到遠」按鈕變為透明背景
   - 課程列表順序改變
   - 出現成功通知「已切換為『由遠到近』」

### 測試 2: 排序效果驗證
1. 確認當前時間
2. 觀察課程列表的排序

**「由近到遠」模式**:
- 正在進行的課程應該在最上面
- 接下來是即將開始的課程
- 然後是剛結束的課程
- 最後是較早之前結束的課程

**「由遠到近」模式**:
- 排序應該完全相反
- 最遠的課程在最上面
- 最近的課程在最下面

### 測試 3: 不同視圖的排序
1. 選擇「今日」視圖，設定為「由遠到近」
2. 切換到「本週」視圖
3. **預期結果**: 排序方式保持為「由遠到近」
4. 切換到「本月」視圖
5. **預期結果**: 排序方式保持為「由遠到近」
6. 切換到「全部」視圖
7. **預期結果**: 排序方式保持為「由遠到近」

### 測試 4: 持久化儲存
1. 將排序設定為「由遠到近」
2. 重新整理頁面 (F5)
3. **預期結果**:
   - 頁面載入後，「由遠到近」按鈕仍然是選中狀態
   - 課程列表保持「由遠到近」的排序
4. 切換回「由近到遠」
5. 重新整理頁面
6. **預期結果**:
   - 頁面載入後，「由近到遠」按鈕是選中狀態
   - 課程列表保持「由近到遠」的排序

### 測試 5: 講師篩選配合
1. 選擇特定講師（例如：某位講師）
2. 設定排序為「由遠到近」
3. **預期結果**: 該講師的課程按「由遠到近」排序
4. 切換回「全部講師」
5. **預期結果**: 排序方式保持為「由遠到近」

### 測試 6: 手機版響應式測試
1. 開啟瀏覽器的開發者工具 (F12)
2. 切換到手機模式 (Ctrl+Shift+M / Cmd+Shift+M)
3. 選擇 iPhone 或 Android 裝置模擬
4. **預期結果**:
   - 排序按鈕自動延展填滿寬度
   - 兩個按鈕等寬顯示
   - 文字和圖標清晰可見
   - 點擊功能正常

### 測試 7: 視覺效果測試
1. 懸浮在排序按鈕上
2. **預期結果**:
   - 未選中的按鈕出現白色半透明背景
   - 按鈕輕微上移
   - 出現陰影效果
3. 點擊按鈕
4. **預期結果**:
   - 選中的按鈕變為藍色漸層背景
   - 圖標略微放大
   - 出現明顯的陰影效果

## 🔍 除錯技巧

### 檢查排序方向狀態
在瀏覽器控制台執行：
```javascript
console.log('當前排序方向:', sortDirection);
console.log('localStorage 中的排序:', localStorage.getItem('courseSortDirection'));
```

### 檢查課程順序
```javascript
// 取得當前顯示的課程卡片
const cards = document.querySelectorAll('.event-card');
console.log('課程數量:', cards.length);

// 顯示前5個課程的時間
Array.from(cards).slice(0, 5).forEach((card, index) => {
    const timeElem = card.querySelector('.event-time');
    const titleElem = card.querySelector('.event-title');
    console.log(`${index + 1}. ${timeElem?.textContent} - ${titleElem?.textContent}`);
});
```

### 強制重置排序設定
如果排序功能異常，可以執行：
```javascript
localStorage.removeItem('courseSortDirection');
location.reload();
```

## ⚠️ 常見問題

### Q1: 按鈕沒有反應
**解決方法**:
1. 檢查瀏覽器控制台是否有錯誤訊息
2. 確認檔案是否正確部署
3. 清除瀏覽器快取 (Ctrl+F5)

### Q2: 排序沒有改變
**解決方法**:
1. 檢查是否有課程資料
2. 確認課程時間是否正確
3. 檢查控制台的 `sortDirection` 變數

### Q3: 重新整理後設定沒有保存
**解決方法**:
1. 檢查瀏覽器是否允許 localStorage
2. 確認沒有開啟無痕模式
3. 檢查 localStorage 容量是否已滿

### Q4: 手機版按鈕顯示異常
**解決方法**:
1. 確認瀏覽器支援 flexbox
2. 檢查 CSS 是否正確載入
3. 清除快取並重新載入
