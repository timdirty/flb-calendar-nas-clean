# 📋 日曆點擊修復 - 快速參考卡

## 🎯 問題

- ❌ 日曆方塊不可點擊
- ❌ 沒有懸浮資訊顯示

## ✅ 解決方案

### 1. 雙重點擊機制

```
Inline onclick (主要)
        ↓
事件委派 (備援)
        ↓
執行函數
```

### 2. 修復內容

| 功能 | 實現方式 |
|------|---------|
| 懸浮提示 | 原生 `title` 屬性 |
| 點擊日曆 | 事件委派 + inline onclick |
| 點擊事件 | 事件委派 + inline onclick |
| 錯誤處理 | 函數存在性檢查 |

## 🚀 快速部署

```bash
# 1. 部署修復
./🚀立即部署-日曆點擊修復.sh

# 2. 啟動服務（如果未運行）
docker-compose up -d

# 3. 測試功能
# http://localhost:3000
```

## 🧪 快速測試

### 週/月視圖

1. ✓ 切換到「本週」或「本月」
2. ✓ 懸停查看提示
3. ✓ 點擊日曆方塊 → 滾動到日期
4. ✓ 點擊事件方塊 → 高亮課程

### Console 檢查

**應該看到**：
```
✅ 正在定義全域點擊處理函數...
✅ 日曆視圖事件委派已設置完成
window.scrollToDateCourses: function
window.highlightEventCardFromCalendar: function
```

**點擊時應該看到**：
```
🗓️ 點擊日曆方塊（事件委派）
或
🎯 點擊事件方塊（事件委派）
```

## 🐛 問題排查

| 問題 | 解決方案 |
|------|---------|
| 點擊無反應 | Ctrl+Shift+R 強制重新載入 |
| 懸浮提示不顯示 | 等待 1-2 秒，或檢查 title 屬性 |
| Console 錯誤 | 檢查函數是否定義 |
| 頁面不滾動 | 確認課程列表已載入 |
