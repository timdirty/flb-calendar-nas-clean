## 🚀 立即開始使用（3 步驟）

### 第 1 步：設定管理員（2 分鐘）

**最快方法：** 打開瀏覽器控制台

1. 訪問：`https://calendar.funlearnbar.synology.me`
2. 按 `F12` 打開控制台（Mac: `Cmd + Option + I`）
3. 複製貼上以下代碼，按 Enter：

```javascript
fetch('/api/admin/set', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        adminUserId: 'Udb51363eb6fdc605a6a9816379a38103'
    })
})
.then(res => res.json())
.then(data => {
    if (data.success) {
        console.log('✅ 管理員設定成功！', data);
        alert('✅ 設定完成！現在可以使用學生簽到功能了。');
    } else {
        console.error('❌ 設定失敗:', data);
    }
});
```

4. 看到 "✅ 設定完成！" 即可

## 🎓 技術細節

### 數據流程

```
學生點擊「出席」按鈕
    ↓
saveSingleAttendanceRecord()
    ↓
Promise.allSettled([
    updateStudentDataJson(),   ← 更新本地 JSON
    updateGoogleSheets()       ← 調用 Google Sheets API
])
    ↓
updateGoogleSheets() 發送標準格式 payload:
{
  "action": "update",
  "name": "Cooper",
  "date": "2025-10-10",
  "present": true
}
    ↓
後端代理 (/api/proxy/google-sheets)
    ↓
Google Apps Script
    ↓
寫入 Google Sheets
    ↓
返回成功
    ↓
更新 UI
    ↓
3 秒後發送 LINE 通知（如果管理員已設定）
```

### API 端點

| 端點 | 方法 | 用途 |
|------|------|------|
| `/api/admin/set` | POST | 設定管理員 User ID |
| `/api/admin/info` | GET | 獲取管理員資訊 |
| `/api/proxy/google-sheets` | POST | Google Sheets API 代理 |
| `/api/student-attendance-notification` | POST | 發送學生簽到通知 |
| `/api/notification-config` | GET | 獲取通知配置 |
