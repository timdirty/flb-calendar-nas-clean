# 🔐 設定管理員 - 所有可用方法

## ❌ 如果控制台方法遇到問題

您遇到的錯誤：
```
Uncaught TypeError: "" is not a function
```

這通常是因為複製貼上時引號字符被轉換了。以下提供**多種替代方法**。

---

## 方法 1：訪問設定頁面 ⭐ 最簡單

### 步驟：

1. **訪問設定頁面**（需要先部署）：
   ```
   https://calendar.funlearnbar.synology.me/設定管理員.html
   ```

2. **確認管理員 ID**（已預填）：
   ```
   Udb51363eb6fdc605a6a9816379a38103
   ```

3. **點擊「儲存設定」**

4. **看到成功訊息** ✅

---

## 方法 2：單行腳本（無引號問題）

複製以下**單行**代碼到控制台：

```javascript
fetch('/api/admin/set',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({adminUserId:'Udb51363eb6fdc605a6a9816379a38103'})}).then(r=>r.json()).then(d=>{console.log(d);if(d.success)alert('設定成功');else alert('失敗:'+d.message)})
```

---

## 方法 3：分步執行

### 第 1 步：定義管理員 ID

```javascript
adminId='Udb51363eb6fdc605a6a9816379a38103'
```

### 第 2 步：發送請求

```javascript
fetch('/api/admin/set',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({adminUserId:adminId})}).then(r=>r.json()).then(d=>{console.log(d);alert(d.success?'成功':'失敗')})
```

---

## 方法 4：使用 XMLHttpRequest（最兼容）

複製並執行 `設定管理員-兼容版本.js` 文件的完整內容。

或者手動輸入：

```javascript
var xhr=new XMLHttpRequest();
xhr.open('POST','/api/admin/set',true);
xhr.setRequestHeader('Content-Type','application/json');
xhr.onload=function(){var d=JSON.parse(xhr.responseText);alert(d.success?'成功':'失敗:'+d.message)};
xhr.send(JSON.stringify({adminUserId:'Udb51363eb6fdc605a6a9816379a38103'}));
```

## 方法 5：使用課程提醒管理頁面

### 步驟：

1. **訪問頁面**：
   ```
   https://calendar.funlearnbar.synology.me/course-reminder-management.html
   ```

2. **在頁面中找到「系統狀態」區域**

3. **找到「管理員」卡片**

4. **點擊「設定管理員」按鈕**

5. **在彈出的對話框中輸入或選擇管理員**

## 方法 6：使用 cURL（從終端機）

如果您可以訪問終端機，執行：

```bash
curl -X POST https://calendar.funlearnbar.synology.me/api/admin/set \
  -H "Content-Type: application/json" \
  -d '{"adminUserId":"Udb51363eb6fdc605a6a9816379a38103"}'
```

---

## 方法 7：手動修改配置文件（直接在 NAS 上）

如果上述方法都不行，可以直接在 NAS 上修改配置：

### 步驟：

1. **SSH 登入 NAS**：
   ```bash
   ssh -p 1022 your_user@funlearnbar.synology.me
   ```

2. **進入項目目錄**：
   ```bash
   cd /volume1/docker/flb-calendar-nas
   ```

3. **編輯配置文件**（如果存在）：
   ```bash
   # 查看是否有配置文件
   ls -la data/
   
   # 如果有 config.json，編輯它
   nano data/config.json
   ```

4. **添加管理員設定**：
   ```json
   {
     "adminUserId": "Udb51363eb6fdc605a6a9816379a38103"
   }
   ```

5. **重啟服務**：
   ```bash
   docker-compose restart
   ```

## 🔍 故障排除

### Q: 所有控制台方法都不行？

**可能原因：**
- 瀏覽器安全設置
- 控制台限制
- CORS 問題

**解決方案：**
1. 使用**方法 1**（設定頁面）- 最可靠
2. 使用**方法 5**（課程提醒管理頁面）
3. 使用**方法 7**（直接在 NAS 修改）

### Q: 設定頁面不存在？

**原因：** 文件尚未部署到 NAS

**解決方案：**

#### 選項 A：部署設定頁面

1. 確認文件存在於本地：
   ```bash
   ls -la "/Users/apple/Library/CloudStorage/SynologyDrive-FLBTim/樂程坊計畫/課程資料/Cursor/講師行事曆檢視/flb-calendar-nas/public/設定管理員.html"
   ```

2. 等待 Synology Drive 同步（通常是自動的）

3. 在 NAS 上重啟容器：
   ```bash
   ssh -p 1022 your_user@funlearnbar.synology.me
   cd /volume1/docker/flb-calendar-nas
   docker-compose restart
   ```

#### 選項 B：使用現有頁面

使用**方法 5**（課程提醒管理頁面）中的設定功能

### Q: API 返回 404？

**檢查：**
1. 確認後端已部署最新版本
2. 查看後端日誌：
   ```bash
   docker-compose logs -f
   ```
