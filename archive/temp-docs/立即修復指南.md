   - Mac: 按 `Cmd + Option + I`

3. **切換到 Console（控制台）標籤**

4. **複製並貼上以下代碼，然後按 Enter**
   ```javascript
   fetch('/api/admin/set', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({
           adminUserId: 'Udb51363eb6fdc605a6a9816379a38103'
       })
   })
   .then(res => res.json())
   .then(data => {
       if (data.success) {
           console.log('✅ 管理員設定成功！', data);
           alert('✅ 管理員設定成功！現在可以使用學生簽到功能了。');
       } else {
           console.error('❌ 設定失敗:', data);
           alert('❌ 設定失敗: ' + data.message);
       }
   })
   .catch(err => {
       console.error('❌ 錯誤:', err);
       alert('❌ 設定失敗，請查看控制台錯誤訊息');
   });
   ```

5. **看到 "✅ 管理員設定成功！" 即完成**

## ✅ Google Sheets API 確認

### 已確認：學生簽到功能正確使用 Google Sheets API ✅

**代碼位置：** `perfect-calendar-optimized-complete.html`

**流程：**
```
學生簽到按鈕點擊
    ↓
saveSingleAttendanceRecord() (第17472行)
    ↓
同時執行兩個操作：
    ├─ updateStudentDataJson() → 更新本地 student_data.json
    └─ updateGoogleSheets() → 調用 Google Sheets API (第17534行)
         ↓
         通過後端代理 /api/proxy/google-sheets
         ↓
         發送到 Google Apps Script
         ↓
         寫入 Google Sheets
```

**發送的數據格式（已修正）：**
```json
{
  "action": "update",
  "name": "學生姓名",
  "date": "2025-10-10",
  "present": true
}
```

**注意：** 根據 Google Sheets API 標準格式，payload 只包含 4 個必要字段：
- `action`: 操作類型（固定為 "update"）
- `name`: 學生姓名
- `date`: 日期（格式：YYYY-MM-DD）
- `present`: 出席狀態（true/false）

**已移除的冗餘字段：**
- ~~`teacher`~~ - 不需要
- ~~`course`~~ - 不需要
- ~~`period`~~ - 不需要

## 🔍 故障排除

### Q: 設定後仍收不到通知？

**檢查清單：**
1. 確認管理員 User ID 正確
   ```javascript
   fetch('/api/admin/info').then(r=>r.json()).then(console.log)
   ```

2. 確認已加入 LINE Bot 為好友
   - LINE Bot 名稱：[您的 Bot 名稱]

3. 確認通知配置已載入
   ```javascript
   fetch('/api/notification-config').then(r=>r.json()).then(console.log)
   ```

### Q: Google Sheets 沒有更新？

**檢查清單：**
1. 打開瀏覽器控制台，查看是否有錯誤
2. 確認 Google Apps Script 部署正常
3. 檢查 Google Sheets API 權限

**測試 Google Sheets 連接：**
```javascript
fetch('/api/proxy/google-sheets', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        action: 'updateAttendance',
        googleSheetsUrl: 'https://script.google.com/macros/s/AKfycbxfj5fwNIc8ncbqkOm763yo6o06wYPHm2nbfd_1yLkHlakoS9FtYfYJhvGCaiAYh_vjIQ/dev',
        payload: {
            action: 'update',
            name: '測試學生',
            date: new Date().toISOString().split('T')[0],
            present: true
        }
    })
})
.then(res => res.text())
.then(console.log);
```
