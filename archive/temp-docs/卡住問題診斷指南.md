## 🔍 問題 A: 白屏或空白頁面

### 原因
JavaScript 錯誤導致頁面無法渲染

### 解決方案

**1. 清除瀏覽器緩存**
```bash
# 在瀏覽器中
1. 按 Ctrl+Shift+Delete (Windows) 或 Cmd+Shift+Delete (Mac)
2. 選擇「快取的圖片和檔案」
3. 選擇時間範圍：「全部」
4. 點擊「清除資料」
```

**2. 使用無痕模式測試**
- Chrome/Edge: `Ctrl+Shift+N` (Windows) 或 `Cmd+Shift+N` (Mac)
- Safari: `Cmd+Shift+N`

**3. 查看控制台錯誤**
```bash
1. 按 F12 打開開發者工具
2. 切換到 Console 標籤
3. 截圖所有紅色錯誤訊息
```

**4. 使用測試版本**
打開無 LIFF 測試版：
```
https://你的域名/perfect-calendar-no-liff.html
```

## 🔍 問題 B: 一直顯示「載入中...」

### 原因
1. API 請求失敗或超時
2. LIFF 初始化卡住
3. 網路連接問題

### 解決方案

**方案 1: 檢查網路連接**
```bash
# 在控制台執行
fetch('/api/events')
  .then(r => r.json())
  .then(data => console.log('API 正常:', data))
  .catch(err => console.error('API 錯誤:', err));
```

**方案 2: 跳過 LIFF 初始化**
打開無 LIFF 版本：
```
http://localhost:3005/perfect-calendar-no-liff.html
或
https://你的域名/perfect-calendar-no-liff.html
```

**方案 3: 強制重新載入**
```javascript
// 在控制台執行
location.reload(true);
```

**方案 4: 檢查載入狀態**
```javascript
// 在控制台執行
console.log('頁面狀態:', document.readyState);
console.log('LIFF 狀態:', typeof liff !== 'undefined' ? '已載入' : '未載入');
```

## 🔍 問題 C: LIFF 登入循環

### 症狀
- 頁面一直重新載入
- 不斷跳轉到 LINE 登入頁面
- 登入後又回到原頁面重新開始

### 原因
`liff.login()` 在非 LINE 環境中會導致無限循環

### 解決方案

**已修復！** 最新版本已添加以下保護：

1. **超時保護** - 10 秒內未完成則失敗
2. **環境檢測** - 只在 LINE 應用程式中自動登入
3. **錯誤提示** - 清楚說明問題原因

**立即解決：**

**方案 1: 在 LINE 應用程式中開啟**
```
1. 複製連結
2. 在 LINE 中傳送給自己
3. 點擊連結在 LINE 內建瀏覽器中開啟
```

**方案 2: 使用無 LIFF 測試版**
```
http://localhost:3005/perfect-calendar-no-liff.html
```

**方案 3: 使用 LIFF 調試工具**
```
http://localhost:3005/liff-debug.html
或
https://你的域名/liff-debug.html
```

## 🔍 問題 D: 講師綁定卡住

### 症狀
- 講師綁定對話框打開後無法關閉
- 無法選擇講師
- 點擊按鈕無反應

### 解決方案

**方案 1: 強制關閉對話框**
```javascript
// 在控制台執行
document.getElementById('teacherBindModal').style.display = 'none';
```

**方案 2: 重置綁定狀態**
```javascript
// 在控制台執行
window.pendingBindUser = null;
localStorage.removeItem('boundTeacher');
location.reload();
```

**方案 3: 檢查講師列表**
```javascript
// 在控制台執行
const select = document.getElementById('bindTeacherSelect');
console.log('講師數量:', select.options.length);
console.log('講師列表:', Array.from(select.options).map(o => o.value));
```

## 🔍 問題 E: 頁面無法互動

### 症狀
- 頁面顯示正常
- 但無法點擊按鈕
- 無法輸入文字

### 原因
1. 載入遮罩層未移除
2. JavaScript 事件監聽器未綁定
3. CSS z-index 問題

### 解決方案

**方案 1: 移除載入遮罩**
```javascript
// 在控制台執行
const overlay = document.getElementById('optimized-loading-overlay');
if (overlay) overlay.remove();

const studentOverlay = document.querySelector('.student-loading-overlay');
if (studentOverlay) studentOverlay.remove();
```

**方案 2: 檢查事件監聽器**
```javascript
// 在控制台執行
const btn = document.querySelector('.btn-primary');
console.log('按鈕監聽器:', getEventListeners(btn));
```

**方案 3: 強制啟用互動**
```javascript
// 在控制台執行
document.body.style.pointerEvents = 'auto';
```

## 🚑 緊急修復

如果所有方法都無效，使用以下緊急修復：

### 修復 1: 重置所有狀態

```javascript
// 在控制台執行
// 清除所有本地儲存
localStorage.clear();
sessionStorage.clear();

// 清除所有 cookie
document.cookie.split(";").forEach(c => {
    document.cookie = c.replace(/^ +/, "").replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/");
});

// 重新載入
location.reload(true);
```

### 修復 2: 強制跳過 LIFF

```javascript
// 在控制台執行
// 設置標記跳過 LIFF
localStorage.setItem('skipLIFF', 'true');
location.reload();
```

### 修復 3: 使用安全模式

打開以下 URL（帶參數）：
```
https://你的域名/perfect-calendar-complete-optimized.html?debug=true&skipLIFF=true
```

## 📊 常見錯誤代碼

| 錯誤訊息 | 原因 | 解決方案 |
|---------|------|----------|
| `Uncaught SyntaxError` | JavaScript 語法錯誤 | 清除緩存重新載入 |
| `showStudentLoadingState is not defined` | 函數未載入 | 已修復，更新文件 |
| `LIFF SDK not loaded` | LIFF SDK 載入失敗 | 檢查網路連接 |
| `LIFF 初始化超時` | LIFF 初始化花太久 | 在 LINE 應用程式中開啟 |
| `API 連接失敗` | 後端服務異常 | 檢查服務器狀態 |
