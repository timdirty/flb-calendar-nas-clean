## 📋 修正摘要

### ✅ 已修正的問題

1. **Google Sheets API 數據格式錯誤**
   - **問題：** payload 包含多餘的字段（teacher, course, period）
   - **修正：** 移除多餘字段，只保留標準的 4 個字段（action, name, date, present）
   
2. **通知發送失敗**
   - **問題：** 管理員 User ID 未設定
   - **解決方案：** 提供設定頁面和快速設定腳本

## 🔍 故障排除

### Q1: Google Sheets 沒有更新？

**檢查清單：**

1. 確認 payload 格式正確（只有 4 個字段）
   ```javascript
   // 在控制台執行
   fetch('/api/proxy/google-sheets', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({
           action: 'updateAttendance',
           googleSheetsUrl: 'https://script.google.com/macros/s/AKfycbxfj5fwNIc8ncbqkOm763yo6o06wYPHm2nbfd_1yLkHlakoS9FtYfYJhvGCaiAYh_vjIQ/dev',
           payload: {
               action: "update",
               name: "測試",
               date: "2025-10-10",
               present: true
           }
       })
   })
   .then(res => res.text())
   .then(console.log);
   ```

2. 檢查後端日誌
   ```bash
   docker-compose logs -f --tail=100 | grep "Google Sheets"
   ```

3. 確認 Google Apps Script 部署狀態
   - 訪問 Google Apps Script 控制台
   - 確認部署為 "dev" 版本
   - 檢查執行日誌

### Q2: 仍然收不到 LINE 通知？

1. 確認管理員已設定
   ```javascript
   fetch('/api/admin/info')
       .then(res => res.json())
       .then(console.log);
   ```

2. 確認 LINE Bot 配置
   ```javascript
   fetch('/api/notification-config')
       .then(res => res.json())
       .then(console.log);
   ```

3. 測試通知發送
   ```javascript
   fetch('/api/student-attendance-notification', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({
           message: '測試通知',
           teacherName: '測試講師',
           courseName: '測試課程',
           time: '12:00',
           presentStudents: ['測試學生'],
           absentStudents: [],
           unmarkedStudents: []
       })
   })
   .then(res => res.json())
   .then(console.log);
   ```

### Q3: 部署後頁面沒有更新？

1. 強制刷新瀏覽器緩存
   - Windows/Linux: `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`

2. 清除瀏覽器緩存
   ```javascript
   localStorage.clear();
   sessionStorage.clear();
   location.reload(true);
   ```

3. 確認文件已更新
   - 檢查文件修改時間
   - 查看源代碼是否包含新的日誌訊息
