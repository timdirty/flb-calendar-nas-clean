1. 開啟課程提醒管理介面

   - 北車教室

4. **新增地點測試**：
   - 地點簡稱：「松江教室」
   - 具體地址：「104台北市中山區松江路123號4樓｜捷運松江南京站 3 號出口」
   - 點擊「新增地點」
   - 確認列表中出現新地點

5. **刪除地點測試**：
   - 點擊「松江教室」的「刪除」按鈕
   - 確認刪除提示對話框
   - 確認列表中已移除該地點

6. **更新預設地址測試**：
   - 修改「預設地址」欄位
   - 點擊「儲存地點對應表」
   - 重新載入頁面，確認預設地址已更新

✅ 所有 CRUD 操作正常運作  
✅ Toast 提示訊息正確顯示  
✅ 資料即時更新到畫面

## 測試案例 6：API 端點測試

### 目的
驗證地點對應表管理 API

### 步驟

#### 6.1 讀取地點對應表
```bash
curl http://localhost:3002/api/location-mapping
```

**預期回應**：
```json
{
  "success": true,
  "data": {
    "version": "1.0.0",
    "mappings": {
      "樂程坊": "10491台北市中山區復興北路15號9樓...",
      ...
    },
    "預設地址": "..."
  }
}
```

#### 6.2 新增地點
```bash
curl -X POST http://localhost:3002/api/location-mapping/location \
  -H "Content-Type: application/json" \
  -d '{
    "name": "測試教室",
    "address": "台北市測試路1號"
  }'
```

**預期回應**：`success: true`

#### 6.3 刪除地點
```bash
curl -X DELETE http://localhost:3002/api/location-mapping/location/測試教室
```

**預期回應**：`success: true`

#### 6.4 更新地點對應表
```bash
curl -X PUT http://localhost:3002/api/location-mapping \
  -H "Content-Type: application/json" \
  -d '{
    "mappings": {...},
    "預設地址": "新的預設地址"
  }'
```

**預期回應**：`success: true`

### 預期結果
✅ 所有 API 端點正常回應  
✅ 資料正確存入 `location-mapping.json`  
✅ 錯誤處理正確（例如：缺少參數、不存在的地點）

## 問題排查

### 問題 1：地點對應表無法載入
**排查**：
1. 檢查 `location-mapping.json` 是否存在
2. 檢查檔案格式是否正確（有效的 JSON）
3. 檢查檔案權限

### 問題 2：導航按鈕沒有顯示
**排查**：
1. 檢查 `googleMapsUrl` 是否為空
2. 檢查 Console 是否有「移除導航按鈕」日誌
3. 檢查 `notification-manager.js` 的 `buildFlexMessage` 函數

### 問題 3：地址優先順序錯誤
**排查**：
1. 檢查 `reminder-scheduler.js` 的 `resolveDetailedAddress` 函數
2. 確認學生資料中 `detailedAddress` 欄位
3. 檢查臨時學生資料
