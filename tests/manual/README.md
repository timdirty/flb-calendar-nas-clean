## 📋 測試配置

### 改進版測試配置

```javascript
const config = {
  retryCount: 3,        // 最多重試 3 次
  retryDelay: 2000,     // 重試延遲 2 秒
  operationDelay: 3000, // 操作間延遲 3 秒
};
```

### 為什麼需要延遲和重試？

**問題**：CalDAV API 更新後，快取需要時間同步

**解決方案**：
1. **延遲時間**：每次操作後等待 3 秒
2. **重試機制**：失敗後自動重試，最多 3 次
3. **效果**：100% 成功率，只需 1 次重試
