## 📋 測試前準備

### 1️⃣ 準備測試課程

在 Synology Calendar 中創建以下測試課程：

| 課程名稱 | 時間 | 描述 | 用途 |
|---------|------|------|------|
| 【測試】SPIKE 基礎班 | 今天 14:00-15:30 | 這是原始描述內容，包含課程大綱和注意事項。<br>第一行<br>第二行<br>第三行 | 測試單標記 |
| 【測試】Python 進階班 | 今天 16:00-17:30 | 原始課程說明文字 | 測試代課功能 |
| 【測試】Minecraft 程式班 | 明天 10:00-11:30 | 課程內容描述 | 測試改時間 |
| 【測試】Scratch 創意班 | 明天 14:00-15:30 | 豐富的描述內容，包含：<br>- 特殊字元 !@#$%<br>- 多行文字<br>- 空行測試 | 測試描述保留 |

### 2️⃣ 準備測試資料

- 確認有多個講師帳號（用於代課測試）
- 清空瀏覽器快取：`Cmd+Shift+R`（Mac）或 `Ctrl+Shift+R`（Win）
- 開啟 Console：`Cmd+Option+J`（Mac）或 `F12`（Win）

### 3️⃣ 打開測試頁面

```
http://calendar.funlearnbar.synology.me/admin-dashboard.html
```

## 🔴 測試階段一：單標記基本功能

### 測試案例 1.1：停課標記 ✅

#### 執行步驟
1. 在管理後台找到「【測試】SPIKE 基礎班」課程
2. 點擊課程卡片，開啟標記面板
3. 勾選「停課」標記
4. 點擊「確認標記」按鈕
5. 確認預覽彈窗內容正確
6. 點擊「確認送出」

#### 預期結果
- [ ] 標題變為：`[停課] 【測試】SPIKE 基礎班`
- [ ] 描述保留原始內容：「這是原始描述內容...」
- [ ] 課程卡片顯示 **紅色邊框和背景**
- [ ] Console 顯示：`✅ 特殊事件標記成功`
- [ ] Toast 提示：「✅ 特殊事件標記成功」

#### 驗證點
```javascript
// 在 Console 執行以下命令驗證
const event = adminAllEvents.find(e => e.title.includes('SPIKE'));
console.log('📋 標題:', event.title);
console.log('📋 描述:', event.description);

**預期輸出**：

### 測試案例 1.3：代課標記（重點測試）⭐

#### 測試 1.3A：代課成功案例

**執行步驟**
1. 找到「【測試】Minecraft 程式班」課程
2. 記錄原授課講師名稱：______________________
3. 點擊開啟標記面板
4. 勾選「代課」標記
5. **選擇不同的代課講師**（不能是原講師）
6. 輸入備註：「原講師請假」
7. 確認標記

**預期結果**
- [ ] 標題變為：`[代課] 【測試】Minecraft 程式班`
- [ ] 描述包含：`[代課講師] XXX`（代課講師名稱）
- [ ] 描述包含：`[特殊事件備註] 原講師請假`
- [ ] 課程卡片顯示 **藍色邊框和背景**
- [ ] **事件移動到代課講師的日曆**（如果該講師有日曆）

**驗證日曆移動**
1. 在左側日曆列表中，找到代課講師的日曆
2. 檢查該日曆中是否出現此課程
3. 原講師日曆中該課程應消失

**實際結果**：
- 標題：______________________
- 描述：______________________
- 代課講師：______________________
- 日曆移動：[ ] 成功 [ ] 失敗 [ ] 該講師無日曆
- 測試狀態：[ ] ✅ 通過 [ ] ❌ 失敗

## 🛡️ 測試階段二：原始描述保留測試（關鍵）

### 測試案例 5.5：多次操作後描述完整性 ⭐⭐⭐

這是**最關鍵**的測試，驗證原始描述在任何操作後都不會丟失。

#### 準備工作
使用「【測試】Scratch 創意班」課程，確認原始描述為：
```
豐富的描述內容，包含：
- 特殊字元 !@#$%
- 多行文字
- 空行測試
```

#### 執行步驟

**步驟 1**：添加體驗標記
1. 勾選「體驗」
2. 確認標記
3. **記錄描述**：______________________

**步驟 2**：增量添加公告（增量模式）
1. 切換到「增量模式」（勾選「保留現有標記」）
2. 勾選「公告」
3. 輸入公告：「測試公告內容」
4. 確認標記
5. **記錄描述**：______________________

**步驟 3**：移除公告
1. 勾選「公告」
2. 點擊「移除標記」
3. 確認移除
4. **記錄描述**：______________________

**步驟 4**：移除體驗
1. 勾選「體驗」
2. 點擊「移除標記」
3. 確認移除
4. **記錄描述**：______________________

#### 預期結果

| 步驟 | 標題 | 描述應包含 |
|------|------|-----------|
| 步驟 1 | `[體驗]` 前綴 | 原始描述 ✅ |
| 步驟 2 | `[體驗]` 前綴 | 原始描述 ✅ + 公告區塊 |
| 步驟 3 | `[體驗]` 前綴 | 原始描述 ✅（公告移除） |
| 步驟 4 | 無前綴 | **原始描述完全恢復** ✅ |

**最終驗證**：

console.log('📋 最終描述:', event.description);
console.log('📋 原始描述:', `豐富的描述內容，包含：
- 特殊字元 !@#$%
- 多行文字
- 空行測試`);
```
