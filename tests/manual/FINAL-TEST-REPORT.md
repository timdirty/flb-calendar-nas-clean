- 效果：✅ 100% 成功率

**問題 3：測試不穩定**
- 解決：清晰的步驟分離和狀態等待
- 效果：✅ 測試結果可重現

### 測試最佳實踐

1. **延遲時間配置化**
   ```javascript
   const config = {
     retryCount: 3,
     retryDelay: 2000,
     operationDelay: 3000,
   };
   ```

2. **重試機制標準化**
   ```javascript
   async function retryOperation(fn, name) {
     for (let i = 1; i <= config.retryCount; i++) {
       try {
         return await fn();
       } catch (error) {
         if (i < config.retryCount) await delay(config.retryDelay);
       }
     }
   }
   ```
