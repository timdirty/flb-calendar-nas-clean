# 學習歷程上傳系統全盤性能優化計劃

## 一、架構重構（模組化拆分）

### 1.1 核心狀態管理模組

- `public/js/modules/learning-upload/state-manager.js` - 統一狀態管理（取代 40+ 全域變數）
- `public/js/modules/learning-upload/constants.js` - 常數定義集中管理
- `public/js/modules/learning-upload/config.js` - 配置管理

### 1.2 課程與學生管理模組

- `public/js/modules/learning-upload/course-manager.js` - 課程載入、篩選、選擇
- `public/js/modules/learning-upload/student-manager.js` - 學生資料管理、出缺席處理
- `public/js/modules/learning-upload/attendance-resolver.js` - 出缺席狀態解析

### 1.3 上傳系統模組

- `public/js/modules/learning-upload/upload-manager.js` - 上傳核心邏輯（學生/總覽）
- `public/js/modules/learning-upload/upload-queue.js` - 上傳佇列管理（併發控制）
- `public/js/modules/learning-upload/upload-progress.js` - 進度追蹤與顯示
- `public/js/modules/learning-upload/retry-manager.js` - 重試機制統一管理

### 1.4 媒體處理模組

- `public/js/modules/learning-upload/media-preview-manager.js` - 媒體預覽管理（整合現有邏輯）
- `public/js/modules/learning-upload/video-poster-manager.js` - 影片縮圖生成與快取
- `public/js/modules/learning-upload/blob-url-manager.js` - Blob URL 生命週期管理（防止記憶體洩漏）
- `public/js/modules/learning-upload/media-cache.js` - 媒體快取策略

### 1.5 UI 渲染模組

- `public/js/modules/learning-upload/ui/course-renderer.js` - 課程列表渲染（虛擬滾動）
- `public/js/modules/learning-upload/ui/student-renderer.js` - 學生卡片渲染
- `public/js/modules/learning-upload/ui/overview-renderer.js` - 課程總覽渲染
- `public/js/modules/learning-upload/ui/templates-panel.js` - 評語/影片模板面板

### 1.6 工具模組

- `public/js/modules/learning-upload/utils/dom-utils.js` - DOM 操作優化工具
- `public/js/modules/learning-upload/utils/debounce-throttle.js` - 防抖節流工具
- `public/js/modules/learning-upload/utils/memory-cleanup.js` - 記憶體清理工具

### 1.7 主入口

- `public/js/pages/learning-record-upload.js` - 精簡為初始化和路由整合（< 500 行）

## 二、性能優化重點

### 2.1 DOM 操作優化

- 使用 DocumentFragment 批量操作
- 實現虛擬滾動（課程列表、學生列表）
- 事件委派取代個別監聽器
- DOM 查詢結果快取
- 減少 innerHTML 使用，改用 createElement

### 2.2 記憶體管理優化

- 統一的 Blob URL 管理器（追蹤、自動清理）
- 弱引用快取（WeakMap/WeakSet）
- 及時清理事件監聽器
- 課程切換時完整資源清理
- 頁面隱藏時釋放非必要資源

### 2.3 載入性能優化

- 代碼分割（按需載入模組）
- 懶加載非關鍵模組
- 優化初始載入順序
- 減少初始渲染工作量
- 使用 requestIdleCallback 處理非關鍵任務

### 2.4 上傳性能優化

- 優化併發控制（動態調整）
- 上傳佇列優先級管理
- 斷點續傳優化
- 減少不必要的 API 請求
- 批量操作優化

### 2.5 快取策略優化

- 統一的快取管理器
- 快取失效策略優化
- 減少重複資料載入
- 智能預載入
