# 學習歷程上傳系統

## 系統概述

建立一個完整的學習歷程管理系統，讓講師能在課後為每個學生上傳至少3張照片、1個影片和20字評語，以及課程總覽資料。系統會自動將檔案分類存儲到NAS的特定目錄結構中。

## 檔案結構設計

```
/volume1/Fun Learn Bar/學習歷程 automatic/
  ├── 114-1/                          # 學期資料夾
  │   ├── SPIKE-六1600-1800/         # 課程-時段
  │   │   ├── 2025-10-17/            # 上課日期
  │   │   │   ├── 吳昀衡/            # 學生姓名
  │   │   │   │   ├── photo1.jpg
  │   │   │   │   ├── photo2.jpg
  │   │   │   │   ├── photo3.jpg
  │   │   │   │   ├── video1.mp4
  │   │   │   │   └── comment.txt    # 評語
  │   │   │   ├── 簡筠恩/
  │   │   │   └── 課程總覽/
  │   │   │       ├── overview1.jpg  # 課程照片
  │   │   │       └── summary.txt    # 課程摘要
  │   └── SPM-六0930-1100/
  └── 夏令營-2025/
```

## 學期判斷邏輯

- 3-6月 → `{年度}-2`（下學期，如113-2）
- 7-8月 → `夏令營-{年份}`（如夏令營-2025）
- 9-12月 → `{年度}-1`（上學期，如114-1）
- 1-2月 → `冬令營-{年份}`（如冬令營-2025）

## 實施步驟

### 1. 後端開發（server.js）

#### 1.1 安裝必要套件

需要新增 `multer` 套件處理檔案上傳：

```json
"dependencies": {
  "multer": "^1.4.5-lts.1"
}
```

#### 1.2 建立核心功能模組

**學期判斷函數**：

```javascript
function getCurrentSemester() {
  const now = new Date();
  const month = now.getMonth() + 1;
  const year = now.getFullYear();
  const taiwanYear = year - 1911;
  
  if (month >= 3 && month <= 6) {
    return `${taiwanYear}-2`;
  } else if (month >= 7 && month <= 8) {
    return `夏令營-${year}`;
  } else if (month >= 9 && month <= 12) {
    return `${taiwanYear}-1`;
  } else {
    return `冬令營-${year}`;
  }
}
```

**路徑生成函數**：

```javascript
function generateLearningPath(course, period, date, studentName = null, isOverview = false) {
  const basePath = '/volume1/Fun Learn Bar/學習歷程 automatic';
  const semester = getCurrentSemester();
  const coursePeriod = `${course}-${period.replace(/\s+/g, '')}`;
  
  let fullPath = path.join(basePath, semester, coursePeriod, date);
  
  if (isOverview) {
    fullPath = path.join(fullPath, '課程總覽');
  } else if (studentName) {
    fullPath = path.join(fullPath, studentName);
  }
  
  return fullPath;
}
```

#### 1.3 API端點設計

**GET /api/learning-records/today-completed-courses**

- 獲取今天已結束的課程列表
- 從 `/api/events` 獲取行事曆資料
- 過濾出今天且結束時間已過的課程
- 關聯 `student_data.json` 獲取學生名單

**POST /api/learning-records/upload**

- 處理檔案上傳（照片、影片、評語）
- 自動創建目錄結構
- 支援學生個人資料和課程總覽
- 驗證：每個學生至少3張照片、1個影片、評語至少20字

**GET /api/learning-records/history**

- 查詢已上傳的歷程記錄
- 參數：學期、課程、日期、學生
- 返回檔案列表和評語內容

**DELETE /api/learning-records/:recordId**

- 刪除指定的學習記錄
- 支援刪除單一檔案或整個記錄

**PUT /api/learning-records/:recordId**

- 更新評語或補充照片/影片

**GET /api/learning-records/check-completion**

- 檢查特定課程/學生的上傳完成度
- 返回缺少的項目（照片數、影片、評語）

### 2. 前端開發（learning-record-upload.html）

#### 2.1 頁面結構

```html
- 頂部：日期顯示、課程選擇器
- 中間：學生卡片列表（顯示上傳進度）
- 底部：課程總覽上傳區
- 側邊：歷史記錄查看面板
```

#### 2.2 核心功能

**課程選擇區**：

- 自動載入今天已結束的課程
- 顯示課程名稱、時段、已上傳/未上傳學生數
- 支援切換不同課程

**學生上傳卡片**：

- 顯示學生姓名、剩餘堂數
- 照片上傳區（拖放或點擊，最多10張）
- 影片上傳區（支援mp4, mov等格式）
- 評語輸入框（字數統計，最少20字）
- 進度指示器（3/3照片 ✓、1/1影片 ✓、20字評語 ✓）
- 上傳按鈕（只有完成要求才能上傳）

**課程總覽區**：

- 課程照片上傳（不限張數）
- 課程摘要輸入（富文本編輯器）
- 獨立上傳按鈕

**歷史記錄面板**：

- 日期篩選器（日曆選擇）
- 課程篩選器
- 學生篩選器
- 記錄列表（顯示縮圖、評語預覽）
- 點擊展開查看完整內容
- 編輯/刪除按鈕

#### 2.3 UI/UX設計

- 使用與現有系統一致的液態玻璃風格
- 響應式設計，支援平板和手機
- 上傳進度顯示（使用進度條）
- 拖放上傳體驗優化
- 圖片預覽（縮圖展示）

### 3. 檔案處理與驗證

#### 3.1 檔案類型限制

- 照片：jpg, jpeg, png, heic（最大5MB）
- 影片：mp4, mov, avi（最大50MB）
- 自動轉換 HEIC 為 JPG（使用 sharp 或 imagemagick）

#### 3.2 檔案命名規則

```
{學生姓名}_photo_{序號}_{時間戳}.jpg
{學生姓名}_video_{序號}_{時間戳}.mp4
comment.txt
```

#### 3.3 驗證規則

- 最少3張照片
- 最少1個影片
- 評語最少20個中文字符
- 檔案大小驗證
- 檔案類型驗證

### 4. 整合現有系統

#### 4.1 使用現有資料

- `student_data.json`：獲取學生名單、課程、時段
