# 完全異步化所有上傳和預覽操作計劃

## 目標

將所有上傳和預覽操作改為完全異步，確保：

1. 函數開頭的所有同步操作都異步化
2. FormData 構建過程異步化
3. 所有 DOM 操作都使用 updateDOMAsync
4. 所有數據處理操作都異步化
5. 完全不會阻塞主線程

### 階段 1：優化 uploadOverview 函數開頭

#### 1.1 將函數改為立即返回 Promise，所有準備工作在異步中執行

**文件**: `public/js/pages/learning-record-upload.js` (9655行開始)

**改動**：

- 將函數改為返回 Promise
- 使用 `setTimeout(..., 0)` 讓準備工作在下一事件循環執行
- 將所有 DOM 查詢和更新包裝在 `updateDOMAsync` 中
- 將數據處理也改為異步（使用 `updateDOMAsync` 或 `setTimeout`）

**關鍵改動**：

```javascript
// 當前
async function uploadOverview(options) {
  // 同步操作...
  var uploadResult = await uploadFilesWithSmartManager({...});
}

// 改為
function uploadOverview(options) {
  return new Promise((resolve, reject) => {
    // 使用 setTimeout 讓準備工作在下一事件循環執行
    setTimeout(async () => {
      try {
        // 所有準備工作（DOM 查詢、數據處理）都包裝在 updateDOMAsync 中
        // ...
        var uploadResult = await uploadFilesWithSmartManager({...});
        resolve(uploadResult);
      } catch (error) {
        reject(error);
      }
    }, 0);
  });
}
```

#### 1.2 提取準備工作為獨立函數

```javascript
/**
 * 異步準備課程總覽上傳數據
 */
async function prepareOverviewUploadData(course, options) {
  return new Promise((resolve) => {
    updateDOMAsync(() => {
      // 獲取課程資訊
      var parsed = global.FLB.Course.parseTitle(course.title || '');
      var startDate = new Date(course.start);
      var dateStr = formatDateTWISO(startDate);
      var courseName = course.courseName || parsed.courseName;
      var period = (parsed.period || '').replace(/\s+/g, '');
      var semester = '114-1';
      
      // 獲取所有待上傳的檔案
      var photos = (window.overviewPhotosFiles || []).slice();
      var videos = (window.overviewVideosFiles || []).slice();
      
      // 構建格式化文本
      var summaryText = '';
      try {
        if (typeof buildOverviewBlockFromFields === 'function') {
          summaryText = buildOverviewBlockFromFields();
        }
      } catch (e) {
        console.warn('⚠️ 無法構建格式化文本:', e);
      }
      
      // 構建元數據
      var metadata = {
        semester: semester,
        courseName: course.title || (courseName + ' ' + period),
        date: dateStr,
        studentName: '課程總覽',
        isOverview: 'true'
      };
      
      if (summaryText) {
        metadata.comment = summaryText;
      }
      
      resolve({
        photos: photos,
        videos: videos,
        metadata: metadata,
        summaryText: summaryText
      });
    });
  });
}

/**
 * 異步更新課程總覽上傳初始 UI
 */
function updateOverviewUploadInitialUI(silent, btn, syncFill, syncText) {
  updateDOMAsync(() => {
    if (!silent && btn) {
      btn.classList.add('uploading');
      btn.disabled = true;
      btn.innerHTML = '<span class="loading"></span> 準備上傳...';
    } else if (silent && syncText) {
      syncText.textContent = '準備同步...';
      syncText.style.color = '#3b82f6';
    }
  }, 0); // 立即執行
}
```

### 修改 3: FormData 構建異步化

**位置**: `public/js/modules/smart-upload-manager.js` (394-407行)

**改動**：

```javascript
async buildFormDataAsync(metadata, files) {
  return new Promise((resolve) => {
    updateDOMAsync(() => {
      const formData = new FormData();
      
      // 添加元數據（分批處理，避免阻塞）
      const metadataKeys = Object.keys(metadata);
      let metadataIndex = 0;
      
      const addMetadata = () => {
        if (metadataIndex < metadataKeys.length) {
          const key = metadataKeys[metadataIndex];
          formData.append(key, metadata[key]);
          metadataIndex++;
          
          if (metadataIndex < metadataKeys.length) {
            updateDOMAsync(addMetadata, 0);
          } else {
            addFiles();
          }
        } else {
          addFiles();
        }
      };
      
      // 添加文件（分批處理，避免阻塞）
      let fileIndex = 0;
      const addFiles = () => {
        if (fileIndex < files.length) {
          const file = files[fileIndex];
          const fieldName = file.type.startsWith('video/') ? 'videos' : 
                           (metadata.isOverview ? 'overviewPhotos' : 'photos');
          formData.append(fieldName, file, file.name);
          fileIndex++;
          
          if (fileIndex < files.length) {
            // 每 5 個文件延遲一次
            if (fileIndex % 5 === 0) {
              updateDOMAsync(addFiles, 10);
            } else {
              addFiles(); // 繼續同步添加
            }
          } else {
            resolve(formData);
          }
        } else {
          resolve(formData);
        }
      };
      
      addMetadata();
    }, 0);
  });
}
```

**注意**：如果文件很少（<10個），可以同步構建；如果很多，分批處理

## 風險評估

### 低風險

1. **DOM 操作異步化**：只是延遲執行，不改變功能
2. **數據處理異步化**：數據處理很快，延遲不明顯

### 中風險

1. **函數簽名改變**：從 `async function` 改為 `function` 返回 Promise

                                                - **緩解**：檢查所有調用處，確保正確處理 Promise
                                                - **注意**：調用者已經沒有 `await`，所以安全

2. **FormData 構建異步化**：可能影響上傳時序

                                                - **緩解**：使用 `await` 確保 FormData 準備好再上傳
                                                - **注意**：分批處理時要確保所有文件都添加完成

### 需要特別注意

1. **錯誤處理**：確保 Promise 的 reject 正確處理
2. **向後兼容**：確保所有現有調用正常工作
3. **性能平衡**：不要過度異步化，導致不必要的延遲
