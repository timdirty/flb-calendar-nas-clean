## 🚀 部署流程

### 文件同步說明
- 本地檔案透過 **Synology Drive** 自動同步到 NAS
- 同步位置：`/volume1/homes/ctctim14/樂程坊計畫/...`
- Docker 容器使用：`/volume1/web/flb-calendar-nas`

### 需要重新部署的文件
1. `server.js` - 後端 API 邏輯
2. `notification-manager.js` - 通知管理邏輯
3. `flex-message-templates.json` - Flex Message 範本
4. `public/` 目錄下的前端文件

### 快速部署命令

```bash
# 1. SSH 連接到 NAS
ssh ctctim14@funlearnbar.synology.me

# 2. 進入專案目錄
cd /volume1/web/flb-calendar-nas

# 3. 複製檔案到 Docker 容器
sudo docker cp flex-message-templates.json flb-calendar-nas:/app/
sudo docker cp notification-manager.js flb-calendar-nas:/app/
sudo docker cp server.js flb-calendar-nas:/app/
sudo docker cp -r public flb-calendar-nas:/app/

# 4. 重啟容器
sudo docker-compose restart course-api

# 5. 查看日誌
sudo docker-compose logs -f course-api
```

### 完全重建（重大更新）

```bash
cd /volume1/web/flb-calendar-nas
sudo docker-compose down
sudo docker-compose build --no-cache
sudo docker-compose up -d
```
