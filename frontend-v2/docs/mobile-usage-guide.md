# 行動裝置使用指南與測試清單

## 📱 行動裝置操作說明

### 🎯 快速開始
1. **網址**: `http://<你的電腦IP>:5173/`
2. **需求**: 確保手機與電腦在同一 WiFi 網路
3. **瀏覽器**: 建議使用 Chrome 或 Safari（最新版）

### 📑 頁面導覽
- **課程選擇**: 滑動查看今日課程，點擊課程卡片選擇
- **學生管理**: 查看已選課程的學生列表，點擊學生卡片進入上傳頁
- **媒體上傳**: 上傳照片/影片並編輯學習評語

### 🔍 主要功能測試

#### 1. 導航列測試

- [ ] **點擊精準**: 手指點擊 Tab 不會誤觸到其他 Tab

- [ ] **卡片資訊**: 課程名稱、時間、地點資訊清晰可見
- [ ] **載入狀態**: 載入時有適當的載入指示器

- [ ] **空狀態**: 無學生時有適當的提示訊息

#### 4. 媒體上傳頁測試

#### 5. 錯誤處理測試
- [ ] **網路錯誤**: 網路斷線時有適當錯誤提示
- [ ] **上傳失敗**: 上傳失敗時有清楚的錯誤訊息
- [ ] **檔案限制**: 不支援的檔案格式有提示

### 📋 日常使用流程

#### 完整上傳流程
1. **選擇課程** → 點擊今日要上傳的課程
2. **選擇學生** → 點擊要上傳學習記錄的學生
3. **撰寫評語** → 輸入至少 20 字的學習評語
4. **選擇檔案** → 點擊「+ 選擇檔案」或拖放檔案
5. **預覽檔案** → 確認檔案正確，不需要的點 X 刪除
6. **開始上傳** → 點擊底部「開始上傳」按鈕
7. **等待完成** → 觀察進度條，等待上傳完成

### 🔧 常見問題解決

#### Q: 點擊刪除按鈕沒反應？
**A**: 確保：
- 不是在上傳中狀態
- 手指確實點擊到紅色 X 按鈕
- 嘗試重新整理頁面再試

#### Q: 鍵盤遮住輸入框？
**A**: 系統應該自動處理，如果沒有：
- 點擊輸入框外處再點擊回來
- 重新進入頁面

#### Q: 上傳失敗？
**A**: 檢查：
- 網路連接是否正常
- 檔案大小是否過大（建議單檔 < 100MB）
- 檔案格式是否支援（jpg, png, mp4 等）

### 📱 瀏覽器相容性

#### ✅ 支援的瀏覽器
- **iOS**: Safari 14+, Chrome 100+
- **Android**: Chrome 100+, Samsung Internet 14+

#### ❌ 不支援的瀏覽器
- 舊版 Internet Explorer
- 部分內建瀏覽器（建議使用 Chrome）

### 📞 技術支援

如果遇到問題：
1. **截圖保存**: 將問題頁面截圖
2. **記錄步驟**: 詳細記錄操作步驟
3. **檢查網路**: 確認手機與電腦網路連接正常
4. **重新整理**: 嘗試重新整理頁面
5. **回報問題**: 聯繫開發人員協助
