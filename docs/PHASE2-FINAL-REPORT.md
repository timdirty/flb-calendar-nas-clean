## 🔍 已知問題與解決方案

### 問題 1: Templates reload 端點失敗

**現象**:
```
POST /api/v3/templates/flex-templates/reload
❌ 500 Error: NotificationManager 未正確初始化
```

**根本原因**:
- `reloadFlexTemplates` 方法需要 `NotificationManager`
- 可能在初始化時未正確傳遞

**解決方案**:
1. 檢查 `routes/index.js` 中 Templates 模組的初始化
2. 確保 `notificationManager` 正確傳遞
3. 添加 null 檢查和降級處理

**優先級**: 低（不影響其他功能）
