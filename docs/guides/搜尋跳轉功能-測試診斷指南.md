# 搜尋跳轉功能 - 測試與診斷指南

## 📋 功能說明

當您使用全文搜尋找到課程後，點擊搜尋結果應該會自動：

1. ✅ 切換到課程所在的時間視圖（今日/本週/本月/全部）
2. ✅ 自動設置講師篩選
3. ✅ 自動設置日期篩選
4. ✅ 平滑滾動到該課程
5. ✅ 課程卡片高亮顯示

---

## 🧪 測試步驟

### 步驟 1: 開啟瀏覽器控制台

**為什麼要開啟控制台？**  
控制台會顯示詳細的調試信息，幫助我們找出問題所在。

**如何開啟：**
- **Chrome**: `F12` 或 `Cmd+Option+I` (Mac)
- **Firefox**: `F12` 或 `Cmd+Option+K` (Mac)
- **Safari**: `Cmd+Option+C` (需先在設定中啟用開發者選單)

**開啟後切換到 Console 標籤頁**

---

### 步驟 2: 執行搜尋

1. 在頁面頂部的搜尋框輸入課程名稱、講師名稱或學生姓名
2. 觀察控制台應該顯示：
   ```
   🔍 執行全文搜尋: "你的搜尋關鍵字"
   ✅ 搜尋完成，找到 X 筆課程
   🔍 為 X 個搜尋結果添加點擊事件處理器...
   ```

3. 檢查搜尋結果數量
   - 如果找到 **0 筆課程**：代表搜尋本身有問題
   - 如果找到 **大於 0 筆**：繼續下一步

---

### 步驟 3: 檢查點擊處理器綁定

在控制台中應該看到類似這樣的訊息：

```
🔍 [1/5] 處理事件: Python 基礎班 - 王老師
   ID: abc123...
   ✅ 方法1成功: 使用 event.id 找到卡片
   ✅ 找到事件卡片，添加點擊處理器
✅ 點擊處理器添加完成: 成功 5/5
```

**關鍵檢查點：**

#### ✅ 正常情況
```
✅ 點擊處理器添加完成: 成功 5/5
```
→ 所有搜尋結果都成功添加了點擊事件

#### ❌ 異常情況 1: 找不到卡片
```
   ❌ 找不到事件卡片
   嘗試的查詢: [data-event-id="..."]
⚠️ 有 5 個事件找不到對應的卡片
```
→ **原因**：搜尋結果中的事件沒有在當前頁面顯示  
→ **解決**：點擊後應該會自動切換視圖

#### ❌ 異常情況 2: 沒有任何處理器訊息
```
⚠️ addSearchResultClickHandlers: 沒有搜尋結果
```
→ **原因**：搜尋功能沒有返回結果  
→ **檢查**：確認搜尋關鍵字是否正確

---

### 步驟 4: 點擊搜尋結果

## 🐛 常見問題診斷

### 問題 1: 點擊後沒有任何反應

**症狀**：點擊搜尋結果卡片後，控制台沒有顯示 `🎯 [搜尋結果點擊] 事件觸發!`

**可能原因**：

1. **點擊處理器沒有綁定成功**
   - 檢查步驟 3 的訊息
   - 如果看到 `❌ 找不到事件卡片`，請繼續下一步測試

2. **點擊了按鈕而不是卡片本身**
   - 搜尋結果卡片上可能有按鈕（簽到、學生列表等）
   - **解決**：點擊卡片的空白區域，避開按鈕

3. **事件被其他 JS 攔截了**
   - 在控制台執行以下命令檢查：
     ```javascript
     document.querySelectorAll('[data-search-result="true"]').length
     ```
   - 應該顯示搜尋結果數量
   - 如果是 `0`，代表沒有成功標記搜尋結果

**手動測試**：
```javascript
// 在控制台執行以下命令
const firstResult = document.querySelector('[data-search-result="true"]');
console.log('找到搜尋結果卡片:', firstResult);
firstResult.click();
```

---

### 問題 2: 點擊後有反應，但沒有切換視圖

**症狀**：控制台顯示 `🎯 [搜尋結果點擊] 事件觸發!`，但沒有後續的導航訊息

**可能原因**：

1. **`navigateToEvent` 函數執行失敗**
   - 檢查控制台是否有紅色錯誤訊息
   - 錯誤訊息會顯示 `❌ 導航失敗:` 

2. **事件物件缺少必要資訊**
   - 查看 `📊 導航事件物件:` 的內容
   - 確認是否有 `id`, `title`, `start` 欄位

**手動測試**：
```javascript
// 在控制台執行
window.navigateToEvent({
    id: 'test-id',
    title: '測試課程 - 測試老師',
    start: '2025-01-16T10:00:00+08:00',
    instructor: '測試老師'
});
```

---

### 問題 3: 切換視圖成功，但找不到課程卡片

**症狀**：控制台顯示多次 `⚠️ 第 X 次未找到課程卡片`

**可能原因**：

1. **課程 ID 不匹配**
   - 查看 `目標 ID:` 和 `課程卡片 ID 列表:`
   - 比較兩者是否有匹配的 ID

2. **課程被篩選器過濾掉了**
   - 講師篩選可能選錯了
   - 日期篩選可能設定錯了
   - 課程類型篩選可能遮蔽了該課程

3. **渲染延遲**
   - 系統已經設定最多重試 5 次
   - 如果 5 次都失敗，可能是渲染速度問題

**手動檢查**：
```javascript
// 檢查當前頁面的事件卡片
document.querySelectorAll('[data-event-id]').forEach(card => {
    console.log('ID:', card.getAttribute('data-event-id'));
    console.log('標題:', card.getAttribute('data-event-title'));
});
```

---

### 問題 4: 講師篩選沒有自動選擇

**症狀**：視圖切換成功，但講師下拉選單仍然是「全部講師」

**可能原因**：

1. **講師名稱提取失敗**
   - 查看 `👨‍🏫 最終識別講師:` 的值
   - 如果是 `(無法識別)`，代表無法從課程標題中提取講師名稱

2. **講師名稱不匹配**
   - 查看 `⚠️ 找不到匹配的講師選項:`
   - 查看 `可用的講師選項:` 列表
   - 比較兩者是否有差異（例如：多餘的空格、不同的破折號）

**手動檢查講師選項**：
```javascript
// 列出所有講師選項
const select = document.getElementById('instructorSelect');
Array.from(select.options).forEach((opt, i) => {
    console.log(`${i}: "${opt.text}" (value: "${opt.value}")`);
});
```

---

### 問題 5: 日期篩選沒有自動設置

**症狀**：視圖切換成功，但日期篩選器是空的

**可能原因**：

1. **日期篩選器元素不存在**
   - 查看 `⚠️ 找不到日期篩選器 #eventDateFilter`
   - 確認 HTML 中是否有 `id="eventDateFilter"` 的元素

2. **日期格式問題**
   - 查看 `✅ 設置日期篩選為:` 的值
   - 應該是 `YYYY-MM-DD` 格式

**手動檢查**：
```javascript
// 檢查日期篩選器
const dateFilter = document.getElementById('eventDateFilter');
console.log('日期篩選器:', dateFilter);
console.log('當前值:', dateFilter ? dateFilter.value : '不存在');
```

## 🛠️ 進階診斷工具

### 工具 1: 檢查搜尋功能狀態

在控制台執行：

```javascript
console.log('=== 搜尋功能狀態檢查 ===');
console.log('SearchManager:', window.SearchManager);
console.log('searchManager 實例:', window.searchManager);
console.log('performGlobalSearch:', typeof window.performGlobalSearch);
console.log('navigateToEvent:', typeof window.navigateToEvent);
console.log('allEvents 數量:', window.allEvents?.length || 0);
console.log('filteredEvents 數量:', window.filteredEvents?.length || 0);
```

**預期結果**：
- 所有函數類型應該是 `function`
- `allEvents` 應該有數量（大於 0）

---

### 工具 2: 手動觸發搜尋

```javascript
// 手動執行搜尋
const results = window.performGlobalSearch('Python');
console.log('搜尋結果:', results);
console.log('結果數量:', results.length);

// 查看第一筆結果的詳細資訊
if (results.length > 0) {
    console.log('第一筆結果:', results[0]);
}
```

---

### 工具 3: 手動添加點擊處理器

```javascript
// 手動為搜尋結果添加點擊處理器
if (window.filteredEvents && window.filteredEvents.length > 0) {
    console.log('手動添加點擊處理器...');
    window.addSearchResultClickHandlers(window.filteredEvents);
}
```

---

### 工具 4: 檢查事件卡片

```javascript
// 列出所有事件卡片的資訊
const cards = document.querySelectorAll('[data-event-id]');
console.log(`找到 ${cards.length} 個事件卡片`);

cards.forEach((card, index) => {
    if (index < 5) { // 只顯示前 5 個
        console.log(`卡片 ${index + 1}:`, {
            id: card.getAttribute('data-event-id'),
            title: card.getAttribute('data-event-title'),
            instructor: card.getAttribute('data-event-instructor'),
            isSearchResult: card.getAttribute('data-search-result') === 'true',
            hasClickHandler: card.onclick !== null || card.hasAttribute('data-search-result')
        });
    }
});
```

## 🚀 下一步行動

### 如果所有測試都通過

恭喜！搜尋跳轉功能正常運作。您可以：

1. 清除瀏覽器控制台的輸出（方便下次測試）
2. 關閉控制台，正常使用系統
3. 如果覺得日誌太多，可以在程式碼中調整 `console.log` 的頻率

### 如果測試失敗

請：

1. **截圖控制台的完整輸出**（包含錯誤訊息）
2. **記錄您的操作步驟**：
   - 搜尋的關鍵字是什麼？
   - 點擊了哪個搜尋結果？
   - 當前在哪個視圖（今日/本週/本月/全部）？
3. **執行上面的「進階診斷工具」**，複製輸出結果
4. **將上述資訊提供給開發人員**，以便快速定位問題

- 如果懷疑是瀏覽器快取問題，請按 `Ctrl+Shift+R` (Windows) 或 `Cmd+Shift+R` (Mac) 強制重新載入
- 如果問題持續存在，可以嘗試清除瀏覽器快取和 localStorage
- 建議使用 Chrome 瀏覽器測試，其開發者工具功能最完整
