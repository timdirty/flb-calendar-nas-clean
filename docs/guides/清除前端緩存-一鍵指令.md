# 清除前端緩存 - 一鍵指令

## 🎯 何時需要清除緩存？

如果遇到以下情況，請清除前端緩存：

- ✅ 看到已刪除的影片仍在顯示
- ✅ 影片顯示「▶」圖標而不是縮圖（且確認影片存在）
- ✅ 系統更新後，畫面沒有變化
- ✅ 資料顯示不正確或過時

---

## 🚀 一鍵清除指令

### 方法 1：瀏覽器 Console（推薦）

1. 按 **F12** 或 **Cmd+Option+I**（Mac）打開開發者工具
2. 切換到 **Console** 標籤
3. 複製並貼上以下指令，按 Enter：

```javascript
// 🧹 一鍵清除所有緩存並重載
(function() {
    console.log('🧹 開始清除所有緩存...');
    
    // 清除 localStorage
    try {
        localStorage.clear();
        console.log('✅ localStorage 已清除');
    } catch (e) {
        console.warn('⚠️ localStorage 清除失敗:', e);
    }
    
    // 清除 sessionStorage
    try {
        sessionStorage.clear();
        console.log('✅ sessionStorage 已清除');
    } catch (e) {
        console.warn('⚠️ sessionStorage 清除失敗:', e);
    }
    
    // 清除 Cookies
    try {
        document.cookie.split(";").forEach(function(c) { 
            document.cookie = c.replace(/^ +/, "").replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/"); 
        });
        console.log('✅ Cookies 已清除');
    } catch (e) {
        console.warn('⚠️ Cookies 清除失敗:', e);
    }
    
    // 清除 Cache API
    if ('caches' in window) {
        caches.keys().then(function(names) {
            names.forEach(function(name) {
                caches.delete(name);
            });
            console.log('✅ Cache API 已清除');
        });
    }
    
    console.log('✅ 緩存已清除，2秒後重新載入...');
    setTimeout(function() {
        location.reload(true);
    }, 2000);
})();
```

### 方法 2：手動清除（Chrome）

1. 按 **Cmd+Shift+Delete**（Mac）或 **Ctrl+Shift+Delete**（Windows）
2. 選擇「時間範圍」：**不限時間**
3. 勾選：
   - ✅ Cookies 和其他網站資料
   - ✅ 快取圖片和檔案
4. 點擊「清除資料」
5. 重新整理頁面（**Cmd+Shift+R** 或 **Ctrl+Shift+F5**）

### 方法 3：手動清除（Safari）

1. 開啟 Safari
2. 按 **Cmd+Option+E** 清除快取
3. 前往「設定」→「隱私權」→「管理網站資料」
4. 搜尋 `calendar.funlearnbar.synology.me`
5. 點擊「移除」
6. 重新整理頁面（**Cmd+R**）

## ⚠️ 注意事項

### 清除緩存後會怎樣？

**會失去的**：
- ❌ 自動登入狀態（需要重新登入 LINE LIFF）
- ❌ 草稿資料（未儲存的評語）
- ❌ 頁面設定（篩選條件等）

**不會失去的**：
- ✅ 已上傳的照片和影片
- ✅ 已儲存的學習記錄
- ✅ 系統資料

### 建議的操作順序

```
1. 確認已儲存所有草稿
   ↓
2. 執行清除緩存指令
   ↓
3. 等待頁面自動重新載入
   ↓
4. 重新登入 LINE（如需要）
   ↓
5. 驗證問題是否解決
```

## 🎓 技術原理

### 為什麼需要清除緩存？

瀏覽器會保存以下資料以提升效能：

| 緩存類型 | 內容 | 影響 |
|---------|------|------|
| localStorage | 課程列表、學生資料 | ⚠️ 可能顯示舊資料 |
| sessionStorage | 當前頁面狀態 | ⚠️ 頁面行為異常 |
| Cookies | 登入狀態、設定 | ⚠️ 登入問題 |
| Cache API | 圖片、影片縮圖 | ⚠️ 顯示舊縮圖 |

**當後端更新時**，這些緩存可能與伺服器不一致，導致顯示問題。

### 強制重新整理 vs 一般重新整理

| 類型 | 快捷鍵 | 效果 |
|------|--------|------|
| 一般重新整理 | F5 / Cmd+R | 可能使用快取 |
| 強制重新整理 | Ctrl+F5 / Cmd+Shift+R | 略過快取，重新下載 |
| 一鍵清除 | 上面的指令 | 清除所有緩存 + 重新整理 |
