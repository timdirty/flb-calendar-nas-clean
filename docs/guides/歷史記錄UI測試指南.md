# 歷史記錄 UI 測試指南

## 🚀 快速開始

1. **打開學習歷程頁面**
   ```
   https://calendar.funlearnbar.synology.me/learning-record-upload.html
   ```

2. **點擊左上角「查看歷史記錄」按鈕**
   - 或點擊綠色的歷史記錄 FAB 按鈕

3. **選擇一個課程記錄並展開**

## ✅ 測試檢查清單

### 1. Tab 切換功能

- [ ] **課程總覽 Tab**
  - 點擊「📊 課程總覽」Tab
  - 應該顯示藍色課程卡片
  - 卡片包含：標題、評語內容、查看按鈕
  - Tab 按鈕應該變成藍色背景

- [ ] **學生記錄 Tab**
  - 點擊「👥 學生記錄」Tab
  - 應該顯示綠色學生卡片網格
  - 每個卡片包含：學生姓名、媒體數量、評語摘要、查看按鈕
  - Tab 按鈕應該變成藍色背景

- [ ] **Tab 數字顯示**
  - 學生記錄 Tab 應該顯示學生數量，例如「學生記錄 (3)」

### 2. 內容顯示測試

- [ ] **課程總覽卡片**
  - 評語內容完整顯示（不截斷）
  - 長評語可以滾動查看（最多 400px 高度）
  - 「查看完整內容」按鈕可點擊
  - 卡片 hover 時有上移效果

- [ ] **學生記錄卡片**
  - 所有學生卡片都能看到（不截斷） ⭐ **重點測試**
  - 學生姓名清晰顯示
  - 照片/影片數量正確
  - 評語摘要顯示（最多 150 字）
  - 「查看完整記錄」按鈕可點擊

- [ ] **網格布局**
  - 桌面：3 列展示
  - 平板：2 列展示
  - 手機：1 列展示

### 3. 交互效果測試

- [ ] **Tab 切換動畫**
  - 切換時有淡入動畫（0.3s）
  - 動畫流暢不卡頓
  - 內容切換即時

- [ ] **卡片 Hover 效果**

  - 過渡動畫流暢

  - Hover 時變深色

  - 正確跳轉到詳細記錄

  - 不顯示 Tab 選單

- [ ] **只有學生記錄（無課程總覽）**

- [ ] **無任何記錄**

## 🐛 常見問題排查

### 問題 1：Tab 切換沒反應
**檢查**：
- 瀏覽器控制台是否有錯誤
- `switchRecordTab` 函數是否正確載入
- Tab 按鈕的 `onclick` 屬性是否正確

### 問題 2：學生卡片還是被截斷
**檢查**：
- CSS 文件是否正確載入
- `.students-grid` 樣式是否生效
- 瀏覽器快取是否清除（Ctrl+Shift+R）

### 問題 3：樣式不正確
**檢查**：
- 確認 `history-records-tabs.css` 已引入
- 檢查 CSS 載入順序
- 檢查是否有衝突的樣式

### 問題 4：卡片 Hover 效果異常
**檢查**：
- 是否在低階設備上（會自動禁用動畫）
- 是否開啟了「減少動態效果」系統設定
