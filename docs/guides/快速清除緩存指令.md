# 快速清除緩存指令

## 🔥 問題現象

前端顯示已刪除的照片或影片，點擊刪除按鈕顯示「檔案不存在」錯誤。

## ✅ 完整解決方案（3 步驟）

### 步驟 1：執行後端清理

打開終端機（Terminal），執行以下指令：

```bash
# 生產環境
curl -X POST https://calendar.funlearnbar.synology.me/api/clean-all-metadata

# 本地測試
curl -X POST http://localhost:3002/api/clean-all-metadata
```

### 步驟 2：清除前端緩存

打開瀏覽器，按 **F12** 或 **Cmd+Option+I（Mac）** 打開開發者工具，切換到 **Console** 標籤，複製貼上以下指令並執行：

```javascript
// 🔥 一鍵清除所有緩存並重載
(function() {
    console.log('🧹 開始清除所有緩存...');
    localStorage.clear();
    sessionStorage.clear();
    document.cookie.split(";").forEach(c => { 
        document.cookie = c.replace(/^ +/, "").replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/"); 
    });
    if ('caches' in window) {
        caches.keys().then(names => {
            names.forEach(name => caches.delete(name));
        });
    }
    console.log('✅ 緩存已清除，2秒後重新載入...');
    setTimeout(() => location.reload(true), 2000);
})();
```

### 步驟 3：驗證結果

頁面重新載入後，確認：
- ✅ 不存在的照片/影片已不再顯示
- ✅ 可以正常瀏覽學習記錄
- ✅ 上傳新照片/影片正常

## 📋 簡易版（僅清除緩存）

如果只需要清除緩存（不執行後端清理），在瀏覽器 Console 執行：

```javascript
localStorage.clear();
sessionStorage.clear();
location.reload(true);
```

## 🔧 手動清除（不使用 Console）

### Chrome / Edge

1. 按 **Cmd/Ctrl + Shift + Delete**
2. 勾選「快取的圖片和檔案」
3. 選擇「所有時間」
4. 點擊「清除資料」

### Safari

1. 開發 → 清除快取
2. 或：Safari 偏好設定 → 隱私權 → 管理網站資料 → 移除全部

### Firefox

1. 按 **Cmd/Ctrl + Shift + Delete**
2. 勾選「快取」和「Cookie」
3. 選擇「所有時間」
4. 點擊「立即清除」

## ⚠️ 注意事項

1. **清除緩存會登出**：清除後需要重新登入 LINE LIFF
2. **不會影響資料**：只清除瀏覽器本地緩存，不會刪除伺服器資料
3. **定期執行**：建議每月執行一次批量清理，保持資料整潔
4. **多人使用**：如果多人遇到相同問題，每個人都需要清除自己的瀏覽器緩存

## 🚀 自動化清理（管理員）

如果需要定期自動清理，可以設定 cron job：

```bash
# 每天凌晨 3 點執行清理
0 3 * * * curl -X POST https://calendar.funlearnbar.synology.me/api/clean-all-metadata
```

或在伺服器端添加排程任務（需要修改 `server.js`）。
