## 🎯 目的

診斷選擇照片/影片後無法上傳的問題

## ✅ 已套用的修復

### 1. 在 `shared-integration.js` 加入詳細日誌

- ✅ 顯示檔案處理前後的 entry 狀態
- ✅ 顯示每個檔案加入 entry 的過程
- ✅ 顯示 checkUpload 回調是否被呼叫

---

## 🧪 測試步驟

### 步驟 1: 準備環境

1. 開啟瀏覽器開發者工具 (F12)
2. 切換到 Console 標籤
3. 清除現有日誌 (Console 左上角的🚫圖標)

### 步驟 2: 選擇單張照片

1. 進入學習記錄上傳頁面
2. 選擇一個課程
3. 點選第一位學生的「照片」上傳區
4. 選擇 **1 張** 照片（建議 1-5 MB）

### 步驟 3: 觀察 Console 日誌

**立即複製所有日誌**，尋找以下關鍵訊息：

#### ✅ 正常流程應該看到：

```
🎯 [SharedIntegration] 處理學生媒體: { studentIndex: 0, type: 'photos', filesCount: 1, ... }
🚀 [processFiles] 開始處理 1 個檔案 (類型: image )
📦 [1/1] 處理: IMG_1234.jpg
📦 [SharedIntegration] 檔案處理完成: { fileName: "IMG_1234.jpg", fileSize: "2.35 MB", ... }
✅ [SharedIntegration] 檔案已加入 entry: { entryLengthAfter: 1 }
✅ [processFiles] 流式處理完成，共處理 1 個檔案
✅ [SharedIntegration] 學生媒體處理完成: { allFilesLength: 1, entryPhotosLength: 1, ... }
🚀 [SharedIntegration] 準備呼叫 checkUpload
```

#### ❌ 如果出現以下訊息，說明有問題：

```
⚠️ [SharedIntegration] checkUpload 回調不存在
```

→ **問題**: `checkUpload` 回調沒有正確傳遞

```
✅ [SharedIntegration] 檔案已加入 entry: { entryLengthAfter: 0 }
```

→ **問題**: 檔案沒有正確加入 `entry`

## 📊 檢查點

### 檢查點 1: 檔案是否加入 entry？

在 Console 輸入：

```javascript
// 檢查學生 0 的照片數量
console.log('照片數量:', window.studentFiles[0].photos.length);
console.log('照片列表:', window.studentFiles[0].photos.map(f => f.name));
```

**預期結果**: 應該顯示 1 張照片

---

### 檢查點 2: 是否觸發自動上傳？

等待 1-2 秒後，在 Console 輸入：

```javascript
// 檢查自動上傳計時器
console.log('自動上傳計時器:', window.autoUploadTimers);
console.log('上傳中的學生:', window.uploadingStudents);
```

**預期結果**: 
- `autoUploadTimers` 應該是空的（已觸發）
- `uploadingStudents[0]` 應該是 `true`（正在上傳）

---

### 檢查點 3: 上傳進度是否顯示？

查看頁面上的學生卡片：

- 照片預覽是否顯示？ ✅ / ❌
- 照片預覽是否有「上傳中」的進度條？ ✅ / ❌
- 進度條是否從 5% 開始增加？ ✅ / ❌

## 🔧 常見問題排查

### 問題 A: 看不到任何日誌

**可能原因**:
1. 瀏覽器快取未清除
2. 新版本程式碼未載入

**解決方法**:
1. 強制重新載入頁面: `Ctrl+Shift+R` (Windows) 或 `Cmd+Shift+R` (Mac)
2. 清除瀏覽器快取
3. 使用無痕模式測試

---

### 問題 B: 日誌顯示「checkUpload 回調不存在」

**可能原因**: `learning-record-upload.js` 中的 `handleFileSelect` 沒有正確傳遞回調

**需要檢查**: 確認 `learning-record-upload.html` 是否載入了最新版本的 JS 檔案

---

### 問題 C: 檔案加入 entry 但沒有觸發上傳

**可能原因**: 
1. `checkUploadReady` 判斷條件不符
2. `hasPendingChanges` 返回 false
3. 學生被鎖定 (`locked = true`)

**排查方法**: 在 Console 執行

```javascript
// 檢查學生狀態
var studentIndex = 0;
console.log('學生狀態:', {
  photos: window.studentFiles[studentIndex].photos.length,
  videos: window.studentFiles[studentIndex].videos.length,
  locked: window.studentFiles[studentIndex].locked,
  uploading: window.uploadingStudents[studentIndex]
});
```
