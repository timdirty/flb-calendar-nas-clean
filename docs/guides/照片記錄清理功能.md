# 照片/影片記錄清理功能說明

## 問題描述

之前系統可能會出現以下問題：
- 前端顯示已經被刪除的照片或影片
- 點擊刪除按鈕顯示「檔案不存在」錯誤
- `photos-meta.json` 和 `videos-meta.json` 中包含不存在的檔案記錄

## 修復內容

### 1. 自動清理機制（修復日期：2025-11-06）

**功能**：在讀取學習記錄時自動過濾並更新 meta 檔案

**位置**：`server.js` 第 16852-16920 行

**邏輯**：
1. 讀取 `photos-meta.json` 或 `videos-meta.json`
2. 檢查每個記錄對應的檔案是否存在
3. 過濾掉不存在的檔案記錄
4. 如果有記錄被過濾：
   - 若剩餘記錄為 0，刪除 meta 檔案
   - 若剩餘記錄 > 0，更新 meta 檔案（移除不存在的記錄）

**日誌輸出**：
```
⚠️ 照片文件已不存在，跳過: test-photo.jpg
🔄 過濾後照片數量: 4 → 3
✅ 已自動清理 photos-meta.json，移除 1 個不存在的照片記錄
```

### 2. 批量清理 API（新增）

**端點**：`POST /api/clean-all-metadata`

**功能**：掃描所有學習記錄目錄，清理所有 `photos-meta.json` 和 `videos-meta.json` 中不存在的檔案記錄

**使用方式**：

#### 方式一：使用 curl

```bash
curl -X POST http://localhost:3002/api/clean-all-metadata
```

#### 方式二：使用生產環境域名

```bash
curl -X POST https://calendar.funlearnbar.synology.me/api/clean-all-metadata
```

**回應格式**：

```json
{
  "success": true,
  "data": {
    "totalDirectories": 45,
    "processedDirectories": 5,
    "photosMetaCleaned": 1,
    "videosMetaCleaned": 0,
    "totalPhotosRemoved": 3,
    "totalVideosRemoved": 0,
    "emptyMetaDeleted": 0,
    "errors": []
  },
  "message": "已清理 3 個無效媒體引用"
}
```

**回應欄位說明**：
- `totalDirectories`: 掃描的總目錄數
- `processedDirectories`: 包含 meta 檔案的目錄數
- `photosMetaCleaned`: 清理的 photos-meta.json 檔案數
- `videosMetaCleaned`: 清理的 videos-meta.json 檔案數
- `totalPhotosRemoved`: 移除的照片記錄總數
- `totalVideosRemoved`: 移除的影片記錄總數
- `emptyMetaDeleted`: 刪除的空 meta 檔案數
- `errors`: 錯誤列表

**日誌輸出**：
```
🧹 開始批量清理所有學習記錄的無效媒體引用...
🔍 檢查目錄: /path/to/student/
  ⚠️ 照片不存在: test-photo.jpg
  ✅ 清理 photos-meta.json: 4 → 3
✅ 批量清理完成
📊 統計資訊: { 總目錄數: 45, 處理目錄數: 5, ... }
```

## 使用建議

### 何時使用自動清理

自動清理會在以下情況觸發：
1. 前端載入學生學習記錄時
2. 查詢課程學習記錄時
3. 任何讀取 `photos-meta.json`、`videos-meta.json` 或 `media-meta.json` 的操作

**優點**：無需手動操作，自動維護資料一致性

### 何時使用批量清理 API

建議在以下情況手動執行批量清理：
1. 系統維護時
2. 發現大量不存在的照片/影片記錄時
3. 遷移或備份資料後
4. 定期清理（例如每月一次）

**優點**：一次性清理所有記錄，生成完整的統計報告

### 完整清理流程（推薦）

1. **後端清理**：執行批量清理 API
   ```bash
   curl -X POST https://calendar.funlearnbar.synology.me/api/clean-all-metadata
   ```

2. **前端清除緩存**：在瀏覽器 Console 執行
   ```javascript
   (function() {
       console.log('🧹 開始清除所有緩存...');
       localStorage.clear();
       sessionStorage.clear();
       document.cookie.split(";").forEach(c => { 
           document.cookie = c.replace(/^ +/, "").replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/"); 
       });
       if ('caches' in window) {
           caches.keys().then(names => {
               names.forEach(name => caches.delete(name));
           });
       }
       console.log('✅ 緩存已清除，2秒後重新載入...');
       setTimeout(() => location.reload(true), 2000);
   })();
   ```

3. **驗證結果**：重新載入頁面，確認不存在的照片已不再顯示

## 故障排除

### 問題：清理後前端仍顯示不存在的照片

**原因**：前端的 localStorage/sessionStorage 保存了舊的學習記錄資料

**解決方案 1：一鍵清除所有緩存（推薦）**

在瀏覽器開發者工具的 Console 中執行以下指令：

```javascript
// 🔥 一鍵清除所有緩存並重載
(function() {
    console.log('🧹 開始清除所有緩存...');
    localStorage.clear();
    sessionStorage.clear();
    document.cookie.split(";").forEach(c => { 
        document.cookie = c.replace(/^ +/, "").replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/"); 
    });
    if ('caches' in window) {
        caches.keys().then(names => {
            names.forEach(name => caches.delete(name));
        });
    }
    console.log('✅ 緩存已清除，2秒後重新載入...');
    setTimeout(() => location.reload(true), 2000);
})();
```

**解決方案 2：手動清除**

1. 打開瀏覽器開發者工具（F12）
2. 執行以下指令：
   ```javascript
   localStorage.clear();
   sessionStorage.clear();
   ```
3. 強制重新整理頁面（Cmd/Ctrl + Shift + R）

**解決方案 3：使用瀏覽器功能**

1. Chrome/Edge：設定 → 隱私權和安全性 → 清除瀏覽資料 → 選擇「快取的圖片和檔案」
2. Safari：開發 → 清除快取
3. Firefox：設定 → 隱私權與安全性 → Cookie 與網站資料 → 清除資料

### 問題：批量清理 API 回傳錯誤

**可能原因**：
1. 權限不足：檢查目錄權限
2. 檔案被鎖定：確認沒有其他程序正在使用
3. JSON 格式錯誤：檢查 meta 檔案格式

**解決方案**：
```bash
# 檢查權限
ls -la data/learning-portfolio/

# 查看錯誤詳情
curl -X POST http://localhost:3002/api/clean-all-metadata | jq '.data.errors'
```
