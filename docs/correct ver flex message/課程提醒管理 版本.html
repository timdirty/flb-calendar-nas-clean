請假通知設定

功能說明

當學生家長透過 LINE 回覆「請假」或「待確認」時，系統會自動發送通知訊息到指定的群組。 您可以在此設定通知的條件和目標群組。

基本設定

開啟後，符合條件的學生回應將自動發送通知到群組
請輸入 LINE 群組的 Group ID。可以從 LINE Developers Console 查詢。
使用精美的卡片式訊息，若關閉則使用純文字訊息

通知條件

選擇哪些類型的回應需要發送通知：

家長回覆「會出席」時發送通知
家長回覆「請假」時發送通知（推薦開啟）
家長回覆「待確認」時發送通知（推薦開啟）

建議設定

  • 建議開啟「請假」和「待確認」通知，讓講師即時了解學生狀況
  • 「會出席」通知通常不需要開啟，避免訊息過多
  • 使用 Flex Message 可以讓通知更美觀易讀
  • 通知群組 ID 可以從 LINE 官方帳號後台取得
