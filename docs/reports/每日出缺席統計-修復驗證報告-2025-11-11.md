# 每日出缺席統計 — 修復與驗證報告（2025-11-11）

## 目標
- 讓 Flex Message「每日出缺席統計」在缺少 baseline（studentReminders）時也能正確計算與發送。
- 讓後台 admin-dashboard.html 的「家長回應統計」可即時查詢指定日期統計，不依賴快取檔是否存在。

## 關鍵變更
- server.js：新增 `computeDailyAttendanceSummaryForDate(dateStr, { sendFlex, persistCache, source })`
  - 缺 baseline 時，透過 `reminderScheduler.generateStudentBaselineForDate(dateStr)` 即時從行事曆建立 baseline（不落盤）。
  - 可選擇是否發送 Flex、是否寫入快取檔 `data/daily-attendance-reports.json`。
  - 原 `generateDailyAttendanceReport` 改為呼叫上述通用函式（預設今日、發送 Flex 並快取）。
- server.js：`GET /api/student-responses/summary`
  - 對請求區間內缺漏的日期即時計算統計（不發送、不快取），後台查詢不再顯示空白。
- reminder-scheduler.js：新增
  - `getCombinedStudents()`：回傳正式 + 臨時學生（補課/體驗，含有效期與 userId 合併）。
  - `generateStudentBaselineForDate(dateStr)`：生成指定日期的 baseline（不落盤）。

## 測試重點
1) 本地啟動（避免阻塞）
```
PORT=3002 DISABLE_AUTO_REMINDERS=true ENABLE_DAILY_REPORT=false npm run dev > /tmp/npm-dev.log 2>&1 & echo $!
```
等待 12–15 秒，確認 /tmp/npm-dev.log 出現 API listeners、排程器訊息。

2) 立即產生日報（今日）：
```
curl -X POST http://localhost:3002/api/daily-attendance-report/trigger
```
若缺 baseline，日誌會顯示「嘗試即時從行事曆建立 baseline…」並顯示筆數。

3) 後台查詢（家長回應統計）：
```
curl "http://localhost:3002/api/student-responses/summary?start=$(date +%F)&end=$(date +%F)"
```
回傳 `totals` 與 `daily[0]` 應包含 attend/leave/pending/noResponse。

4) Flex 發送驗證（需設定通知群組）：
將 `ENABLE_DAILY_REPORT=true`，等到 08:00（台灣時區）或手動觸發，即可於群組收到 Flex 報表。

## 回滾
- `server.js`：移除 `computeDailyAttendanceSummaryForDate`，還原 `generateDailyAttendanceReport` 原實作；
- `reminder-scheduler.js`：移除新加入的兩個方法。

## 備註
- 即時計算不會寫入每日快取檔，僅用於查詢與 UI 呈現；正式報表仍以排程或手動觸發落盤為準。
