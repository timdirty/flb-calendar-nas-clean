# 歷史記錄UI優化 - 修改說明

## 📊 問題分析

### 問題 1：講師資訊未顯示
- 課程名稱格式：`ESM 四 17:30-18:30 到府 第10週`
- 不包含講師名稱，導致講師標籤無法顯示

### 問題 2：UI 混亂
- 同一堂課的「總覽」和「學生記錄」分開顯示
- 用戶看到同一課程有多筆記錄，難以理解

## ✅ 解決方案

### 1. 記錄分組與合併

**修改位置**：`public/js/pages/learning-record-upload.js` - `loadHistory()` 函數

**實現邏輯**：
- 將所有記錄按 `course + date` 分組
- 每個分組包含：
  - 課程總覽（overview）
  - 學生列表（students[]）
  - 總計照片/影片數量

```javascript
// 分組結構
{
  course: "ESM 四 17:30-18:30 到府 第10週",
  date: "2025-11-06 自動畫圖機",
  overview: { ... },      // 課程總覽記錄
  students: [...],        // 學生記錄陣列
  totalPhotos: 25,
  totalVideos: 3
}
```

### 2. 全新UI設計

#### 卡片結構

```
┌─────────────────────────────────────────┐
│ 📚 ESM 四 17:30-18:30 到府 第10週       │  ← 課程名稱

展開後：

└─────────────────────────────────────────┘
```

### 3. 講師資訊提取優化

**當前邏輯**：
1. 嘗試從 `record.teacher` 欄位獲取（後端暫不提供）
2. 嘗試從路徑解析（`/114-1/講師/課程/...` 格式）
3. 從課程標題中匹配講師名稱

**建議改進**（需後端配合）：
- 後端在 `extractRecordInfo()` 中添加講師欄位
- 通過查詢日曆事件或配置檔案匹配講師

## 🎨 UI 優化亮點

### 1. 資訊層級清晰
- **一級資訊**：課程名稱、標籤、日期
- **二級資訊**：統計數據
- **三級資訊**：詳細內容（需展開）

### 2. 視覺設計
- 講師和課別使用動態顏色標籤
- 圖標輔助識別（📅 日期、👥 學生、📷 照片、🎬 影片）
- 可折疊設計節省空間

### 3. 互動優化
- 點擊卡片摘要區展開/收合
- 獨立的「查看詳情」按鈕跳轉到完整記錄
- 學生列表清晰呈現個別資訊
