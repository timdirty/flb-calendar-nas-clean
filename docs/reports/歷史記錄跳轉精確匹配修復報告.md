# 📍 歷史記錄跳轉精確匹配修復報告

## 🐛 問題描述

### 用戶反映的問題
從歷史記錄點擊「查看完整內容」跳轉時，會跳轉到**錯誤的課程**：

**案例：**
- **點擊課程**：`ESM 四 17:30-18:30 到府 第10週`
- **實際跳轉到**：`SPM 四 17:30-18:30 到府 第1週` ❌

### 問題根源
原有的課程匹配邏輯**過於寬鬆**，使用了模糊的字串包含判斷：
```javascript
// ❌ 問題邏輯
titleMatch = cleanTitle.includes(cleanCourse) || cleanCourse.includes(cleanTitle) ||
            cleanTitle.startsWith(cleanCourse.split(' ')[0]) ||
            c.title.includes(course) || course.includes(c.title);
```

這導致：
- ✅ 匹配了日期：2025-11-06
- ✅ 匹配了時間：17:30-18:30
- ✅ 匹配了地點：到府
- ❌ **沒有精確匹配課程類型**：ESM vs SPM
- ❌ **沒有精確匹配週次**：第10週 vs 第1週

結果就是系統找到了第一個符合時間和地點的課程，而不是正確的那個。

---

## 🔧 修復方案

### 新的精確匹配策略

實現了**多層級精確匹配**，按以下順序檢查：

1. **📅 日期匹配**（必須）
2. **📚 課程類型匹配**（必須）- 提取開頭的大寫字母組合
3. **📖 週次匹配**（如果有） - 提取「第X週」
4. **⏰ 時間匹配**（如果有） - 提取「HH:MM-HH:MM」

### 實現代碼

```javascript
// 🎯 提取課程類型（ESM、SPM、SPIKE 等）
function extractCourseType(str) {
  if (!str) return '';
  // 匹配課程類型：大寫字母組合（如 ESM、SPM、SPIKE）
  var match = str.match(/^([A-Z]+)/);
  return match ? match[1] : '';
}

// 🎯 提取週次
function extractWeek(str) {
  if (!str) return '';
  var match = str.match(/第(\d+)週/);
  return match ? match[1] : '';
}

// 精確匹配邏輯
var targetCourseType = extractCourseType(course);  // "ESM"
var targetWeek = extractWeek(course);               // "10"

targetCourse = courses.find(function (c) {
  // 1. 日期必須匹配
  var dateMatch = formatDateTWISO(new Date(c.start)) === date;
  if (!dateMatch) return false;
  
  // 2. 課程類型必須匹配
  var currentCourseType = extractCourseType(c.title);  // "ESM" 或 "SPM"
  var courseTypeMatch = targetCourseType && currentCourseType && 
                        targetCourseType === currentCourseType;
  
  // 3. 週次必須匹配（如果兩邊都有）
  var currentWeek = extractWeek(c.title);
  var weekMatch = !targetWeek || !currentWeek || targetWeek === currentWeek;
  
  // 4. 時間必須匹配（如果兩邊都有）
  var timePattern = /(\d{1,2}:\d{2})-(\d{1,2}:\d{2})/;
  var targetTime = course.match(timePattern);
  var currentTime = c.title.match(timePattern);
  var timeMatch = true;
  if (targetTime && currentTime) {
    timeMatch = targetTime[0] === currentTime[0];
  }
  
  return courseTypeMatch && weekMatch && timeMatch;
});
```

## 🎯 匹配規則詳解

### 1. 課程類型提取
```javascript
extractCourseType("ESM 四 17:30-18:30 到府 第10週")  // → "ESM"
extractCourseType("SPM 四 17:30-18:30 到府 第1週")   // → "SPM"
extractCourseType("SPIKE 三 18:30-20:30 第8週")     // → "SPIKE"
```

**規則**：匹配字串開頭的連續大寫字母

### 2. 週次提取
```javascript
extractWeek("ESM 四 17:30-18:30 到府 第10週")  // → "10"
extractWeek("SPM 四 17:30-18:30 到府 第1週")   // → "1"
extractWeek("課程沒有週次資訊")                // → ""
```

**規則**：匹配「第X週」格式，提取數字部分

### 3. 時間提取
```javascript
var timePattern = /(\d{1,2}:\d{2})-(\d{1,2}:\d{2})/;
"ESM 四 17:30-18:30 到府".match(timePattern)[0]  // → "17:30-18:30"
```

**規則**：匹配「HH:MM-HH:MM」格式
