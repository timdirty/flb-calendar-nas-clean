# 特殊事件疊加功能測試指南

## 實作完成項目

### ✅ 階段一：疊加編輯功能

1. **現有標記偵測與預選**
   - 打開已標記的課程時，自動偵測並預選所有現有標記
   - 在模態框頂部顯示現有標記徽章（黃色背景區域）
   - 按鈕自動更新為選中狀態

2. **增量標記模式**
   - 新增「標記模式」切換開關（替換模式 ↔ 增量模式）
   - **替換模式**（預設）：用新標記替換所有現有標記
   - **增量模式**：保留現有標記並新增選擇的標記
   - 自動應用互斥規則（例如：停課 vs 體驗/代課/改時間）

### ✅ 階段二：單一標記移除功能

1. **移除選中標記**
   - 按鈕文字改為「移除選中標記」
   - 只移除當前選中的標記，保留未選中的標記
   - 如果全部移除，呼叫完全移除 API
   - 如果部分移除，更新為剩餘標記

### ✅ 階段三：日/週/月曆視覺優化

1. **淡色背景**
   - 單一標記：使用該標記的淡色背景（opacity 0.08）
   - 多標記：使用漸層背景（最多3個顏色）
   - hover 時背景加深（opacity 0.08 → 0.15）

2. **彩色左邊框**
   - 單一標記：4px 實心邊框，顏色對應標記類型
   - 多標記：使用第一個標記的顏色

3. **hover 效果**
   - 平滑過渡動畫（0.25s ease）
   - 卡片右移 3px
   - 陰影增強
   - 懸浮提示顯示所有標記

## 測試場景

### 測試場景 1：分次疊加標記

**步驟**：
1. 選擇一個普通課程（無標記）
2. 標記為「改時間」→ 確認
3. 重新打開同一課程
4. 驗證：「改時間」按鈕自動選中
5. 切換到「增量模式」
6. 選擇「公告」標記 → 輸入公告內容 → 確認
7. 驗證：標題顯示 `[改時間][公告] 原標題`
8. 驗證：課程卡片左邊框為橙色（改時間主色）
9. 驗證：卡片背景為橙色+紫色漸層

**預期結果**：
- ✅ 標記成功疊加
- ✅ 標題正確顯示多標記
- ✅ 視覺樣式正確（漸層背景 + 彩色邊框）
- ✅ hover 時顯示兩個標記徽章（🟠 改時間 · 🟣 公告）

**預期結果**：
- ✅ 標記正確替換
- ✅ 互斥規則生效（停課被體驗替換）
- ✅ 視覺樣式更新正確

## 已知限制

1. **最多顯示 3 個標記的漸層**：如果有超過 3 個標記，只有前 3 個會在漸層背景中顯示
2. **互斥規則限制**：
   - 停課不能與體驗、代課、改時間共存
   - 體驗不能與停課共存
   - 代課不能與停課共存
   - 公告可與所有標記共存
3. **代課標記特殊性**：代課會移動事件到新講師日曆，後續修改在新日曆中進行

## 故障排除

### 問題：打開已標記課程時，標記沒有自動選中
**解決方案**：
1. 確認 `detectExistingMarkers` 函數正確偵測標題和描述
2. 檢查 `adminSelectedEventTypes` 陣列是否正確填充
3. 查看控制台日誌：`檢測到現有標記: [...]`

### 問題：增量模式沒有保留現有標記
**解決方案**：
1. 確認切換開關已選中（顯示為綠色）
2. 檢查控制台日誌：`增量模式：現有標記 [...] + 新選標記 [...]`
3. 驗證 `confirmSpecialEventMark` 函數中的 `incrementalMode` 變數

### 問題：視覺樣式沒有顯示
**解決方案**：
1. 清除瀏覽器快取（Ctrl+Shift+R / Cmd+Shift+R）
2. 檢查 `getSpecialEventStyles` 函數是否正確返回樣式物件
3. 驗證 CSS 是否正確載入

### 問題：hover 效果不順暢
**解決方案**：
1. 確認 `transition: all 0.25s ease` 樣式已套用
2. 檢查 `data-hover-bg` 屬性是否正確設置
3. 驗證 onmouseover 和 onmouseout 事件是否正確綁定
