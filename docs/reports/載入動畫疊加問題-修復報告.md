# 載入動畫疊加問題 - 修復報告

**修復日期**: 2025-11-07  
**問題類型**: UI/UX 改進  
**影響範圍**: 照片和影片上傳載入指示器  
**狀態**: ✅ 已完成

---

## 📋 問題描述

### 原始問題

在影片和照片上傳過程中，出現多個載入動畫同時顯示的疊加現象：

1. **`.thumb-loading`** - 白色半透明背景 + 藍色旋轉 spinner
2. **`.file-uploading-overlay`** - 黑色半透明背景 + "待上傳" 文字

### 視覺問題

- ✗ 兩個載入指示器同時顯示
- ✗ 整個圖框看起來在旋轉
- ✗ 視覺混亂，影響使用者體驗
- ✗ 不清楚當前處於哪個階段

---

## ✅ 解決方案

### 設計原則

**分階段顯示載入指示器**，確保每個階段只顯示一個清晰的視覺反饋。

### 階段劃分

#### 階段 1: 檔案選擇後（待上傳）
- **顯示**: `file-uploading-overlay` - 黑色遮罩 + "待上傳" 文字
- **隱藏**: `thumb-loading` - 旋轉 spinner
- **目的**: 讓使用者知道檔案已選擇，等待上傳

#### 階段 2: 上傳進行中
- **顯示**: `file-uploading-overlay` - 黑色遮罩 + 進度百分比 + 進度條
- **隱藏**: `thumb-loading` - 旋轉 spinner
- **目的**: 顯示實際上傳進度

#### 階段 3: 縮圖生成中
- **顯示**: `thumb-loading` - 白色背景 + 藍色旋轉 spinner
- **隱藏**: `file-uploading-overlay` - 上傳遮罩
- **目的**: 顯示縮圖正在生成（特別是影片）

#### 階段 4: 完成
- **隱藏**: 所有載入指示器
- **顯示**: 上傳成功標記（綠色勾勾）或失敗標記（紅色叉叉）
- **目的**: 清晰的最終狀態

### 修改文件

**文件**: `public/css/learning-records.css`  
**備份**: `learning-records.css.backup-YYYYMMDD-HHMMSS-before-loading-fix`

### CSS 規則變更

#### 位置: 第 917-952 行

**修改前**:
```css
/* 新選擇的檔案立即顯示「待上傳」覆蓋層 */
.file-preview.new-upload .file-uploading-overlay { display: flex; }

.file-preview.uploading .file-uploading-overlay {
    display: flex;
}

/* 需要時顯示：新上傳、懶載入或未完成載入的縮圖 */
.file-preview.new-upload .thumb-loading,
.file-preview.lazy .thumb-loading,
.file-preview.loading .thumb-loading { display: flex; }
```

**修改後**:
```css
/* 🔥 階段 1: 待上傳 - 只顯示上傳遮罩，不顯示 spinner */
.file-preview.new-upload .file-uploading-overlay { display: flex; }
.file-preview.new-upload .file-upload-progress { display: block; }
.file-preview.new-upload .thumb-loading { display: none !important; }

/* 🔥 階段 2: 上傳中 - 只顯示上傳遮罩，不顯示 spinner */
.file-preview.uploading .file-uploading-overlay {
    display: flex;
}
.file-preview.uploading .thumb-loading { display: none !important; }

/* 🔥 階段 3: 縮圖生成 - 只顯示 spinner，不顯示上傳遮罩 */
.file-preview.lazy .thumb-loading,
.file-preview.loading .thumb-loading { display: flex; }
.file-preview.loading .file-uploading-overlay { display: none !important; }
.file-preview.loaded .thumb-loading { display: none !important; }
```

### 關鍵改進

1. **`.new-upload .thumb-loading { display: none !important; }`**
   - 待上傳階段不顯示旋轉 spinner
   
2. **`.uploading .thumb-loading { display: none !important; }`**
   - 上傳中階段不顯示旋轉 spinner
   
3. **`.loading .file-uploading-overlay { display: none !important; }`**
   - 縮圖生成階段不顯示上傳遮罩

4. **移除 `.new-upload .thumb-loading { display: flex; }`**
   - 避免待上傳階段同時顯示兩個指示器
