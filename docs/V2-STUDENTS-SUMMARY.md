## 🔍 技術細節

### API 請求格式
```http
GET /api/v2/students/courses/:courseId/students?courseTitle=ESM%20日%209:30-10:30
```

### API 返回格式
```json
{
  "success": true,
  "data": [
    {
      "id": "student-1",
      "name": "學生姓名",
      "courseId": "ESM 日 9:30-10:30",
      "attendance": "present",           // 出缺席狀態
      "attendanceLocked": false,         // 是否被鎖定
      "comment": "",
      "uploadStatus": { ... },
      "metadata": {
        "course": "ESM",
        "period": "ESM 日 9:30-10:30",
        "remaining": 10
      }
    }
  ],
  "message": "找到 6 位學生",
  "metadata": {
    "courseTitle": "ESM 日 9:30-10:30",
    "totalStudents": 96,
    "matchedStudents": 6,
    "hasEventMatch": true
  }
}
```

### 篩選流程圖
```
原始學生列表 (96 位)
    ↓
[步驟 1] 資料完整性檢查 (course + period)
    → 90 位學生
    ↓
[步驟 2] 讀取篩選配置 (minRemainingClasses: 1)
    ↓
[步驟 3] 檢查課程是否停課
    → 若停課則返回 []
    ↓
[步驟 4] 剩餘堂數篩選 + 智能持續顯示
    → 85 位學生
    ↓
[步驟 5] 課程匹配 (時間+星期+地點)
    → 6 位學生
    ↓
[步驟 6] 補充出缺席狀態 (2 位被鎖定)
    ↓
最終返回 6 位學生
```

## 🎓 關鍵學習

### 1. 配置統一管理
- 從 `data/student-filter-config.json` 讀取配置
- 與 `admin-dashboard.html` 共用相同配置
- 確保前後端行為一致

### 2. 智能持續顯示邏輯
```javascript
// 即使堂數不足，一週內有簽到記錄仍顯示
if (!hasRemainingClasses && showInCurrentWeek) {
  const daysDiff = calculateDaysSinceLastAttendance(student);
  if (daysDiff <= 7) {
    hasRemainingClasses = true; // ✅ 繼續顯示
  }
}
```

### 3. 出缺席狀態處理
- 支援多種格式：`boolean`、`string`
- 統一轉換為標準狀態：`present`、`leave`、`absent`、`unknown`
- 請假/缺席時自動鎖定上傳

### 4. 停課關鍵字匹配
- 使用大小寫不敏感匹配
- 支援中文關鍵字：停課、取消、暫停、休息、放假、請假
- 停課時直接返回空陣列（不進行後續處理）

## 💡 最佳實踐

### 1. 多層篩選策略
- **先快後慢**：先執行快速篩選（資料完整性、停課檢查）
- **分層處理**：將複雜邏輯分解為多個獨立步驟
- **提前返回**：停課等情況直接返回，避免不必要的計算
