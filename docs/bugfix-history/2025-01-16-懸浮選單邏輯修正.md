# 手機端懸浮選單邏輯修正

**版本**: 2025-01-16-FLOATING-MENU-FIX  
**日期**: 2025年1月16日  
**類型**: Bug 修正  
**影響範圍**: 手機端（≤ 768px）懸浮視圖切換選單

---

## 📋 問題描述

**原始問題**：
> 手機端懸浮選單的顯示邏輯不正確，需要滾動到第一張課程卡片碰到上方邊界才會出現，而不是在視圖按鈕（今日/本週/本月/全部）離開視窗時就出現。

**用戶需求**：
> 當主要篩選區塊的視圖按鈕（今日/本週/本月/全部）消失於螢幕時，懸浮選單就應該自動出現。

---

## 🎯 解決方案

### 修正前的邏輯

```javascript
// ❌ 舊邏輯：基於統計區域（statsText）的位置
const statsRect = statsText.getBoundingClientRect();
const shouldShow = statsRect.bottom < 0;
```

**問題**：
- 統計區域在頁面較下方
- 需要滾動很多才會觸發
- 與視圖按鈕位置不同步

### 修正後的邏輯

```javascript
// ✅ 新邏輯：基於視圖按鈕（.view-buttons）的位置
const viewButtonsRect = viewButtons.getBoundingClientRect();
const shouldShow = viewButtonsRect.bottom < 0;
```

**改進**：
- 直接偵測視圖按鈕位置
- 按鈕消失時立即顯示懸浮選單
- 邏輯簡單明確

### 修改的檔案

#### 1. `public/js/main.js`

**位置**: 行 19719-19839（`initializeFloatingMenu` 函數）

**核心修改**：

##### 1.1 更新元素選擇器
```javascript
// 修改前
const statsText = document.getElementById('statsText');

// 修改後
const viewButtons = document.querySelector('.view-buttons');

```

##### 1.2 簡化判斷邏輯
```javascript
// 🔥 新邏輯：當主要篩選區塊的視圖按鈕消失時顯示懸浮選單
let shouldShow = false;

// 檢查視圖按鈕是否離開視窗頂部
if (viewButtons) {
    const viewButtonsRect = viewButtons.getBoundingClientRect();
    // 🎯 核心邏輯：當視圖按鈕完全離開視窗頂部時，顯示懸浮選單
    shouldShow = viewButtonsRect.bottom < 0;
}
```

##### 1.3 添加調試日誌
```javascript
// 🔍 調試日誌：僅在狀態變化時輸出
if ((shouldShow && !isFloatingVisible) || (!shouldShow && isFloatingVisible)) {
    console.log('📍 懸浮選單狀態變化:', {
        視圖按鈕位置: `top: ${Math.round(viewButtonsRect.top)}, bottom: ${Math.round(viewButtonsRect.bottom)}`,
        應顯示: shouldShow,
        當前顯示: isFloatingVisible
    });
}
```

##### 1.4 添加初始化檢查
```javascript
// 🔥 初始化時檢查一次（確保頁面載入後立即檢查狀態）
console.log('🎬 初始化懸浮選單，檢查元素:', {
    懸浮選單: !!floatingMenu,
    視圖按鈕: !!viewButtons,
    視窗寬度: window.innerWidth
});

// 延遲 500ms 後檢查，確保 DOM 完全渲染
setTimeout(() => {
    handleScroll();
    console.log('✅ 懸浮選單初始化完成');
}, 500);
```

##### 1.5 保持手機端專用
```javascript
// 🔥 手機端專用邏輯（≤ 768px）
const isMobile = window.innerWidth <= 768;

if (!isMobile) {
    // 電腦端：不顯示懸浮選單
    if (isFloatingVisible) {
        hideFloatingMenu();
        isFloatingVisible = false;
    }
    return;
}
```

### 常見問題排查

#### 問題 1：懸浮選單沒有出現

**檢查項目**：
1. 打開 Console 查看是否有初始化日誌
2. 確認 `視圖按鈕: true`（如果是 false，表示元素未找到）
3. 確認視窗寬度 ≤ 768px
4. 清除瀏覽器快取後重新載入

**解決方法**：
```javascript
// 在 Console 執行以下命令檢查元素
document.querySelector('.view-buttons')  // 應該返回 DOM 元素
document.getElementById('floatingStatsMenu')  // 應該返回 DOM 元素
window.innerWidth  // 應該 ≤ 768
```

#### 問題 2：懸浮選單出現太早或太晚

**檢查項目**：
1. 查看 Console 日誌中的「視圖按鈕位置」
2. 確認 `bottom` 值是否正確

**調整閾值**：
```javascript
// 如果需要調整觸發時機，修改判斷邏輯
// 當前：viewButtonsRect.bottom < 0
// 提早觸發：viewButtonsRect.bottom < 50
// 延後觸發：viewButtonsRect.bottom < -50
```

#### 問題 3：電腦端也顯示了懸浮選單

**檢查項目**：
1. 確認視窗寬度是否真的 > 768px
2. 查看 Console 是否有「電腦端：不顯示懸浮選單」日誌
