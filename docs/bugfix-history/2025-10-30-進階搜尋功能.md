# 2025-10-30 進階搜尋功能實作

## 📝 更新概述

實作 **Google/Spotlight 風格的進階搜尋功能**，大幅提升課程搜尋的靈活性和精確度。

---

## 🎯 新增功能

### 1. 進階搜尋解析器
- **檔案**: `public/js/modules/advanced-search-parser.js`
- **功能**: 解析和執行複雜搜尋語法
- **支援語法**:
  - 多關鍵字（AND 邏輯）：`spm 到府`
  - OR 邏輯：`spm OR scratch`
  - 精確匹配：`"Python 基礎"`
  - 排除關鍵字：`程式 -scratch`
  - 必須包含：`+spm 到府`
  - 複雜組合：`+spm 到府 OR 線上 -取消`

### 2. 搜尋幫助系統
- 搜尋框旁新增 **?** 圖標按鈕
- 點擊顯示完整語法說明
- 提供可點擊的範例代碼
- 精美的漸層色彩界面設計

### 3. 優化搜尋建議列表
- 降低下拉列表高度（180px）
- 添加自訂滾動條樣式
- 不再遮擋下方控制欄位
- 更好的滾動體驗

## 💡 使用範例

### 基本搜尋
```
spm
```
→ 找出所有包含 "spm" 的課程

### 多關鍵字（AND）
```
spm 到府
```
→ 同時包含 "spm" **和** "到府" 的課程

### OR 搜尋
```
spm OR scratch
```
→ 包含 "spm" **或** "scratch" 的課程

### 複雜組合
```
+spm 到府 OR 線上 -取消
```
→ 必須有 "spm"，地點是 "到府" 或 "線上"，排除 "取消" 的課程

## 🔍 技術細節

### 搜尋流程
```
1. 使用者輸入搜尋查詢
   ↓
2. AdvancedSearchParser 解析查詢
   ↓
3. 產生搜尋條件物件（terms, orGroups, excludedTerms, etc.）
   ↓
4. 遍歷所有事件，使用 matchEvent() 判斷是否匹配
   ↓
5. 返回匹配的事件列表
   ↓
6. 渲染搜尋結果
```

### 容錯機制
- 如果進階搜尋解析失敗，自動回退到基本搜尋
- 確保系統永遠可用，不會因語法錯誤而崩潰

### 效能優化
- 搜尋時合併事件的所有文字欄位（避免重複匹配）
- 使用 `.includes()` 進行快速字串匹配
- 防抖機制（300ms）避免過度搜尋
