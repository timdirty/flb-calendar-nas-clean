# 2025-10-30 GPU 過載優化

## 🎯 問題描述

系統出現持續性 GPU 過載問題，導致：
- 瀏覽器卡頓
- 風扇高速運轉
- 耗電量增加
- 使用體驗下降

## 🔍 根本原因分析

經過系統性診斷，發現以下主要問題：

### 1. **無限循環 CSS 動畫**（最嚴重）

系統中有 **2 個無限循環動畫**持續運行：

```css
/* ❌ 問題1：搜尋結果圖標的彈跳動畫 */
.event-card.search-result-current::before {
    animation: bounce 1s ease-in-out infinite;
}

/* ❌ 問題2：載入狀態的旋轉動畫 */
.calendar-loading-state i {
    animation: spin 1s linear infinite;
}
```

**影響**：這些動畫每秒執行多次，持續佔用 GPU 資源。

### 2. **過度使用 transition: all**

大量元素使用 `transition: all`，導致所有 CSS 屬性變化都觸發過渡：

```css
/* ❌ 問題：過度過渡 */
transition: all 0.2s ease;
```

**影響**：即使只改變背景色，也會計算所有屬性的過渡。

### 3. **缺少 CSS contain 和 content-visibility**

元素沒有使用現代 CSS 性能優化屬性：

```css
/* ❌ 缺少優化 */
.search-suggestions { /* 沒有 contain */ }
.search-help-tooltip { /* 沒有 content-visibility */ }
```

**影響**：瀏覽器無法優化渲染範圍。

### 4. **inline style 中的 transition**

在 HTML 中直接寫入過渡效果：

```html
<!-- ❌ 問題 -->
<div style="transition: all 0.2s ease;">
```

**影響**：無法被瀏覽器有效優化。

## ✅ 解決方案

### 1. 停用所有無限循環動畫

```css
/* ✅ 修復1：停用彈跳動畫 */
.event-card.search-result-current::before {
    /* 🔥 GPU 優化：停用無限循環彈跳動畫 */
    /* animation: bounce 1s ease-in-out infinite; */
}

/* ✅ 修復2：停用旋轉動畫 */
.calendar-loading-state i {
    /* 🔥 GPU 優化：停用無限循環旋轉動畫 */
    /* animation: spin 1s linear infinite; */
}
```

### 2. 優化搜尋相關動畫

```css
/* ✅ 移除動畫，改為簡單的 opacity 過渡 */
.search-suggestions {
    /* animation: fadeInUp 0.2s ease; */
    opacity: 0;
    transition: opacity 0.15s ease;
}

.search-suggestions[style*="display: block"] {
    opacity: 1;
}
```

### 3. 添加 CSS contain 和 content-visibility

```css
/* ✅ 優化1：使用 contain */
.search-suggestions {
    contain: layout style paint;
}

.search-suggestion-item {
    contain: layout style paint;
}

/* ✅ 優化2：使用 content-visibility */
.search-help-tooltip {
    content-visibility: auto;
}
```

### 4. 優化過渡效果

```css
/* ✅ 只過渡必要的屬性 */
.search-suggestion-item {
    transition: background-color 0.15s ease; /* 而不是 all */
}

.event-card {
    transition: box-shadow 0.2s ease, opacity 0.2s ease; /* 而不是 all */
}
```

### 5. 移除 inline 過渡

```javascript
// ❌ 之前
style="transition: all 0.2s ease;"

// ✅ 修復後
style="background: ${color};" /* 移除 transition，在 CSS 中定義 */
```

### 6. 全域動畫限制

```css
/* ✅ 禁用所有無限循環動畫 */
@media (prefers-reduced-motion: no-preference) {
    * {
        animation-iteration-count: 1 !important;
    }
}
```

### 7. GPU 加速優化

```css
/* ✅ 優化滾動容器 */
.search-suggestions,
.search-help-tooltip,
.search-help-content {
    transform: translateZ(0);
    backface-visibility: hidden;
    -webkit-font-smoothing: antialiased;
}
```

## 🎓 學習要點

### 1. 無限循環動畫的危害

```css
/* ❌ 永遠不要這樣做 */
animation: bounce 1s infinite;
```

**原因**：即使元素不可見，動畫仍在運行，持續佔用 GPU。

**解決方案**：
- 只在需要時觸發動畫
- 使用 `animation-iteration-count: 1`
- 動畫結束後移除 class

### 2. transition: all 的問題

```css
/* ❌ 效能差 */
transition: all 0.2s ease;

/* ✅ 效能好 */
transition: background-color 0.15s ease;
```

**原因**：`all` 會計算所有屬性，包括不需要過渡的。

### 3. CSS contain 的重要性

```css
/* ✅ 告訴瀏覽器這個元素是獨立的 */
contain: layout style paint;
```

**好處**：
- 瀏覽器可以跳過不可見元素的計算
- 減少重排範圍
- 提升整體性能

### 4. content-visibility 的魔力

```css
/* ✅ 自動管理渲染 */
content-visibility: auto;
```

**好處**：
- 不可見內容不會渲染
- 大幅提升長列表性能
- 幾乎無副作用
