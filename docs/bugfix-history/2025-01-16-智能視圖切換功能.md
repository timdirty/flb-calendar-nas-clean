# 智能視圖切換功能 - 完整說明

**版本**: 2025-01-16-SMART-VIEW-SWITCH  
**日期**: 2025年1月16日  
**類型**: 新功能  
**影響範圍**: 電腦端日曆互動體驗

---

## 📋 功能概述

當用戶在電腦端點擊日曆（週視圖或月視圖）中的課程方塊時，如果該課程不在當前視圖範圍內，系統會自動切換到最小適合的視圖，並滾動到該課程進行高亮顯示。

---

## 🎯 使用場景

### 場景 1：點擊下週的課程
**操作**：用戶在「今日」視圖，點擊日曆中下週的課程  
**結果**：系統自動切換到「本週」視圖，並定位到該課程

### 場景 2：點擊下個月的課程
**操作**：用戶在「本週」視圖，點擊日曆中下個月的課程  
**結果**：系統自動切換到該月份的「月」視圖，並定位到該課程

### 場景 3：點擊過去的課程
**操作**：用戶在「今日」視圖，點擊日曆中上個月的課程  
**結果**：系統自動切換到該月份的「月」視圖，並定位到該課程

### 場景 4：點擊很遠的課程
**操作**：用戶點擊日曆中 3 個月以外的課程  
**結果**：系統自動切換到「全部」視圖，並定位到該課程

## 🔧 技術實現

### 核心函數

#### 1. `highlightEventCardFromCalendar(eventId)`
**位置**: `public/js/main.js` 行 1583  
**功能**: 處理日曆課程點擊事件

**修改內容**:
```javascript
// 🔥 如果找不到卡片，智能切換視圖
if (!targetCard) {
    console.warn('⚠️ 當前視圖找不到對應的課程卡片:', eventId);
    console.log('💡 提示：該課程可能不在當前視圖範圍內，嘗試智能切換視圖...');
    
    // 🔥 電腦端：嘗試智能切換視圖（手機端不自動切換，保持現有行為）
    const isDesktop = window.innerWidth > 768;
    if (isDesktop) {
        const switchResult = autoSwitchViewForEvent(eventId);
        if (switchResult) {
            // 視圖切換成功，函數會在切換完成後自動調用高亮
            return;
        }
    }
    
    // 如果無法切換視圖（手機端或找不到課程），顯示提示訊息
    showToast('💡 該課程不在當前視圖範圍內，請切換日期範圍查看', 'info');
    ...
}
```

#### 2. `autoSwitchViewForEvent(eventId)`
**位置**: `public/js/main.js` 行 1641  
**功能**: 智能判斷並切換到最小適合視圖

**邏輯流程**:
1. 從 `allEvents` 中找到目標課程
2. 解析課程日期
3. 判斷課程屬於哪個視圖範圍
4. 執行視圖切換
5. 等待渲染完成後高亮並滾動到課程

**視圖選擇邏輯**:
```javascript
// 檢查是否為今日
if (eventDay.getTime() === today.getTime()) {
    targetView = 'today';
}
// 檢查是否在本週範圍內
else if (eventDay >= currentWeekStart && eventDay <= currentWeekEnd) {
    targetView = 'week';
}
// 檢查是否在本月範圍內
else if (eventDate.getFullYear() === now.getFullYear() && 
         eventDate.getMonth() === now.getMonth()) {
    targetView = 'month';
}
// 檢查是否在 3 個月內
else if (daysDiff <= 90) {
    targetView = 'month';
    needUpdateViewDate = true;  // 更新到課程所在月份
}
// 超過 3 個月
else {
    targetView = 'all';
    needUpdateViewDate = true;
}
```

## 🎨 用戶體驗優化

### 1. 智能提示訊息
系統會根據目標視圖顯示不同的提示訊息：

- **今日視圖**: `🔄 正在切換到「今日」視圖...`
- **本週視圖**: `🔄 正在切換到「本週」視圖...`
- **本月視圖**: `🔄 正在切換到「2025年2月」視圖...`
- **全部視圖**: `🔄 正在切換到「全部」視圖...`

### 2. 成功確認訊息
視圖切換並定位完成後顯示：

- **跨月切換**: `✅ 已切換到「2025年2月」並定位課程`
- **同月切換**: `✅ 已切換到「本月」視圖並定位課程`

### 3. 錯誤處理
- 如果找不到課程：`❌ 無法定位到該課程`
- 手機端點擊：`💡 該課程不在當前視圖範圍內，請切換日期範圍查看`

## 🔧 配置參數

### 時間閾值
```javascript
const daysDiff = Math.abs((eventDay.getTime() - today.getTime()) / (1000 * 60 * 60 * 24));

if (daysDiff <= 90) {
    // 3個月內 → 使用月視圖
} else {
    // 超過3個月 → 使用全部視圖
}
```

**可調整參數**:
- `90` 天：月視圖的最大範圍
- 可根據實際需求調整（例如：60天、120天）

### 視圖切換延遲
```javascript
setTimeout(() => {
    // 執行高亮和滾動
}, 1500); // 1.5 秒
```

**可調整參數**:
- `1500` 毫秒：視圖切換後的等待時間
- 確保 DOM 完全渲染後再執行高亮

## 🐛 已知問題與解決方案

### 問題 1：視圖切換後找不到課程
**原因**: 視圖渲染尚未完成  
**解決**: 延遲 1.5 秒後再執行高亮  
**狀態**: ✅ 已解決

### 問題 2：跨月切換時日期錯誤
**原因**: `specialEventsState.currentViewDate` 未更新  
**解決**: 在切換前更新 `currentViewDate` 到課程日期  
**狀態**: ✅ 已解決

### 問題 3：手機端自動切換造成體驗中斷
**原因**: 手機端視圖切換會打斷用戶操作  
**解決**: 手機端不啟用自動切換，保持原有提示訊息  
**狀態**: ✅ 已解決
