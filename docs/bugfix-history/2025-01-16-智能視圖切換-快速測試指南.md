# 智能視圖切換 - 快速測試指南 🚀

**版本**: 2025-01-16-SMART-VIEW-SWITCH  
**測試時間**: 5 分鐘  
**測試設備**: 電腦端（推薦 Chrome 瀏覽器）

---

## 🎯 快速測試步驟

### 測試 1：點擊下週課程（最基本）⭐
**預計時間**: 30秒

1. 打開網站：https://course-viewer.funlearnbar.synology.me
2. 確保目前在「今日」視圖
3. 在週日曆（頂部日曆）中找到下週的任一課程
4. 點擊該課程方塊

**✅ 成功標準**：
- 系統顯示「🔄 正在切換到「本週」視圖...」
- 視圖自動切換到「本週」
- 頁面自動滾動到該課程
- 課程卡片高亮顯示（金色邊框）
- 顯示「✅ 已切換到「本週」視圖並定位課程」

---

### 測試 2：點擊下個月課程（跨月切換）⭐⭐
**預計時間**: 1分鐘

1. 確保目前在「本週」視圖
2. 點擊日曆導航的「下一期」按鈕幾次，直到看到下個月的課程
3. 點擊下個月的任一課程方塊

**✅ 成功標準**：
- 系統顯示「🔄 正在切換到「2025年X月」視圖...」
- 視圖自動切換到該月份的月視圖
- 頁面自動滾動到該課程
- 課程卡片高亮顯示
- 顯示「✅ 已切換到「2025年X月」並定位課程」

---

### 測試 3：點擊今日課程（不應切換）⭐
**預計時間**: 30秒

1. 切換到「本週」或「本月」視圖
2. 在日曆中點擊今日的任一課程

**✅ 成功標準**：
- 視圖不切換（保持在「本週」或「本月」）
- 頁面直接滾動到該課程
- 課程卡片高亮顯示
- 無視圖切換的提示訊息

---

### 測試 4：點擊上個月課程（回到過去）⭐⭐
**預計時間**: 1分鐘

1. 確保目前在「今日」視圖
2. 點擊月日曆導航的「上一期」按鈕，回到上個月
3. 點擊上個月的任一課程方塊

**✅ 成功標準**：
- 系統顯示「🔄 正在切換到「2024年12月」視圖...」（或對應月份）
- 視圖自動切換到該月份
- 頁面自動滾動到該課程
- 課程卡片高亮顯示

---

### 測試 5：手機端測試（應該不切換）⭐
**預計時間**: 1分鐘

1. 用手機打開網站（或調整瀏覽器視窗寬度 < 768px）
2. 切換到「今日」視圖
3. 在日曆中點擊下週的課程

**✅ 成功標準**：
- 視圖不自動切換
- 顯示提示訊息：「💡 該課程不在當前視圖範圍內，請切換日期範圍查看」
- 用戶需要手動切換視圖

## 🐛 常見問題排查

### 問題：點擊課程後沒有反應
**檢查**：
1. 打開瀏覽器控制台（F12）
2. 查看是否有 JavaScript 錯誤
3. 確認網路連線正常
4. 重新整理頁面後再試

### 問題：視圖切換了但找不到課程
**檢查**：
1. 確認該課程確實存在於系統中
2. 檢查講師篩選是否開啟（切換到「全部講師」）
3. 查看控制台日誌：`🎯 視圖切換完成，嘗試高亮課程`

### 問題：視圖切換太慢
**原因**：
- 系統等待 1.5 秒確保 DOM 完全渲染
- 這是正常行為，避免高亮失敗

### 問題：手機端也自動切換了
**檢查**：
- 確認視窗寬度是否 ≤ 768px
- 檢查瀏覽器的 User Agent
- 查看控制台是否顯示「🔥 電腦端：嘗試智能切換視圖」
