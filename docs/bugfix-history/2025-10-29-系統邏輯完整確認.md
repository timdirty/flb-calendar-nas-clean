### 3. **學生提醒匹配邏輯**

#### 🔍 提醒功能如何取得 userId？

**Step 1**: 系統從 `/api/students` 取得所有學生列表
```javascript
const allStudents = [...regularStudents, ...tempStudents];
```

**Step 2**: 根據學生姓名匹配
```javascript
const student = allStudents.find(s => s.name === targetStudentName);
const userId = student?.userId;
```

**Step 3**: 使用 userId 發送 LINE 提醒
```javascript
if (userId) {
    await sendLineMessage(userId, reminderMessage);
}
```
