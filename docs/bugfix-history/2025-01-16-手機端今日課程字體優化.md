# 手機端今日課程字體優化

**版本**: 2025-01-16-MOBILE-FONT-FIX  
**日期**: 2025年1月16日  
**類型**: 樣式優化  
**影響範圍**: 手機端（≤ 768px）今日課程區塊

---

## 📋 問題描述

**原始問題**：
> 手機端今日課程的字體大小使課程標題可能換行顯示，影響視覺整潔度

**用戶需求**：
> 縮小手機端今日課程的字體大小，使課程標題一定能在一行內呈現

---

## 🎯 解決方案

### 1. 縮小字體大小 ✅

**課程標題**：
- 修改前：`font-size: 1rem` (16px)
- 修改後：`font-size: 0.85rem` (13.6px)
- 減少：15%

**時間標籤**：
- 修改前：`font-size: 0.85rem` (13.6px)
- 修改後：`font-size: 0.75rem` (12px)
- 減少：~12%

**講師資訊**：
- 修改前：`font-size: 0.85rem` (13.6px)
- 修改後：`font-size: 0.75rem` (12px)
- 減少：~12%

### 2. 強制單行顯示 ✅

添加 CSS 樣式確保標題在一行內：
```css
.today-event-title {
    white-space: nowrap;      /* 不換行 */
    overflow: hidden;         /* 隱藏溢出內容 */
    text-overflow: ellipsis;  /* 顯示省略號 */
    max-width: 100%;          /* 最大寬度限制 */
}
```

### 3. 優化卡片間距 ✅

減少內邊距以節省空間：
```css
.today-event-card {
    padding: 12px 14px;  /* 原本：14px 18px */
    gap: 10px;           /* 原本：12px */
}
```

## 🎨 CSS 技術說明

### 單行文字溢出處理

```css
.today-event-title {
    white-space: nowrap;      /* Step 1: 禁止換行 */
    overflow: hidden;         /* Step 2: 隱藏溢出內容 */
    text-overflow: ellipsis;  /* Step 3: 顯示省略號 */
    max-width: 100%;          /* Step 4: 限制最大寬度 */
}
```

**運作原理**：
1. `white-space: nowrap` 強制文字在一行內顯示
2. `overflow: hidden` 隱藏超出容器的內容
3. `text-overflow: ellipsis` 在被截斷處顯示 "..."
4. `max-width: 100%` 確保不超出父容器

## 🐛 已知問題與限制

### 限制 1：標題被截斷
**問題**: 過長標題只顯示部分內容  
**影響**: 用戶可能看不到完整標題  
**解決方案**: 
- 點擊課程卡片查看完整資訊
- 未來考慮添加 tooltip 顯示完整標題

### 限制 2：極窄螢幕
**問題**: 在極窄螢幕（< 320px）可能顯示異常  
**影響**: 極少數舊設備  
**解決方案**: 考慮添加 @media (max-width: 320px) 樣式
