# 🚀 星期導航優化 - 換行布局與定位改進

**日期**: 2025-01-16  
**問題**: 星期快速導航按鈕在同一行排列，導致超出螢幕範圍  
**目標**: 將星期按鈕換行到第二排，並改進定位功能

---

## 📋 問題分析

### 1️⃣ 原始問題
- 懸浮選單中的星期導航（日一二三四五六）與篩選按鈕在同一行
- 在小螢幕設備上會超出可視範圍
- 需要橫向滾動才能看到所有星期按鈕

### 2️⃣ 用戶需求
- 將星期按鈕排列到第二排
- 確保點擊後能正確定位到該星期的課程
- 避免被懸浮選單遮擋

## 🐛 潛在問題與解決方案

### 問題 1: 點擊後沒有滾動
**可能原因**: 課程卡片沒有 `data-event-start` 屬性  
**解決方案**: 檢查事件卡片渲染時是否正確設置屬性

### 問題 2: 滾動位置不準確
**可能原因**: 懸浮選單高度計算錯誤  
**解決方案**: 添加額外的偏移量（目前為 20px）

### 問題 3: 星期按鈕顏色不更新
**可能原因**: `updateFloatingWeekdayNav()` 沒有被調用  
**解決方案**: 確認在視圖切換和事件渲染後調用此函數

## 📊 技術細節

### 1️⃣ Flexbox 布局
- 使用 `flex-wrap: wrap` 允許換行
- 使用 `width: 100%` 強制星期導航佔滿一整行

### 2️⃣ 滾動定位
- 使用 `getBoundingClientRect()` 獲取元素位置
- 使用 `window.pageYOffset` 獲取當前滾動位置
- 使用 `window.scrollTo()` 平滑滾動

### 3️⃣ DOM 查詢優化
- 使用 `:not([style*="display: none"])` 選擇器
- 只查詢可見的課程卡片
- 避免定位到隱藏元素
