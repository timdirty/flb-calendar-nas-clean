## ⚠️ 失敗案例分析

### 案例 1-3：不完整時間範圍
```
輸入: [代課][改時間] SPM 三 16:30
期望: SPM
實際: SPM1630

輸入: [代課] MINECRAFT 二 11:00
期望: MINECRAFT
實際: MINECRAFT1100
```

**分析**:
- 問題：課程標題缺少結束時間（應為 `16:30-17:30` 或 `11:00-12:00`）
- 真實場景：從 Synology Calendar 獲取的課程標題**一定包含完整時間範圍**
- 影響：**極低**（真實世界不會發生）
- 建議：視為測試案例過於極端，**無需修復**

### 案例 4：校區資訊
```
輸入: [改時間] SPM 三 16:30-17:30 第12週 松山校區
期望: SPM
實際: SPM松山校區
```

**分析**:
- 問題：保留了校區資訊
- 真實場景：校區資訊可能是**有用的區別標識**
  - 例如：同一講師在松山校區和信義校區的 SPM 課程
  - 保留校區可避免路徑衝突
- 影響：**可能是功能而非bug**
- 建議：**保持現狀**，除非業務需求明確要求移除

### 修改 1：`utils/course-topic-helper.js`
**修復內容**:
- 使用 `while` 循環移除所有連續的中括號標記
- 精確匹配講師名（只移除結尾不含數字的 `- XXX` 格式）
- 避免誤傷時間範圍（如 `11:00-12:00`）

```javascript
function stripSpecialMarkers(title) {
  // 🔥 移除所有連續的中括號標記
  while (/^\s*\[[^\]]*\]\s*/.test(output)) {
    output = output.replace(/^\s*\[[^\]]*\]\s*/, '');
  }
  
  // ⚠️ 精確移除講師名，避免誤傷時間
  output = output.replace(/\s*[-－]\s*([^\d-－]+)$/, '');
  
  return output.trim();
}
```
