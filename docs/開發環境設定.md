# 🛠️ 開發環境設定指南

## 問題說明

在本地開發時，以下檔案會被自動更新，導致 Synology Drive 頻繁同步：
- `data/reminders.json` - 課程提醒資料
- `data/holidays-cache.json` - 假期快取資料

## ✅ 解決方案

### 方法 1：使用新的開發命令（推薦）

現在 `npm run dev` 已經**自動禁用**自動排程任務：

```bash
npm run dev
```

您會看到：
```
⚠️  提醒排程器已禁用（開發模式）
   如需啟用，請移除環境變數 DISABLE_AUTO_REMINDERS
```

### 方法 2：需要完整功能測試時

如果需要測試提醒排程功能：

```bash
npm run dev:full
```

這會啟用所有自動排程任務。

## 🔍 技術細節

### 修改內容

1. **package.json**
   ```json
   {
     "scripts": {
       "dev": "DISABLE_AUTO_REMINDERS=true nodemon server.js",
       "dev:full": "nodemon server.js"
     }
   }
   ```

2. **server.js**
   ```javascript
   if (process.env.DISABLE_AUTO_REMINDERS !== 'true') {
     reminderScheduler.start();
   } else {
     console.log('⚠️  提醒排程器已禁用（開發模式）');
   }
   ```

3. **nodemon.json**
   ```json
   {
     "ignore": [
       "data/**/*",  // 已忽略 data 目錄
       "logs/**/*"
     ]
   }
   ```

## 📋 開發流程

### 一般開發（不需要排程功能）
```bash
npm run dev
```
- ✅ 提醒排程器禁用
- ✅ `data/` 檔案不會自動更新
- ✅ Synology Drive 不會頻繁同步

### 測試排程功能
```bash
npm run dev:full
```
- ⚠️ 提醒排程器啟用
- ⚠️ `data/` 檔案會自動更新
- ⚠️ Synology Drive 會頻繁同步

## 🚀 生產環境

生產環境使用 `npm start`，**不受影響**，所有排程任務正常運行：

```bash
npm start
```

## 💡 其他注意事項

### 如果還是有同步問題

1. **檢查是否有其他進程**
   ```bash
   lsof -ti:3002 | xargs kill -9
   ```

2. **清理 nodemon 快取**
   ```bash
   rm -rf node_modules/.cache
   ```

3. **重新啟動**
   ```bash
   npm run dev
   ```

### 手動測試排程功能

即使在開發模式下，您仍可透過 API 手動觸發：

```bash
# 手動啟動排程器
curl -X POST http://localhost:3002/api/reminder-scheduler/start

# 手動停止排程器
curl -X POST http://localhost:3002/api/reminder-scheduler/stop

# 手動執行一次提醒檢查
curl -X POST http://localhost:3002/api/reminder-scheduler/trigger
```

## 📝 總結

| 命令 | 排程任務 | 檔案更新 | 適用場景 |
|------|---------|---------|---------|
| `npm run dev` | ❌ 禁用 | ❌ 不更新 | 一般開發（推薦） |
| `npm run dev:full` | ✅ 啟用 | ✅ 自動更新 | 測試排程功能 |
| `npm start` | ✅ 啟用 | ✅ 自動更新 | 生產環境 |
