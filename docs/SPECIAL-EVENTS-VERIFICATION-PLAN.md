# 📋 特殊事件標記系統 - 完整驗證規劃

## 🎯 系統概述

特殊事件標記系統允許管理員對課程事件添加、移除和組合多種特殊標記，並確保原始課程資訊（標題、描述）不會被清空。

### 支援的標記類型
1. **停課** 🔴 - 與其他標記互斥（體驗、代課、改時間）
2. **體驗** 🟢 - 與停課互斥
3. **代課** 🔵 - 與停課互斥，需要選擇代課講師
4. **改時間** 🟠 - 與停課互斥，需要設定新時間
5. **公告** 🟣 - 不影響標題，只更新描述

### 四、取消標記測試

#### 測試案例 4.1：取消單一標記（部分移除）
- **前提**：課程有「體驗」和「公告」兩個標記
- **操作**：
  1. 開啟課程標記面板
  2. 勾選「公告」（要移除的標記）
  3. 點擊「移除標記」按鈕
  4. 確認移除
- **預期結果**：
  - ✅ 標題保持 `[體驗] 原始課程名稱`
  - ✅ 描述中移除 `[公告]` 區塊
  - ✅ `[體驗]` 標記保留
  - ✅ Toast 提示「已移除：公告 / 保留：體驗」

#### 測試案例 4.2：取消所有標記
- **前提**：課程有「體驗」和「公告」兩個標記
- **操作**：
  1. 開啟課程標記面板
  2. 勾選「體驗」和「公告」（全選）
  3. 點擊「移除標記」按鈕
  4. 確認移除
- **預期結果**：
  - ✅ 標題恢復為原始名稱（無 [標記] 前綴）
  - ✅ 描述中移除所有特殊事件標記區塊
  - ✅ 原始描述內容保留
  - ✅ 調用 `/api/events/remove-special` API

#### 測試案例 4.3：移除代課標記（保留其他）
- **前提**：課程有「代課」和「公告」標記
- **操作**：
  1. 勾選「代課」
  2. 點擊「移除標記」
  3. 確認
- **預期結果**：
  - ✅ 標題移除 `[代課]`
  - ✅ 描述移除 `[代課講師]`
  - ✅ 保留 `[公告]` 標記
  - ⚠️ **注意**：事件不會移回原日曆（保持在代課講師日曆）

#### 測試案例 4.4：逐一移除多標記
- **前提**：課程有「體驗」、「公告」、「改時間」三個標記
- **操作**：
  1. 第一次：勾選「改時間」→ 移除
  2. 確認後，第二次：勾選「公告」→ 移除
  3. 確認後，第三次：勾選「體驗」→ 移除
- **預期結果**：
  - ✅ 第一次移除後：標題 `[體驗] 原始名稱`，描述保留公告
  - ✅ 第二次移除後：標題 `[體驗] 原始名稱`，描述無公告
  - ✅ 第三次移除後：標題恢復原始，所有標記清空
  - ✅ 每次都保留原始標題和描述內容

## 🐛 已知問題與限制

### 1. 代課移動日曆後無法自動移回
- **問題**：移除「代課」標記後，事件仍在代課講師日曆
- **原因**：Synology Calendar API 移動策略是「創建+刪除」
- **影響**：中等
- **建議**：在移除代課標記時，提示管理員手動移回

### 2. 快取更新延遲
- **問題**：標記後需等待 1 秒快取更新
