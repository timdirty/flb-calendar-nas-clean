## 2. 部署步驟

### 階段一：準備工作（30分鐘）
1. **通知使用者**
   - 發送維護通知
   - 預計停機時間：30分鐘

2. **備份現有系統**
   ```bash
   # 備份腳本
   ./scripts/backup-production.sh
   ```

3. **切換維護模式**
   ```bash
   # 啟用維護頁面
   ./scripts/enable-maintenance.sh
   ```

### 階段二：部署新版本（20分鐘）
1. **停止現有服務**
   ```bash
   docker-compose down
   ```

2. **更新代碼**
   ```bash
   git pull origin v54-optimized
   npm install --production
   ```

3. **更新資料庫結構**（如需要）
   ```bash
   npm run migrate
   ```

4. **建構生產版本**
   ```bash
   npm run build:production
   ```

### 階段三：啟動與驗證（10分鐘）
1. **啟動新服務**
   ```bash
   docker-compose up -d
   ```

2. **健康檢查**
   ```bash
   npm run health-check
   ```

3. **功能驗證**
   - 登入功能
   - 檔案上傳
   - 行事曆顯示
   - API 響應

4. **效能驗證**
   ```bash
   npm run performance-check
   ```

### 階段四：監控與優化（持續）
1. **啟用監控**
   - 啟動效能監控
   - 啟動錯誤追蹤
   - 啟動使用者行為分析

2. **關閉維護模式**
   ```bash
   ./scripts/disable-maintenance.sh
   ```

3. **發送完成通知**

## 3. 回滾計劃

### 觸發條件
- 嚴重錯誤無法快速修復
- 效能嚴重下降
- 資料完整性問題

### 回滾步驟
1. **立即切換維護模式**
2. **停止新版本服務**
3. **還原備份**
   ```bash
   ./scripts/rollback-production.sh
   ```
4. **重啟舊版本**
5. **驗證服務正常**
6. **通知相關人員**
