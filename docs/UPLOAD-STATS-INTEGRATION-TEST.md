### 2. 前端整合測試

#### 測試環境
- **URL**: `http://localhost:3000/perfect-calendar-modular.html`
- **瀏覽器**: Chrome/Safari/Firefox（建議使用 Chrome DevTools）

#### 測試步驟

##### Step 1: 啟動開發伺服器
```bash
cd /path/to/flb-calendar-nas
npm run dev
```

##### Step 2: 開啟日曆頁面
1. 打開瀏覽器訪問 `http://localhost:3000/perfect-calendar-modular.html`
2. 開啟瀏覽器開發者工具（F12 或 Cmd+Option+I）
3. 切換到 Console 標籤

##### Step 3: 檢查 API 呼叫
觀察 Console 輸出，應該看到：
```
📊 [V2 Courses] 查詢上傳統計: { eventId: "...", date: "...", courseName: "..." }
🔍 [V2 Courses] 清理後課程名稱: SPIKE 五 1610-1740 松山
✅ [V2 Courses] 返回上傳統計: { ... }
✅ [上傳統計] 查詢成功: { ... }
```

##### Step 4: 檢查 Network 請求
1. 切換到 Network 標籤
2. 篩選 XHR/Fetch 請求
3. 尋找 `/api/v2/courses/upload-stats` 請求
4. 檢查：
   - ✅ 狀態碼：200 OK
   - ✅ 回應格式：`{ "success": true, "data": {...} }`
   - ✅ 無 404 錯誤

##### Step 5: 檢查 UI 顯示
在日曆卡片的「上傳學習歷程」按鈕下方，應該看到：

**有上傳資料時**:
```
👥2/5 · 📁8 · 📋✓
```
說明：
- `👥2/5`: 2 個學生已上傳（共 5 個學生）
- `📁8`: 8 個檔案
- `📋✓`: 課程總覽已上傳

**無上傳資料時**:
```
尚無上傳
```

**載入中**:
```
⏳ 載入統計...
```

## 🐛 常見問題排查

### 問題 1: Console 顯示 404 錯誤
**症狀**: `GET /api/v2/courses/upload-stats 404`

**原因**: 路由優先級問題未修復

**檢查**:
```bash
grep -n "router.get('/courses" routes/v2-courses.js
```

**正確順序**:
```
119:router.get('/courses', ...);              // 列表
326:router.get('/courses/search', ...);       // 搜尋
385:router.get('/courses/upload-stats', ...); // 統計
534:router.get('/courses/:id', ...);          // 單一課程
```

**解決**: 重新套用路由修復（參考 `UPLOAD-STATS-ROUTE-FIX.md`）

---

### 問題 2: 統計不顯示或一直顯示「載入中」
**症狀**: 卡片下方無統計資訊或持續顯示「⏳ 載入統計...」

**檢查**:
1. Console 是否有錯誤訊息
2. Network 標籤中 API 請求是否成功
3. API 回應格式是否正確

**可能原因**:
- 後端未啟動
- 事件快取未就緒
- Google Sheets 資料未載入

**解決**:
```bash
# 重啟伺服器
npm run dev

# 檢查健康狀態
curl http://localhost:3000/health
```

---

### 問題 3: 統計資料不正確
**症狀**: 顯示的學生數或檔案數與實際不符

**檢查**:
1. 後端日誌中的索引查詢結果
2. 課程名稱清理是否正確（移除週次）
3. 學期計算是否正確

**Debug 指令**:
```javascript
// 在瀏覽器 Console 執行
const stats = await fetchCourseUploadStats('event-id', '2025-01-19', 'SPIKE 五 16:10-17:40 松山');
console.log(stats);
```
