# 進階搜尋功能使用指南

## 📋 功能概述

FLB 行事曆系統現在支援強大的 **Google/Spotlight 風格進階搜尋**，讓您可以快速、精確地找到所需的課程！

---

## 🚀 快速開始

### 基本搜尋
直接輸入關鍵字即可搜尋所有相關課程：

```
spm
```

**搜尋範圍**：
- 課程名稱
- 講師名稱
- 上課地點
- 課程描述
- 課程類型
- 學生姓名

---

## 🔥 進階搜尋語法

### 1️⃣ 多關鍵字搜尋（AND 邏輯）

使用空格分隔多個關鍵字，搜尋結果會**同時包含所有關鍵字**。

**範例**：
```
spm 到府
```

**結果**：只顯示同時包含 "spm" **和** "到府" 的課程

**適用場景**：
- 找特定講師的特定課程：`張老師 Python`
- 找特定地點的課程：`台北 程式設計`
- 縮小搜尋範圍：`線上 scratch 初級`

---

### 2️⃣ OR 搜尋（任一匹配）

使用 `OR` 連接關鍵字（大小寫不限），搜尋結果包含**任一關鍵字**即可。

**範例**：
```
spm OR scratch
```

**結果**：顯示包含 "spm" **或** "scratch" 的所有課程

**適用場景**：
- 找多種課程類型：`Python OR Scratch OR Minecraft`
- 找多位講師的課程：`張老師 OR 李老師`
- 找多個地點：`台北 OR 新竹`

**進階組合**：
```
到府 OR 線上 OR 教室
```
→ 找出所有到府、線上或教室課程

---

### 3️⃣ 精確匹配（引號）

使用雙引號 `"` 包裹短語，只搜尋**完全匹配**的內容。

**範例**：
```
"Python 基礎"
```

**結果**：只顯示完全包含 "Python 基礎" 這個短語的課程（不會匹配 "Python 進階" 或 "基礎程式"）

**適用場景**：
- 找特定課程名稱：`"Scratch 遊戲設計"`
- 找完整地址：`"台北市大安區"`
- 避免關鍵字被拆分

---

### 4️⃣ 排除關鍵字（減號）

使用 `-` 符號排除不想要的結果。

**範例**：
```
程式 -scratch
```

**結果**：顯示包含 "程式" 但**不包含** "scratch" 的課程

**適用場景**：
- 排除特定課程：`Python -初級`（只看進階課程）
- 排除特定講師：`程式設計 -張老師`
- 排除已取消課程：`本週課程 -取消`

**多重排除**：
```
課程 -取消 -暫停
```
→ 找出所有課程，但排除已取消和暫停的

---

### 5️⃣ 必須包含（加號）

使用 `+` 符號指定**必須包含**的關鍵字。

**範例**：
```
+spm 到府
```

**結果**：
- "spm" **必須存在**
- "到府" 可選（有更好，沒有也可以）

**適用場景**：
- 核心關鍵字 + 可選條件：`+Python 線上`
- 確保關鍵字不被 OR 邏輯影響

---

## 🎯 實戰範例

### 範例 1：找特定講師的到府課程
```
張老師 到府
```
→ 找出張老師的所有到府課程

---

### 範例 2：找 SPM 或 Scratch 課程，但不要線上課程
```
spm OR scratch -線上
```
→ 找出 SPM 或 Scratch 課程，但排除線上課程

---

### 範例 3：找特定學生的所有課程
```
"王小明"
```
→ 找出王小明的所有課程記錄

---

### 範例 4：找本週的 Python 課程，排除已取消的
```
+Python 本週 -取消
```
→ Python 課程必須存在，本週內的，但不包含已取消的

---

### 範例 5：找到府或線上課程，但必須是程式設計類
```
+程式設計 到府 OR 線上
```
→ 程式設計必須存在，可以是到府或線上

---

### 範例 6：找特定地區的課程
```
台北 OR 新北 -板橋
```
→ 找台北或新北的課程，但排除板橋地區

## 💡 使用技巧

### 1. 從寬到嚴，逐步縮小範圍
```
第1步：Python              （太廣）
第2步：Python 到府         （加入地點）
第3步：Python 到府 張老師  （加入講師）
```

### 2. 使用 OR 擴大搜尋範圍
當不確定關鍵字時，使用 OR 增加匹配機會：
```
程式 OR 編程 OR coding
```

### 3. 排除干擾結果
當搜尋結果太雜時，使用 `-` 排除不需要的：
```
課程 -測試 -範例 -demo
```

### 4. 引號鎖定精確內容
當關鍵字可能被拆分時，使用引號：
```
"到府服務"  （而不是 到府 服務）
```

### 5. 組合使用，打造完美搜尋
```
+Python "進階班" 台北 OR 線上 -週末 -取消
```
→ **必須有** Python，**完全匹配** "進階班"，地點是 **台北或線上**，**排除週末和已取消**的課程

## ⚙️ 技術說明

### 搜尋解析器
- 自動解析搜尋語法
- 支援複雜組合查詢
- 容錯處理（語法錯誤時回退到基本搜尋）

### 搜尋範圍
系統會搜尋以下所有欄位：
1. 課程標題（`title`）
2. 講師名稱（`instructor`, `teacher`）
3. 上課地點（`location`）
4. 課程描述（`description`）
5. 課程類型（`courseType`）
6. 學生姓名（`students[].name`）

### 匹配邏輯
- **不區分大小寫**（SPM = spm = Spm）
- **部分匹配**（"程式" 可匹配 "程式設計"）
- **智能斷詞**（支援中英文混合搜尋）

## 🐛 常見問題

### Q1: 為什麼搜尋 "spm 到府" 沒有結果？
**A**: 確認課程中同時包含這兩個關鍵字。如果只想找包含任一關鍵字的課程，使用 `spm OR 到府`

### Q2: 引號內的文字為什麼搜尋不到？
**A**: 引號用於精確匹配，確保課程中有**完全相同**的文字（包括空格和順序）

### Q3: 如何搜尋所有不在台北的課程？
**A**: 無法直接搜尋「不包含」，但可以使用 `-台北` 排除台北的課程

### Q4: OR 大小寫有影響嗎？
**A**: 無影響，`OR`、`or`、`Or` 都可以，但必須是完整的單字（前後有空格）

### Q5: 可以同時使用多個 OR 嗎？
**A**: 可以！例如：`Python OR Scratch OR Minecraft OR 機器人`

## 🎓 最佳實踐

1. **先試基本搜尋**，再逐步加入進階語法
2. **多使用 OR** 來擴大搜尋範圍
3. **善用排除** 來過濾不需要的結果
4. **保存常用搜尋**（系統會自動記錄搜尋歷史）
5. **點擊範例學習**，實際操作比閱讀文檔更有效
