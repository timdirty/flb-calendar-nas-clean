## 🧪 手動測試步驟

### 測試方法 1：使用幫助提示

1. 開啟行事曆頁面
2. 點擊搜尋框旁的 **?** 圖標
3. 點擊範例代碼進行測試
4. 檢查搜尋結果是否符合預期

### 測試方法 2：直接輸入

1. 在搜尋框輸入測試查詢
2. 觀察搜尋統計（找到幾筆課程）
3. 檢查課程列表是否符合搜尋條件
4. 使用瀏覽器控制台查看日誌

### 測試方法 3：使用控制台

```javascript
// 在瀏覽器控制台執行
const parser = new window.AdvancedSearchParser();

// 測試解析
const result = parser.parse('spm 到府');
console.log('解析結果:', result);

// 測試匹配
const testEvent = {
    title: 'SPM 到府課程',
    instructor: '張老師',
    location: '台北'
};
const matches = parser.matchEvent(testEvent, result);
console.log('是否匹配:', matches);
```

## 🔍 除錯技巧

### 1. 查看解析結果
```javascript
// 控制台執行
const parser = new window.AdvancedSearchParser();
const criteria = parser.parse('你的搜尋查詢');
console.log(criteria);
```

### 2. 查看搜尋日誌
在控制台查看以 `🔍` 開頭的日誌訊息

### 3. 檢查事件資料
```javascript
// 查看所有事件
console.log(window.allEvents);

// 查看搜尋結果
console.log(window.filteredEvents);
```

### 4. 手動測試匹配
```javascript
const parser = new window.AdvancedSearchParser();
const criteria = parser.parse('spm 到府');
const event = window.allEvents[0]; // 測試第一個事件
const matches = parser.matchEvent(event, criteria);
console.log('匹配結果:', matches);
```
