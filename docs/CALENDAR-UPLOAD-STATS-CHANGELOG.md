## 🎯 功能概述

在原版日曆頁面 (`perfect-calendar-modular.html`) 的課程卡片中，當課程已結束並顯示「上傳學習歷程」藍色按鈕時，在按鈕下方以**超緊湊的單行格式**顯示該課程的上傳統計資訊。

### 顯示內容
- **學生上傳統計**: 👥 已上傳/總學生（含顏色編碼）
- **檔案數統計**: 📁 總檔案數
- **課程總覽狀態**: 📋✓（已上傳）

### 設計特點
- ✅ **超緊湊設計**: 單行橫向排列，最小高度 18px（手機 20px）
- ✅ **顏色編碼**: 根據上傳進度顯示不同顏色（綠/橙/灰）
- ✅ **快取機制**: 5分鐘快取，避免頻繁 API 查詢
- ✅ **效能優化**: 避免重複渲染，使用標記機制
- ✅ **優雅降級**: API 失敗時自動隱藏統計區

## ⚡ 效能優化策略

### 1. 快取機制
```javascript
const courseStatsCache = new Map();
const STATS_CACHE_TTL = 5 * 60 * 1000; // 5 分鐘
```
- 使用 Map 儲存查詢結果
- 5分鐘內重複查詢直接返回快取
- 減少 API 請求頻率

### 2. 避免重複渲染
```javascript
if (statsContainer.dataset.rendered !== 'true') {
    statsContainer.dataset.rendered = 'true';
    // ... 查詢和渲染邏輯
}
```
- 使用 `data-rendered` 標記
- 每個課程卡片只查詢一次
- 倒數計時更新不會重複觸發

### 3. 優雅降級
```javascript
if (!stats) {
    statsContainer.style.display = 'none';
    return;
}
```
- API 失敗時自動隱藏統計區
- 不影響原有功能（藍色按鈕仍可用）
- Console 顯示警告但不阻塞執行

## 💡 設計理念

### 為什麼選擇超緊湊設計？
1. **用戶關注**: 避免卡片高度過高，影響瀏覽體驗
2. **資訊密度**: 在最小空間內呈現最重要的資訊
3. **視覺平衡**: 不搶走藍色按鈕的焦點
4. **行動優先**: 手機版依然清晰易讀

### 為什麼使用圖標而非文字？
1. **節省空間**: 圖標比文字更緊湊
2. **國際化**: 圖標無語言障礙
3. **視覺識別**: 快速理解資訊含義
4. **美觀度**: 圖標更加生動

### 為什麼使用顏色編碼？
1. **快速判斷**: 一眼看出上傳進度
2. **視覺提醒**: 低進度用灰色警示
3. **正向反饋**: 高進度用綠色鼓勵
4. **UX 最佳實踐**: 符合直覺
