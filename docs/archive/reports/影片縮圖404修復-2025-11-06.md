# 影片縮圖 404 錯誤修復

## 📅 日期
2025-11-06（第二次修復）

## 🐛 問題描述

用戶反映：影片可以上傳，但前端顯示 404 錯誤：

```
GET /api/media/videos/b982e393-3b2c-4e72-9a39-0c11f9a8231f/thumbnail 404 (Not Found)
```

## 🔍 診斷結果

### 問題根源

發現兩個問題：

1. **資料不同步**（已在前次修復中解決）
   - `videos-meta.json` 與 `media-meta.json` 不同步
   - 解決方案：後端優先讀取 `media-meta.json`

2. **舊資料或已刪除的影片記錄**（本次修復）
   - 前端快取中存在已刪除的 video ID
   - 後端全局索引（`data/learning-media/index.json`）中找不到此記錄
   - 導致 API 返回 404

### 驗證過程

```bash
# 1. 檢查全局索引
$ cat data/learning-media/index.json
# 結果：有 41 個檔案，但沒有 b982e393-3b2c-4e72-9a39-0c11f9a8231f

# 2. 搜索這個 ID
$ find data/learning-portfolio -name "*.json" -exec grep -l "b982e393..." {} \;
# 結果：找不到任何檔案

# 3. 列出所有 media-meta.json
$ find data/learning-portfolio -name "media-meta.json"
# 結果：4 個檔案，都不包含這個 ID
```

**結論**：這是一個已刪除或不存在的影片記錄，但前端快取中仍保留。

---

## ✅ 解決方案

### 方案 1：前端優雅降級（雙重防護）

**檔案**：`public/js/pages/learning-record-upload.js`  
**位置**：第 6105-6124 行

**修改內容**：為縮圖圖片添加 `onerror` 處理器，404 時顯示預設圖標。

```javascript
// 插入影片預覽後，立即添加錯誤處理
if (thumbUrl) {
  var justInserted = videosPreview.lastElementChild;
  var thumbImg = justInserted.querySelector('img[src="' + thumbUrl + '"]');
  if (thumbImg && !thumbImg.__errorHandlerAdded) {
    thumbImg.__errorHandlerAdded = true;
    thumbImg.onerror = function() {
      console.warn('⚠️ [縮圖404] 影片縮圖載入失敗，使用佔位符');
      // 顯示影片圖標佔位符（SVG）
      this.src = 'data:image/svg+xml,...';
      this.onerror = null; // 防止無限循環
    };
  }
}
```

**效果**：
- ✅ 縮圖 404 時自動顯示「▶」播放圖標
- ✅ 不會在 Console 產生紅色錯誤
- ✅ 不影響影片本身的播放功能

### 方案 2：後端返回預設縮圖（優先方案）

**檔案**：`server.js`  
**位置**：第 15761-15789 行

**修改內容**：找不到縮圖時，返回預設 SVG 圖片而不是 404。

```javascript
app.get('/api/media/videos/:recordId/thumbnail', async (req, res) => {
  const record = await mediaManager.getMedia(req.params.recordId);
  
  // 找不到記錄時，返回預設縮圖
  if (!record) {
    console.warn('⚠️ [影片縮圖] 找不到媒體記錄，返回預設縮圖');
    res.setHeader('Content-Type', 'image/svg+xml');
    res.setHeader('Cache-Control', 'public, max-age=3600');
    return res.send(`<svg>...</svg>`);  // 播放圖標 SVG
  }
  
  // 縮圖檔案不存在時，也返回預設縮圖
  if (!thumbPath || !fs.existsSync(thumbPath)) {
    console.warn('⚠️ [影片縮圖] 縮圖不存在，返回預設縮圖');
    res.setHeader('Content-Type', 'image/svg+xml');
    res.setHeader('Cache-Control', 'public, max-age=60');  // 短快取
    return res.send(`<svg>...</svg>`);
  }
  
  // 正常情況：返回實際縮圖
  res.sendFile(resolvedPath);
});
```

**效果**：
- ✅ API 永遠不會返回 404（總是有內容）
- ✅ 前端無需特殊處理
- ✅ 預設圖標清晰表達「影片」的概念
- ✅ 短快取時間（60秒），如果縮圖生成後能快速更新

## 🔍 根本原因分析

### 為什麼會有不存在的 video ID？

可能的原因：

1. **資料刪除未同步**
   - 使用者刪除了影片
   - 但前端 localStorage 快取未清除

2. **開發測試殘留**
   - 測試時上傳的影片
   - 之後檔案被手動刪除

3. **資料遷移問題**
   - 系統升級或資料遷移
   - 部分記錄遺失

4. **索引不一致**
   - `media-meta.json` 與全局索引不同步
   - 影片在目錄中但索引沒有

### 建議的清理步驟

```bash
# 1. 清除前端緩存（用戶端）
localStorage.clear();
sessionStorage.clear();
location.reload(true);

# 2. 重建全局索引（伺服器端，可選）
# 掃描所有 media-meta.json 並更新 index.json
```
