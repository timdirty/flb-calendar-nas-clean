```javascript
function fillCurrentEventTime() {
    const event = window.adminEvents?.find(e => e.id === adminSelectedEventId);
    if (!event) return;
    
    const startTime = new Date(event.dtstart * 1000);
    const endTime = new Date(event.dtend * 1000);
    
    // 格式化為 YYYY-MM-DDThh:mm
    document.getElementById('newStartTime').value = formatDateTime(startTime);
    document.getElementById('newEndTime').value = formatDateTime(endTime);
}
```

**載入講師列表**:
```javascript
async function loadTeacherListToSelect() {
    const response = await fetch('/api/teachers');
    const data = await response.json();

        const select = document.getElementById('substituteTeacher');
        select.innerHTML = '<option value="">請選擇代課講師...</option>';
        
        data.data.forEach(teacher => {
            const option = document.createElement('option');
            option.value = teacher.name;
            option.textContent = teacher.name;
            select.appendChild(option);
        });
    }
}
```

```javascript
async getEventByIcalUid(calendarId, icalUid) {
    await this.ensureLoggedIn();
    
    const params = new URLSearchParams({
        api: 'SYNO.Cal.Event',
        version: '5',
        method: 'get',
        ical_uid: icalUid,
        cal_id: calendarId,
        _sid: this.sid
    });
    
    const response = await axios.post(`${this.baseUrl}/webapi/entry.cgi`, 
        params.toString(), {
            headers: {
                'Content-Type': 'application/x-www-form-urlencoded',
                'X-SYNO-TOKEN': this.synotoken || ''
            }
        });
    
    if (response.data.success && response.data.data) {
        return response.data.data;  // 包含 evt_id
    }
}
```

## 📊 技術要點

### 1. Synology Calendar API 錯誤 9009 解決

**問題**: Parameter error（參數錯誤）

**原因**: 
- 傳遞了字串型 `ical_uid` 而非數字型 `evt_id`
- 缺少必要的 API 欄位

**解決方案**:
1. 使用 `SYNO.Cal.Event.get` API（帶 `ical_uid` + `cal_id`）獲取完整事件資料
2. 從返回資料中提取數字型 `evt_id`
3. 使用 `evt_id` 調用 `SYNO.Cal.Event.set` API
4. 添加所有必要欄位（`summary`, `dtstart`, `dtend`, `is_all_day`, `tz_id`, 等）

### 2. 前後端資料流

```
前端 → 後端 → Synology Calendar
```

**改時間流程**:
```
1. 用戶選擇新時間（datetime-local input）
2. 前端轉換為 Unix timestamp
3. 後端驗證時間合理性
4. 更新 event 物件的 dtstart/dtend
5. 傳遞給 caldavClient.updateEvent()
6. caldavClient 使用正確的數字 evt_id 更新
```

**代課流程**:
```
1. 用戶選擇代課講師（select dropdown）
2. 前端傳送 substituteTeacher 參數
3. 後端生成標題：`[代課-${substituteTeacher}]`
4. 後端添加描述：`[代課講師] ${substituteTeacher}`
5. 更新到 Synology Calendar
```

### 3. 時間處理

**前端**:
```javascript
// datetime-local 格式: "2025-11-08T13:30"
const newStartTimeStr = document.getElementById('newStartTime').value;
// 轉換為 Unix timestamp (秒)
const newStartTime = Math.floor(new Date(newStartTimeStr).getTime() / 1000);
```

**後端**:
```javascript
// 驗證
if (newEndTime <= newStartTime) {
    return res.status(400).json({ error: '結束時間必須晚於開始時間' });
}

// 更新事件
event.dtstart = newStartTime;
event.dtend = newEndTime;
```

**Synology Calendar API**:
```javascript
params.append('dtstart', event.dtstart);  // Unix timestamp (秒)

```
