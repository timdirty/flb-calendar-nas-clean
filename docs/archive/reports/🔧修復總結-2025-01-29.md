### 2. `parseTitle is not a function` 錯誤
**問題**：
```javascript
TypeError: global.FLB.Course.parseTitle is not a function
    at learning-record-upload.js:158:40
```

**原因**：
- `course-utils.js` 缺少 `parseTitle` 函數
- 該函數被 `learning-record-upload.js` 在多處調用（第158、381、417、443行）

**解決方案**：
在 `public/js/modules/course-utils.js` 中添加 `parseTitle` 函數：

```javascript
parseTitle(title) {
  if (!title || typeof title !== 'string') {
    return { courseName: '', period: '', instructor: '' };
  }
  
  // 🎯 處理包含 "—" 分隔符的格式
  if (title.includes('—')) {
    const parts = title.split('—').map(s => s.trim());
    return {
      courseName: parts[0] || '',
      instructor: parts[1] || '',
      period: parts[2] || ''
    };
  }
  
  // 🎯 處理空白分隔的格式
  const parts = title.split(/\s+/).filter(Boolean);
  let courseName = parts[0] || '';
  
  // 智能移除尾部數字（如 資訊課401 → 資訊課）
  if (/[\u4e00-\u9fa5]/.test(courseName)) {
    courseName = courseName.replace(/\d+$/, '');
  }
  
  return {
    courseName: courseName.trim(),
    instructor: parts[1] || '',
    period: parts.slice(2).join(' ')
  };
}
```

**額外修改**：

## ❌ 待修復的問題

### 3. 上傳學習記錄時的 502 錯誤

**問題**：
```
Failed to load resource: the server responded with a status of 502 ()
POST /api/learning-records/upload
```

**原因分析**：
502 Bad Gateway 錯誤通常表示 Nginx（反向代理）無法連接到後端 Node.js 服務。可能的原因：

1. **目錄權限問題**（最可能）
   - 路徑：`/volume1/Fun Learn Bar/學習歷程 automatic`
   - Docker 容器內的 Node.js 進程無法寫入此目錄
   - 或目錄不存在

2. **後端服務問題**
   - Node.js 服務可能崩潰
   - 或無法正常處理大文件上傳

3. **Nginx 配置問題**
   - 上傳文件大小限制
   - 超時設定

### 選項 B：使用 DSM 文件管理器

1. 登入 Synology DSM Web 介面
2. 開啟「File Station」
3. 導航到 `/Fun Learn Bar/`
4. 如果「學習歷程 automatic」資料夾不存在：
   - 右鍵 → 新增資料夾 → 輸入「學習歷程 automatic」

6. 重啟 Docker 容器：
   - 開啟「Container Manager」（Docker 應用）
