### 問題 1: Service Worker 緩存錯誤
**錯誤**: `NetworkError: Failed to execute 'put' on 'Cache'`

**根本原因**: Service Worker 嘗試緩存 opaque 響應或無效響應類型

**修復方案**:
- 更新 `public/sw.js`
- 添加更嚴格的響應檢查：
  - `response.status === 200`
  - `response.type !== 'error'`
  - `response.type !== 'opaque'`
  - `request.url.startsWith(self.location.origin)` (只緩存同源請求)
- 所有 `cache.put()` 操作都包裹在 `try-catch` 中
- 版本更新為 `flb-calendar-v2025-11-01-fix2`

**文件**: `public/sw.js`
**狀態**: ✅ 已修復

**問題**: 點擊課程卡片時，模態框不顯示

**根本原因**: 
1. **事件委託設置正確** ✓
2. **事件 ID 正確傳遞** ✓
3. **模態框元素存在** ✓
4. **模態框樣式不完整** ❌ ← 核心問題！

**診斷過程**:
```javascript
// 日誌顯示模態框樣式狀態
display: flex ✓
visibility: visible ✓
opacity: 1 ✓
z-index: auto ❌ ← 問題！
```

**問題細節**:
模態框的 HTML 只有 `style="display: none;"`，缺少：
- `position: fixed` (固定定位)
- `top/left/width/height` (全屏覆蓋)
- `z-index: 9999` (置於最上層)
- `background: rgba(0,0,0,0.7)` (半透明背景)
- `align-items: center; justify-content: center` (內容居中)

**修復方案**:
更新模態框 HTML：
```html
<!-- 🔥 修復前 -->
<div id="specialEventModal" class="modal-overlay" style="display: none;">

<!-- ✅ 修復後 -->
<div id="specialEventModal" class="modal-overlay" style="display: none; position: fixed; top: 0; left: 0; width: 100%; height: 100%; background: rgba(0, 0, 0, 0.7); z-index: 9999; align-items: center; justify-content: center;">
```

同時更新 `.modal-content` 樣式：
```html
<div class="modal-content" style="max-width: 600px; background: white; border-radius: 12px; box-shadow: 0 10px 40px rgba(0,0,0,0.3); max-height: 90vh; overflow-y: auto; position: relative;">
```

## 🔍 調試技巧總結

### 1. 模態框不顯示時的檢查順序
1. **元素是否存在**: `document.getElementById('modalId')`
2. **display 屬性**: `element.style.display`
3. **計算樣式**: `window.getComputedStyle(element)`
4. **父容器狀態**: 檢查所有父元素的 `display` 屬性
5. **z-index**: 確保足夠高（建議 > 9000）
6. **position**: 必須是 `fixed` 或 `absolute`

### 2. 事件委託調試
```javascript
container.addEventListener('click', (e) => {
    console.log('點擊目標:', e.target);
    const card = e.target.closest('.card-class');
    console.log('找到的卡片:', card);
});
```

### 3. Service Worker 調試
- 開發者工具 > Application > Service Workers
- 勾選 "Update on reload"
- 手動 "Unregister" 後重新整理
