# Perfect Calendar 完整集成方案

## 📅 更新日期：2025-11-02

## 🎯 解决方案概述

**问题：** 在管理后台特殊事件设定页面无法完整显示所有课程（日一二三四五六日）

**解决方案：** 使用 iframe 将完整的 `perfect-calendar-modular.html` 嵌入到管理后台

**优势：**
- ✅ **统一模块和 API** - 使用相同的代码和数据源
- ✅ **完整功能** - 包含所有筛选、搜索、视图切换功能
- ✅ **自动更新** - perfect-calendar 的任何更新会自动反映
- ✅ **易于维护** - 不需要重复代码
- ✅ **完整显示** - 可显示一周七天的所有课程

---

## ✨ 功能优势

### 1. **统一数据源和 API**

**之前：** 需要在两个地方维护相同的逻辑
- perfect-calendar-modular.html 有一套
- admin-dashboard.html 又复制一套

**现在：** 只有一个数据源
```
┌──────────────┐
│  /api/events │ ← 统一的 API 端点
└──────┬───────┘
       │
       ├─→ perfect-calendar-modular.html (主页面)
       │
       └─→ admin-dashboard.html (通过 iframe 引用主页面)
```

### 4. **特殊事件管理工作流**


## 🔧 技术细节

### iframe 尺寸

```css
width: 100%;     /* 填满父容器 */
height: 90vh;    /* 视窗高度的 90%，留出空间给标题 */
border: none;    /* 无边框，无缝集成 */
```

### 重新整理功能

```javascript
// 重新整理 iframe 内容
document.getElementById('calendarFrame').contentWindow.location.reload();
```

### 响应式设计

- **桌面端：** 完整显示日历和所有控件
- **移动端：** 自动调整为列表视图（由 perfect-calendar 内部处理）

## 📋 使用说明

### 对于管理员：

1. **查看课程**
   - 打开管理后台 → 特殊事件设定
   - 直接在嵌入的日历中查看所有课程
   - 使用所有筛选和搜索功能

2. **标记特殊事件**
   - 方法 A：直接在 Synology Calendar 编辑标题（推荐）
   - 方法 B：设定自动检测规则（特殊事件类型管理）

3. **管理规则**
   - 在「特殊事件類型管理」设定关键字
   - 点击「儲存設定」保存
   - 系统会自动检测包含关键字的课程

## ⚠️ 注意事项

### 1. **跨域问题**
- ✅ 由于 iframe 和主页面在同一域名下，不会有跨域问题
- ✅ 可以通过 `contentWindow` 访问 iframe 内容

### 2. **性能**
- ✅ iframe 只在打开「特殊事件设定」页面时加载
- ✅ perfect-calendar 已经过性能优化
- ✅ 不会影响管理后台其他页面的加载速度

### 3. **数据同步**
- ✅ 使用相同的 `/api/events` 端点
- ✅ 修改会实时反映（重新整理后）
- ✅ 无需额外的同步机制
