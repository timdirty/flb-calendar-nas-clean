學生篩選規則配置

說明：這些設定會影響 perfect-calendar 和 learning-record-upload 頁面的學生篩選邏輯

⚙️ 基本設定

啟用後會在瀏覽器 console 輸出詳細的學生匹配過程，方便調試
關閉後將顯示所有學生，不論剩餘堂數
設定為 0 表示顯示剩餘 0 堂以上的學生（預設），設定為 -1 則顯示所有學生包含負數
🎯 智能邏輯：系統會檢查學生的最後出席日期
• 如果學生最後一次出席在 7 天內 → 繼續顯示（方便修改出席狀態）
• 如果超過 7 天 → 自動隱藏
例如：學生在 10/20 出席後剩餘 0 堂，到 10/27 前都會顯示，10/28 後自動隱藏
建議：開啟此選項，避免學生簽到後立即消失

📚 課程匹配設定

精確匹配：SPIKE PRO 只匹配 SPIKE PRO
模糊匹配：SPIKE 可以匹配 SPIKE PRO

⏰ 時間匹配規則

允許 "日 10:00-12:00" 匹配 "日 10:00-12:00 第3週"
允許 "日 10:00-12:00" 匹配 "日 10:00-12:00 代課"
允許 "10:00-12:00" 匹配 "1000-1200"（自動轉換冒號格式）
重要提示：
  • 修改設定後會立即生效，前端會自動刷新快取
  • 調試模式會產生大量 console 日誌，正式環境建議關閉
  • 剩餘堂數設定會影響學生是否顯示在列表中
  • 時間匹配規則影響如何判斷學生是否屬於某堂課
  • 🔗 特殊事件關鍵字會從「特殊事件設定」自動同步
🔗 特殊事件關鍵字來源：

系統會自動從後端讀取「特殊事件設定」中配置的關鍵字（停課、體驗、代課、改時間）。
這些關鍵字用於移除時間後綴，實現精確匹配。
例如：「日 10:00-12:00 停課」→ 自動移除「停課」→ 匹配「日 10:00-12:00」的學生。
